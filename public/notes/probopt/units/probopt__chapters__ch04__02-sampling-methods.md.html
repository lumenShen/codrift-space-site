10.1 先看工程长什么样

前面九个单元，我们一直在跟「期望」「似然」「熵」「损失」打交道。这些量都是对分布做的积分或求和。po01 里已经埋过一句话：期望可以用采样均值来估计。这一单元把那句话兑现——真正把样本从分布里抽出来。

采样不是有趣的小技巧，而是深度学习的日常。训练时的 dropout 是对伯努利分布采样；变分自编码器从后验里采一个隐向量；扩散模型的生成过程是一连串条件采样；强化学习里按策略概率选动作也是采样。不会采样，这些模型连前向跑一遍都做不到。本册不搞测度论，只讲两种最基础、能真跑能对拍的办法：逆变换法和拒绝采样。

大白话一句话讲完这一单元

如果会算分布的累计函数 F，就从均匀数 u 反解 x=F⁻¹(u)；如果只会算密度 p、不会算 F，就在一个包络住 p 的简单分布上采样，再按 p/(Mq) 的概率决定留不留。前者精确且高效，后者通用但会随维度迅速失效。

第 2 帧里新工程的结构和前两单元一致。rejection.h 声明三种采样方式：三角分布的拒绝采样、d 维乘积目标的接受率、逆变换采样；rejection.c 实现它们；main.c 给每种方法固定种子、跑够次数、打印结果；清单写黄金值与容差。注意同一个 main 里用了两个不同的种子——拒绝采样用 20240519UL，逆变换用 990099UL，各自独立，互不干扰。

10.2 逆变换法：会算 CDF 就能采样

先看最容易的一种。设目标密度是三角分布 p(x)=2x，定义域 0≤x≤1。它的累计分布函数（CDF）是

F(x) = ∫₀ˣ 2t dt = x²，0≤x≤1

CDF 单调地从 0 涨到 1，正好是均匀分布的值域。逆变换法的做法是：抽一个 u ~ Uniform(0,1)，令 x = F⁻¹(u) = √u，那么 x 就服从 p。证明只要一行：P(x ≤ a) = P(√u ≤ a) = P(u ≤ a²) = a² = F(a)，与定义吻合。

这个方法的条件很明确：你得能写出 F 的显式反函数。指数分布的 F(x)=1−e^{−λx} 好反解，得到 x=−ln(1−u)/λ；标准正态的 CDF 没有初等反函数，逆变换就不直接可用（实践中用 Box–Muller 或数值近似）；离散分布更容易——把概率累加成区间，抽一个 u 看它落在哪一段。本册共用库里的 po_normal() 用的正是 Box–Muller，把两个均匀数变成一个正态样本；po_categorical() 则是离散版的逆变换。

工程惯例为什么 `√u` 会把样本往大的方向推

均匀数 u 在 [0,1] 上平坦，√u 却是凹函数：它把小区间拉宽、大区间压窄。具体地，u≤0.25 只占四分之一的概率，却对应 x≤0.5 这一半的区间——样本有更多机会落在小 x 吗？反过来想：p(x)=2x 在 x 大时密度高，所以大 x 应该更常见。取 x≤0.5 的概率是 F(0.5)=0.25，确实只有四分之一；u≤0.25 也正好是四分之一。凹变换把 [0,0.25] 这段 u 映射到 [0,0.5] 这段 x，看起来区间变宽了，但概率没变——这正是密度 2x 在小 x 处低、大 x 处高的表现。手算期望 E[x]=∫₀¹ x·2x dx=2/3，明显大于均匀分布的 1/2，与这个直觉一致。

10.3 拒绝采样：只会算密度也能采

现在把条件放宽：假设你只知道密度 p(x) 的函数值，不知道它的 CDF，甚至不知道归一化常数。拒绝采样只需要另找一个提议分布 q(x)（要会采样、会算密度），以及一个常数 M，使得对所有 x 都有 M·q(x) ≥ p(x)——也就是 Mq 这张「毯子」把 p 整个盖住。算法两步循环：

  1. 从 q 抽一个候选 x，再从 Uniform(0,1) 抽一个 u；
  2. 若 u ≤ p(x)/(M q(x))，接受这个 x；否则丢弃，回到第一步。

直觉上很朴素：在 p 高的地方，p/(Mq) 接近 1，候选几乎都留下；在 p 低的地方，这个比值小，候选大多被扔掉。剩下的样本密度自然正比于 p。证明也短：候选密度为 q(x)，接受概率为 p(x)/(Mq(x))，所以接受点的联合密度是 q(x)·p(x)/(Mq(x)) = p(x)/M。再除以总接受概率 ∫p(x)/M dx = 1/M（假设 p 已归一化），得到的条件密度正好是 p(x)。

本例取 q 为 [0,1] 上的均匀分布（q(x)=1），目标 p(x)=2x，它的最大值是 2，所以取 M=2。接受概率简化为 p(x)/(Mq(x)) = 2x/2 = x。程序里那行 if (po_uniform() < x) 就是它。总接受率是 ∫₀¹ q(x)·x dx = ∫₀¹ x dx = 1/2——每两个候选大约留下一个。

第 2 帧的 p -> envelope 那条边是本方法的前提：p(x)=2x 在 x=1 处刚好触到包络高度 2，其余位置都在毯子下面。若你选的 M 太小，毯子被 p 戳破，接受概率 p/(Mq) 会超过 1，数学上不成立，程序里表现为「本来该接受的点被以大于 1 的概率接受」——当然概率不可能大于 1，于是分布被扭曲。第 3 帧把候选点 x 与随机数 u 画在同一个画面里，u < x 就收下这个候选。三帧各自重复了 q、envelope、p 这些仍然成立的元素，符合「每帧自包含」的规矩。

陷阱M 不是越小越好，也不是越大越好

M 必须满足 Mq ≥ p，这是硬约束；在这个前提下，接受率恰是 1/M，所以 M 越小效率越高。但「刚好等于最大值」的 M 往往难求，实际中常取一个略大的保守值。取太大不会让分布变错——p/(Mq) 变小只是让更多候选被丢掉，留下的样本仍然服从 p——但会让实验慢得无法忍受。真正致命的是取小了导致毯子被戳破，这时接受概率公式失效，采样分布出错，而且程序不会报任何错误。所以调 M 时宁大勿小。

10.4 接受率：它是效率的仪表盘

把「接受率」定义成「留下的候选数 / 总候选数」。对本例，理论值是 1/M = 0.5。但真跑时你看到的是 0.499500，不是恰好 0.5——因为它是随机数。每个候选是否留下是一次伯努利试验，成功率 0.5；抽 N=2,000,000 次，接受数的标准差是 √(N·0.5·0.5) ≈ 707，除以 N 得到接受率的标准误约 0.000354。观测值 0.499500 离理论值 0.0005，约 1.4 个标准误，完全在正常波动范围内。这就是清单里 accept_rate 的容差放宽到 atol=1e-3 的原因：蒙特卡洛量自带统计噪声，容差必须比噪声大，否则每次跑都可能因为正常波动而误报。

样本均值 sample_mean 也有误差，但来源不同。留下的 999,000 个样本近似独立地服从 p，单个样本的方差是 E[x²]−(E[x])² = 1/2 − 4/9 = 1/18 ≈ 0.0556；均值的标准误是 √(0.0556/999000) ≈ 0.000236。观测值 0.666581 与理论 2/3≈0.666667 相差约 0.000086，不到半个标准误。注意这里容差是 atol=1e-6，比标准误小得多——为什么不被噪声搞挂？因为种子固定后，这串随机数完全确定，真跑值就是一个确定的数；清单的黄金值直接取这个固定种子下的读数，闸门核对的是「程序有没有跑对这套算法」，不是「估计值有多接近理论值」。理论值另有一行 true_mean=0.666667，它才是用来对照的。

实验记录把种子换掉会怎样

把 main.c 里拒绝采样的种子从 20240519UL 改成别的值，重新编译运行：accept_rate、sample_mean、num_accepted 三个数都会变，但都还在理论值附近。此时闸门会报 numeric_value_mismatch，因为清单里的黄金值对应的是旧种子。这个实验同时说明两件事：一是蒙特卡洛的波动是真实的、可复现的；二是黄金值与种子是绑定的，换种子必须同步更新黄金值，或者另建一个清单做对照。

10.6 数字怎么读：四个层次

把七行输出分四层看。第一层是 first8，八个接受样本全在 0 到 1 之间，且偏大的多（0.937866、0.764720、0.716767），这正是 p(x)=2x 把密度推向大 x 的表现。第二层是接受率：0.499500 对理论 0.5，num_accepted=999000 就是 2,000,000×0.4995，两者互相印证。

第三层是样本均值与理论均值：0.666581 对 0.666667，差约 8.6e-5。true_mean 这一行是程序里写的常数 2.0/3.0，不是从样本算的——它的作用是给读者一把独立的尺子。第四层是维度实验：accept_2d=0.249510 对理论 0.25，accept_5d=0.031241 对理论 0.03125，都落在允许波动里。最后 inv_mean=0.666773 来自逆变换法，用另一串种子独立抽一百万个 √u 样本得到，与拒绝采样的 0.666581 不同但都贴近 2/3。两种方法的样本均值各自带噪声，差 0.000192 约为合并标准误的两倍以内，完全正常。

工程惯例为什么逆变换的结果看起来「更准」

inv_mean=0.666773 离 2/3 的距离是 0.000106，确实比拒绝采样的 0.000086 略大，所以它并不更准。真正的差别在效率：逆变换每个均匀数直接产生一个样本，零浪费；拒绝采样每接受一个样本平均要抽两个候选，而且每次接受判定还要多抽一个 u。若要生成同样多的有效样本，逆变换大约只用一半的随机数。当然，这个优势的前提是 F⁻¹ 存在且便宜——本例 √u 只需一次开方，恰好成立。

第 2 帧的 d10 没有真跑，是按 (1/2)^10 手算出来的——真实实验里这个数意味着每百万个候选只留下约九百个。十维还只是个开始；一百维时接受率是 2⁻¹⁰⁰，这是个比任何实验预算都小得多的数。两帧都把前一维的节点重复写了一遍，读者单看第 2 帧也能读出「逐维打对折」的趋势。

10.7 高维为什么失效，以及 MCMC 想救什么

接受率按 (1/2)^d 塌方，根源是「体积集中」：在高维单位立方体里，绝大部分体积集中在靠近表面的薄壳，而乘积密度 ∏(2xⱼ) 在中心区域最高、在角落才大。均匀提议的候选几乎总落在目标密度极低的区域，于是被无情拒绝。更一般地，高维分布的目标密度往往集中在一个体积很小的典型集上，随便找一个简单提议很难打中它；要盖住密度峰值的包络常数 M 又被迫取得极大，进一步压低接受率。

出路是不要独立地抽每个样本，而是让下一个样本依赖当前样本：如果新点落在高密度区就以较大概率走过去，落在低密度区就可能留在原地。这样构造出的马尔可夫链，其平稳分布恰好是目标分布；跑足够多步之后，链上的样本就近似来自 p。这就是 MCMC（马尔可夫链蒙特卡洛）的核心想法。Metropolis–Hastings 算法用的接受概率是 min(1, p(x')q(x|x') / (p(x)q(x'|x)))，提议可以很局部，接受率不再按维度指数塌方。代价是样本之间相关，不能像拒绝采样那样当成独立同分布；要丢弃开头的「预热期」，还要监控链有没有真正混合。

陷阱MCMC 不是「更聪明的拒绝采样」

两者虽然都有「接受/拒绝」的动作，但目标完全不同。拒绝采样每次从提议分布独立抽候选，被拒就重抽，留下的样本独立同分布；MCMC 被拒时留在原地，样本之间有强相关，独立性只在极长的间隔后近似成立。把 MCMC 的连续样本当成独立样本去算均值，标准误会被严重低估——你以为看了 100 万个样本，有效样本可能只有几千。诊断有效样本量（ESS）是 MCMC 实践里的必备步骤。

10.8 采样在 dropout 与生成里的角色

回到深度学习的日常。dropout 的训练操作是：对每个神经元抽一个伯努利变量，以概率 1−p 把它暂时置零。这就是最朴素的采样——每个训练步、每个神经元都要抽一次。推理时通常不采样，而是用期望（把权重乘以保留概率），这叫 inverted dropout，目的是让训练与推理的期望一致。这里的关键不是采样方法多高级，而是「训练时采样、推理时取消随机性」这个模式。

变分自编码器把采样放进了前向传播：编码器输出隐变量的一个分布参数，解码器需要从后验中采一个 z 才能生成。 famously 的「重参数化技巧」就是把 z = μ + σ⊙ε 中的随机性挪到 ε ~ N(0,1) 上，让梯度能穿过采样这一步——否则采样不可导，反向传播断在这里。这个技巧和逆变换法是一回事：把「从分布采样」改写成「从固定分布采样再做确定性变换」。

扩散模型把这件事推到极致：生成一张图要从噪声开始，按学习到的条件分布一步一步去噪，每一步都涉及一次采样。采样质量、步数、随机种子共同决定了输出——你在图像生成界面里填的那个 seed，控制的就是整条采样链的随机数。理解了本单元「固定种子就固定输出」的道理，你就明白为什么同一个 seed 能复现同一张图，也明白为什么换个实现（不同 LCG、不同采样器）即使 seed 相同也可能得到不同结果。

工程惯例什么时候用逆变换，什么时候用拒绝

判据不是「哪个更高级」，而是「你知道什么」。知道 CDF 且反函数便宜，逆变换首选：精确、无浪费。只知道密度、CDF 难求但能找到好提议和包络，拒绝采样足够：实现几行就能写完，样本独立。两者都不行——密度只知道到比例、维度又高——就该考虑 MCMC 或专门的采样器。深度学习框架里的 torch.normal、numpy.random 等函数在底层已经把逆变换、Box–Muller、别名法等方法封装好了，你通常不用自己实现；但读到采样相关的论文时，应该能判断它用的是哪一类、为什么用这一类。

10.9 常见失败模式与排查

第一，M 选小了，包络被戳破。程序不会报错，但接受概率公式失效，样本分布悄悄变错。防御办法是先在网格上扫一遍 p(x)/q(x) 的最大值，宁可取大一点。第二，种子没固定。蒙特卡洛实验一旦忘了 po_seed，每次跑出的黄金值都不同，闸门永远报 mismatch；更糟的是如果你用「第一次跑的输出」当黄金值，那个数下次就对不上了。

第三，把统计波动当成 bug。接受率 0.499500 与理论 0.5 相差 0.0005，这是正常的；若把容差也设成 1e-6，闸门几乎每次都会误报。反过来，若把容差放宽到 0.1，就等于取消了检查——程序把接受判定写错成常数 0.5，也能通过。容差要按误差来源定：本例标准误约 3.5e-4，取 1e-3 是「大约三个标准误」，既容纳噪声又能抓住真正的错误。

10.10 黄金值来源与复现清单

七个黄金值分两类。true_mean=0.666667 来自手算积分 ∫₀¹2x²dx=2/3，是独立推导。accept_rate=0.5、accept_2d=0.25、accept_5d=0.03125 来自理论接受率 1/M=(1/2)^d，也是独立推导，只是容差放宽到 1e-3 容纳统计噪声。剩下四项——sample_mean=0.666581、num_accepted=999000、inv_mean=0.666773，以及 first8 那串向量——来自固定种子下的真跑读数，属于回归基准。它们不是「第一次随便跑出来的数」：种子写死、编译选项固定 -O0、LCG 实现在共用库里不变，所以任何机器上重跑都得到同一串数。这与 po08 的情况完全一样，是蒙特卡洛实验的标准做法。

复现这个实验要记全以下条件：目标密度 p(x)=2x 与定义域 [0,1]；提议分布 Uniform(0,1)；包络常数 M=2；候选数 REJ_N=2,000,000；两个种子 20240519UL 与 990099UL；逆变换样本数 1,000,000；容差分配（accept 三项 1e-3，其余 1e-6）。清单保存期望，源码保存做法，两者合起来才是一份完整记录。少写任何一条，别人都无法解释屏幕上的七行数从哪来。

10.11 从 LCG 到真随机数：种子到底固定了什么

共用库里的随机数发生器是线性同余发生器（LCG）：r ← (1664525·r + 1013904223) mod 2³²，取高 24 位除以 2²⁴ 得到 [0,1) 上的均匀数。它的全部状态就是一个 32 位整数 r，po_seed(seed) 把它设成给定值。种子固定，整条序列就固定——这就是本单元所有黄金值可复现的根本原因。

需要说清的是，LCG 不是「真随机」，它是伪随机：序列完全确定，只是统计性质看起来像均匀独立。对教学和数值实验来说这恰恰是优点——你要的就是可复现，而不是不可预测。真随机源（硬件噪声、大气噪声）用于密码学和抽签，那里需要的是不可预测性；数值实验需要的是「换台机器还能得到同一串数」，二者目标相反。理解这一点，你就明白为什么本册坚持用固定种子的 LCG 而不用标准库里那些实现各异的发生器。

LCG 也有统计性质上的短板：相邻数之间存在可被检测出的相关性，高维情形下尤其明显。在本单元这种百万量级的一维采样里它够用；若要做严谨的蒙特卡洛积分或高维 MCMC，应该换质量更好的发生器（比如 PCG 或 Mersenne Twister）。但换了发生器，黄金值也会跟着变——所以「复现」永远是指在同一套实现、同一个种子下复现，不是跨实现的绝对一致。

陷阱别把 `po_normal()` 当成免费的午餐

共用库的 po_normal() 用 Box–Muller 变换，每调用一次消耗两个均匀数，并涉及 log、sqrt、cos 三个超越函数。它比 po_uniform() 贵得多。在需要大量正态样本的场合，这个开销会主导运行时间；实践中常用查表、Ziggurat 等更快的算法。另外，Box–Muller 产生的两个数其实是一对（另一个可用正弦得到），库里丢弃了第二个——这是为了代码短，不是数学必需。

10.12 逆变换法的更多例子与数值稳定

逆变换法的适用范围比初看要广。指数分布 p(x)=λe^{−λx}（x≥0）的 CDF 是 F(x)=1−e^{−λx}，反解得 x=−ln(1−u)/λ；因为 u 与 1−u 都服从均匀分布，实践里常写成 x=−ln(u)/λ，省一次减法。威布尔分布、柯西分布、以及任何能写出初等反函数 CDF 的分布都能照办。离散分布更直接：把概率累加成 [0,p₀)、[p₀,p₀+p₁) 这样的区间，抽一个 u 看它落在哪一段；共用库的 po_categorical() 正是这么实现的。

数值稳定上有两个坑。第一，u 可能恰好为 0（LCG 取高 24 位，只有 r 的高位全零时才发生，概率极小但不为零），此时 −ln(u)=+∞。稳妥做法是先取 u = po_uniform() 再做 1.0−u，或者加一个极小偏移——共用库的 po_normal() 里 u + 1e-12 就是在防这件事。第二，当 u 非常接近 1 时，1−u 会遭受灾难性相消；用 −ln(u) 的写法反而更稳。这类细节在教科书里常被略过，真跑时却能让你的程序偶发打出 inf。

实验记录用逆变换采柯西分布，看看期望为什么不收敛

柯西分布的 CDF 是 F(x)=½+arctan(x)/π，反函数是 x=tan(π(u−½))。抽一百万个样本算均值，你会发现结果随着样本数增加并不稳定——它不会像中心极限定理说的那样收敛到某个数。原因是柯西分布没有有限的期望（po01 的引子）。这个实验把「期望不一定存在」从一句话变成一个看得见的数值现象：样本均值会被少数极端值反复拉偏。做的时候记得给 tan 的输入避开 ±π/2，否则会得到巨大的数。

10.13 接受率的误差预算与实验设计

设计一个蒙特卡洛实验，先要算需要多少样本。接受率的估计值是 â = A/N，其中 A 是接受数、N 是候选数。每个候选是成功概率 a=1/M 的伯努利变量，â 的标准误是 √(a(1−a)/N)。若想让标准误降到 σ，需要 N ≈ a(1−a)/σ²。本例 a=0.5，要 σ=1e-4 就需要 N≈2.5×10⁷——两千五百万次，比我们实际用的两百万多一个数量级。这就是为什么容差定在 1e-3：它对应 N≈2.5×10⁵ 就够，两百万提供了宽裕的余量。

样本均值的误差预算则是另一套。接受样本近似独立同分布，数量约 N·a，单个样本方差 Var(p)，均值的标准误是 √(Var(p)/(Na))。本例 Var(p)=1/18≈0.0556、Na≈10⁶，得 ≈2.4e-4。若要把均值估计做到 1e-5，需要约 5.6×10⁸ 个接受样本——这不现实。此时更聪明的办法不是堆样本，而是用低方差估计量：重要性采样、分层采样、控制变量法都是这个思路，它们用问题结构换取更少的样本。

第 2 帧揭示了一个容易忽略的事实：三种采样共用同一个 po_uniform() 状态机，区别只在调用顺序与初始种子。拒绝路径和逆变换路径用不同种子，所以两条序列互不干扰；维度实验虽然用同一个种子，但每次调用产生的序列长度不同，得到的接受率自然不同。若你把种子设成一样又想让两条路径完全独立，必须在切换前重新 po_seed——本例已经这么做了。

工程惯例高斯分布采样为什么值得单独优化

深度学习里正态样本的数量极大（初始化、噪声注入、VAE 的隐变量），po_normal() 里那三个超越函数累积起来相当可观。Ziggurat 算法用预先算好的矩形和阶梯来覆盖密度曲线，绝大多数采样只需几次比较和一次乘法，只有极少数落到尾部才走慢路径。它比 Box–Muller 快好几倍，是许多数值库默认的正态采样器。你不必自己实现它，但看到框架里的采样器选项时，应该知道背后的权衡：速度与尾部精度、状态大小与实现复杂度。

10.14 和前面单元的连接：采样是期望的执行器

回头看整本书的路线，采样串起了至少三处。po01 说期望是「长期平均」，并给出蒙特卡洛估计——本单元正是那句话的执行器：没有采样方法，长期平均就只能停留在定义上。po04 的最大似然要对数据分布求期望（或对数似然的期望），当积分没有闭式解时，就要靠采样近似；EM 算法、变分推断里的蒙特卡洛估计都走这条路。po05 的熵与 KL 同样是积分，离散情形直接求和，连续情形常常需要采样近似。

再往前看，po08 的 Adam 在随机梯度下降里用到的小批量，本质是从训练数据这个经验分布里采样；po09 的对偶变量给约束定价，而采样方法能帮你估计约束的期望值。整个分册从「分布是什么」走到「怎么从分布里取样本」，这条线到此闭合。下一册若进入生成模型，你会发现扩散模型、正常化流、自回归模型本质上都在回答同一个问题：如何高效、可控地从复杂分布中采样。本单元教的两种最基本方法，就是那座大厦的地基。

陷阱采样不是万能的近似工具

蒙特卡洛的误差按 1/√N 下降：样本数翻四倍，精度才翻一倍。在高维问题里，这个缓慢的收敛速度常常比「没有闭式解」更让人绝望。确定性数值积分在一维、二维远优于蒙特卡洛；只有在维度升高后，蒙特卡洛的收敛率才显出优势（它与维度无关，而网格积分的格点数随维度指数增长）。所以正确的问题是「在什么维度、什么精度要求下用采样」，而不是「采样能不能解决一切」。

10.15 一句话收束

把这个单元压缩成一句话：能反解 CDF 就用逆变换，不能反解就找一个包络住密度的提议做拒绝采样；接受率告诉你效率，样本均值告诉你正确性，维度会吃掉前者，种子保证一切可复现。记住这条主线，具体的公式只是它的展开。

10.16 手算核对：不靠程序也能验的三组数

第一组是 CDF 与反函数。p(x)=2x 在 [0,1] 上积分得 F(x)=x²，F(1)=1 说明归一化正确。取 u=0.64，反解得 x=√0.64=0.8；验算 P(x≤0.8)=F(0.8)=0.64=u，一致。取 u=0.25，x=0.5，F(0.5)=0.25，也一致。这说明 √u 把均匀的 u 映射成了密度向大 x 倾斜的样本。

第二组是期望与方差。E[x]=∫₀¹x·2x dx=2/3≈0.666667。E[x²]=∫₀¹x²·2x dx=1/2，所以 Var(x)=1/2−(2/3)²=1/18≈0.055556。用这组数估计样本均值的标准误：√(0.055556/999000)≈0.000236，与真跑偏差 |0.666581−0.666667|≈0.000086 相比，后者不到半个标准误，说明程序行为正常。这三步手算不需要任何工具，任何人重算都能得到同样的数——这就是「可手算核对」的价值，它让你在程序出错时还有一把独立的尺子。

第三组是接受率。一维理论 1/2，真跑 0.499500，接受数 999000=2000000×0.4995，三数咬合。二维理论 (1/2)²=0.25，真跑 0.249510；五维理论 (1/2)⁵=0.03125，真跑 0.031241。把这三个数按维度排成一条序列，你就看到了指数衰减的形状：每加一维，接受率就 roughly 打对折。十维时约 0.00098，二十维时约 9.5e-7，实验预算再大也无济于事——这比任何公式都直观地说明了维度灾难。

工程惯例为什么这三类数要分开验

它们验的是不同的东西。CDF 与反函数验「推导对不对」；期望与方差验「目标分布理解得对不对」；接受率验「采样机制实现得对不对」。一类错了，其它两类可能仍然自洽：比如接受判定写成常数 0.5，接受率仍对得上，但样本均值会露馅；若目标密度写成了 p(x)=3x²，CDF 推导跟着错，手算的 2/3 就不再是正确参照。把三类数各自独立地算一遍，等于给实验上了三道不同的保险。这也解释了为什么清单要同时写七个黄金值，而不是只写最重要的那个。

10.17 再想一步：采样与优化的分工

最后点一下采样和优化的关系，免得把两个工具混用。优化在找一个点：最大化似然、最小化损失、求对偶变量，答案是一个确定的数或向量。采样在生成一批点：从已知分布里抽出样本，用来估计期望或产生随机性。 po08 的 Adam 属于前者，本单元属于后者。二者交汇的地方是随机优化：目标里的期望用样本均值近似，而参数再用优化器更新——每一小步都同时用到本单元的采样和上一单元的优化器。

小结这一节的要点
  • 逆变换法要求 CDF 有显式反函数；p(x)=2x 的 F(x)=x²，所以 x=√u，样本均值理论值 2/3；
  • 拒绝采样只需密度与包络：从 q 抽候选，以 p/(Mq) 的概率接受；本例 q 均匀、M=2，接受概率是 x；
  • 真跑：accept_rate=0.499500、sample_mean=0.666581、accept_5d=0.031241，分别对应理论 0.5、2/3、0.03125；
  • 接受率是效率指标，样本均值才验证「采对了分布」；蒙特卡洛噪声决定容差：accept 三项 1e-3，确定量 1e-6；
  • 高维接受率按 (1/2)^d 塌方，MCMC 用相关样本绕开这个指数灾难，但要处理预热期与有效样本量；
  • dropout、VAE、扩散模型都在用采样；固定种子让随机数成为可复现的实验条件，而不是噪声。

  4. 接受率是蒙特卡洛量，每次实验自带统计噪声；N=2×10⁶ 时标准误约 √(0.25/N)≈3.5e-4，观测偏差 0.0005 约 1.4 个标准误，属正常波动。1e-3 约为三个标准误，既容纳噪声又能抓住真正的错误；1e-6 远小于噪声，会导致每次误报。
  5. 理论值 (1/2)^5=0.03125，真跑 0.031241。高维时目标密度集中在很小的典型集里，简单提议的候选几乎都落在低密度区被拒，接受率按维度指数下降，很快就无法在有限预算内收集到足够样本。
  6. 拒绝采样每次独立抽候选，被拒就重抽，留下的样本独立同分布；MCMC 被拒时留在原地，靠马尔可夫链探索，样本之间强相关。把连续样本当独立样本会严重低估标准误，必须丢弃预热期并监控有效样本量（ESS）。
