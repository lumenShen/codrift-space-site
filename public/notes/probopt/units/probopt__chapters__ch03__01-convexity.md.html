6.1 先看工程长什么样

前面五个单元讲的是概率与信息：用采样看期望，用似然看训练，用熵看损失。从这一单元起换赛道，讲最优化。最优化要回答的第一个问题不是「怎么走」，而是「走到的是不是最好的地方」。凸性就是对这个问题最有力的一族答案：如果目标函数是凸的，任何局部最优都是全局最优；如果还强凸，那个最优点唯一。

这一节的工程和前面同构：共用库继续放在 common/，本地例子 convex_probe/ 里放三个函数的定义与两个数值工具，驱动 main.c 负责打印。数字全部真编译真跑得到，清单用 mode=numerical 把六个黄金值钉住。

大白话先建立一个画面

把一元函数想成一条画在纸上的曲线。在这条曲线上任取两点，用直尺连一条线段（数学里叫弦）。如果曲线整段都躺在这条弦的下方，函数就是凸的；如果某一段鼓到弦的上方，它就不是凸的。这个画面看着朴素，但它等价于后面所有代数判据——一阶判据说切线在图下方，二阶判据说曲率非负，Jensen 说「先代入再平均」不大于「先平均再代入」。三句话说的是同一件事。

第 1 帧是本节开始时的空目录，第 2 帧是落盘后的四个新文件。带 + 的行才是这一节新增的；共用库不在其中，因为它在第 1 单元就已经立好。清单 sources 列 src/main.c、src/convex.c、../../common/src/probopt.c 三样，flags 里同时给 -Iinclude 与 -I../../common/include——前者找本地头文件，后者找共用库头文件。这里专门用到了共用库的 po_square_loss：平方函数不必自己写一遍，直接把「目标值是 2」传进去就好。这不是偷懒，而是在示范怎么把共用库当成可信的地基。

6.2 凸集：先把「形状」说清楚

凸性先有集合，后有函数。一个集合 C 叫凸集，如果任取两点 x,y ∈ C，它们之间连线上的每一点 t x + (1-t) y（0 ≤ t ≤ 1）也都在 C 里。换句话说，你在集合里随便挑两点、拉一条直线，整条线都不许跑出集合。实数轴上的区间是凸集；平面上的实心圆盘、实心三角形是凸集；月牙形、空心环、带缺口的方块都不是——在凹进去的地方连一条线，线段会穿过缺口。

为什么要先讲集合？因为后面谈「可行域」时，约束条件定义的往往是一个集合：线性不等式给出半空间，若干半空间交起来是凸多面体。如果可行域是凸的、目标函数也是凸的，那么整个问题叫凸优化问题，前面那句「局部最优即全局最优」才成立。少了任何一半，保证就没了。

第 2 帧与第 3 帧的对照是这一节的核心：判断凸集不看边界好不好看，只看「连线会不会跑出去」。第 3 帧的月牙在凹处缺了一块，连线中段掉进缺口，所以它不是凸集。这个判据可以直接拿去检查深度学习里的约束集合：比如「权重范数不超过 c」给出的是球，是凸集；「权重至多有 k 个非零」给出的是稀疏集合，不是凸集——取两个各非零在不同位置的向量，它们的平均就有 2k 个非零，跑出集合了。

工程惯例凸集的交还是凸集

两个凸集的交集一定是凸集：交集中的任意两点都在原来两个集合里，连线自然也都在两个集合里，于是留在交集里。这条性质很实用——一堆线性约束各自给出半空间（都是凸集），交起来仍然凸，所以线性约束不会破坏凸性。反过来，凸集的并集一般不凸：两个不相交的圆盘各自凸，并起来却不是，因为跨两个圆连的线穿过中间的空白。记住「交保凸、并不保凸」，你看约束条件时就能迅速判断问题的形状。

6.2.1 常见的凸集与它们怎么拼出来

把几个基本形状记牢，以后看约束条件就能秒判。第一类是区间与半空间：实数轴上的区间 [a,b] 是凸集，高维空间里由一个线性不等式 aᵀx ≤ b 定义的半空间也是凸集。第二类是范数球：{x : ‖x‖₂ ≤ r} 是凸集，这可以直接由三角不等式推出——若 ‖x‖≤r、‖y‖≤r，则 ‖tx+(1-t)y‖ ≤ t‖x‖+(1-t)‖y‖ ≤ r。第三类是凸集的仿射像：把凸集做线性变换再加平移，仍然是凸集，所以椭圆、平行四边形都凸。第四类是凸集的任意交，前面已经证明过。

要用这些积木搭出复杂可行域，最常见的方式是把若干半空间交起来，得到凸多面体。线性规划的可行域就是这样一块多面体；支持向量机的可行域也是半空间的交。反过来要警惕两类坑：一是「至多 k 个非零元素」定义的稀疏集合，它不是凸集——取两个非零位置不同的稀疏向量，它们的平均非零个数翻倍，跑出集合；二是整数约束，整数点的集合离散，连线段都谈不上，自然不是凸集。很多实际问题是「凸的连续部分 + 非凸的整数部分」，这时凸优化的保证只对松弛后的连续问题成立。

工程惯例从可行域形状预判算法难度

拿到一个优化问题，先别急着写梯度下降。先看约束：如果可行域是单纯形（概率分布那种「各分量非负且和为 1」的集合），投影梯度下降里的投影步有闭式解；如果可行域是一般的凸多面体，投影要解一个小二次规划，代价立刻上一个量级；如果约束里带整数或非凸等式，连「可行」都难判断。这就是凸性分析的实用价值——它不直接给算法，但告诉你哪些工具能用、哪一步会变贵。第 9 单元讲对偶时会再回到这个视角。

6.3 凸函数：弦在图上方

有了凸集，凸函数就顺理成章。设函数 f 的定义域是凸集，如果对任意两点 x,y 与任意 t∈[0,1] 都有

f(t x + (1-t) y) ≤ t f(x) + (1-t) f(y)

就称 f 是凸函数。左边是「先取两点的加权平均，再代入函数」；右边是「先分别算函数值，再按同样权重平均」。不等式说：前者永远不超过后者。画成图，左边的点是弦上那个位置的曲线高度，右边的点是弦的高度，所以这句话就是「曲线在弦下方」。

注意不等号方向。中文里「凸」字的形状容易让人以为曲线向上鼓，数学里凸函数恰恰是「向上开口的碗」：x²、eˣ、|x| 都是凸函数。 concave（凹函数）满足反方向的不等式，-x²、log x、sqrt(x) 是凹函数。一条直线既凸又凹，因为两边取等号。

第 2 帧用的正是本单元程序的 Jensen 例子：平方函数 f(x)=(x-2)²，取 a=-1、b=1，f(a)=9、f(b)=1，弦中点高度 (9+1)/2=5；曲线中点 x=0，f(0)=4。4 ≤ 5，凸性在这一对点上成立。程序打出的 jensen_gap_square:[1.000000] 就是这个差值 5-4。第 3 帧强调「一对点成立不够」：必须对定义域里任意两点都成立，才是凸函数。

陷阱别把「函数值非负」当成凸性

新手常拿 f(x) ≥ 0 当凸性的判据，因为常见凸函数都非负。反例随手就有：eˣ - 2x 在本例的最小值是 0.613706，确实非负；但 x - 1 是线性函数，在 x<1 时取负值，它既凸又凹。另一个方向：sin x 在部分区间取正值，却不是凸函数。你会被坑到的场景是写一个「检查凸性」的程序时只检查函数值符号——那和凸性毫无关系。正确的数值检查是逐对取点，比较弦中点与曲线中点，这正是本地函数 cv_midpoint_convex 干的事。

6.3.1 一份凸函数清单：哪些常见，哪些不常见

把常用函数按凸性归堆，比每次重新证明省事。凸的一族包括：仿射函数 aᵀx+b（既凸又凹）、平方与任意偶数次幂的正系数和、eˣ、范数 ‖x‖、最大值函数 maxᵢ xᵢ、以及 log(sum exp(xᵢ))（叫 log-sum-exp，是 max 的光滑近似）。凹的一族包括 log x（定义域正数）、sqrt(x)、负熵 Σ pᵢ log pᵢ（注意是正的 p log p，不是负的）。把凹函数取负就变成凸函数，所以正则化里常出现 -log det 这类凸的壁垒函数。

不凸的一族更要记牢：sin x 在整条实轴上既不凸也不凹；x³ 在负半轴凹、正半轴凸；神经网络里任何一个带非线性激活的隐层几乎都破坏凸性——即使每一层本身很温和，复合之后也未必凸。一个特别有用的复合规则是：若 f 凸且非减、g 凸，则 f∘g 凸；若 f 凸但递减、g 凹，复合也凸。正则化里的 exp(‖w‖) 就是「凸递增复合凸」的例子，而 log(1+exp(·)) 的复合要逐条检查单调性，不能凭感觉。

陷阱两个凸函数相加凸，相乘却不保证

你会很自然地把「凸 + 凸 = 凸」推广到「凸 × 凸 = 凸」。反例：f(x)=x、g(x)=-x 都是仿射（于是都凸），乘积 -x² 是凹函数。即使限制两个函数都取正值也救不回来：eˣ 与 e^{-x} 都凸，乘积恒为 1，既凸又凹，倒是没坏；但换 x² 与 1/x²（正半轴上前者凸、后者也凸），乘积恒为 1 也没坏。真正的反例藏在更一般的情况里，所以纪律是：只记住「非负权重求和保凸」与「凸集交保凸」，乘法和复合一律现推，不套用不存在的规律。

6.4 Jensen 不等式：一次平均换来一个方向

把凸函数定义里的两个点推广到多个点、再推广到概率分布，就得到 Jensen 不等式：若 f 凸、X 是随机变量，则

f(E[X]) ≤ E[f(X)]

写成大白话：先平均再代入，不大于先代入再平均。若 f 凹，不等号反向。这条不等式在概率论里出现频率极高，因为「期望」到处都是。

本单元的例子里，X 取 -1 与 1 各半，f(x)=(x-2)²。E[X]=0，所以 f(E[X])=f(0)=4；E[f(X)]=(9+1)/2=5。4 ≤ 5 成立，差值 1 就是程序打印的 Jensen 间隙。间隙越大，说明函数弯曲得越厉害；线性函数处处取等号，间隙恒为零。

Jensen 还有个特别好用的推论：对凸函数 f，E[f(X)] ≥ f(E[X]) 意味着「先算损失再平均」总是不小于「先平均再算损失」。在机器学习里，如果损失关于预测是凸的，那么「对一批样本求平均预测再算损失」会低估真实平均损失。这正是小批量训练有时表现得像隐式正则的一个角度，也提醒你：不要把平均预测当成平均损失的替代品。

工程惯例用 Jensen 证明最大值，不用求导

第 5 单元说过「固定格子数时，均匀分布熵最大」。当时用 KL 非负证明，这里再给一个 Jensen 版本：对数函数是凹的，所以对任意分布 p，Σ pᵢ log pᵢ ≤ log(Σ pᵢ · pᵢ) 看起来不太对劲？别急，正确的用法是取凹函数 log，令随机变量取值 1/pᵢ、概率 pᵢ，则 E[1/p] = Σ pᵢ (1/pᵢ) = K，Jensen 给 log(E[1/p]) ≥ E[log(1/p)]，即 log K ≥ -Σ pᵢ log pᵢ = H(p)。两种方法给出同一个上界 log K。会挑随机变量是使用 Jensen 的关键——这一步在教材里常被一笔带过，却是初学者卡住的地方。

6.5 一阶判据：切线在图的下方

凸函数还有两个等价说法，比定义更好用。先说一阶判据：可微函数 f 是凸的，当且仅当对任意 x,y 都有

f(y) ≥ f(x) + ∇f(x)ᵀ(y-x)

右边是 f 在点 x 处的切平面（一元函数就是切线）在 y 处的高度。整句话是「切平面永远不高于函数」。这个判据把凸性从「任意两点的弦」变成「任一点出发的切线」，验证时只要找一个点就能给出下界。

它在最优化里的价值极大：如果 x* 是凸函数的一个驻点（∇f(x*)=0），代入上式得到 f(y) ≥ f(x*) 对一切 y 成立——驻点就是全局最小点。这一步证明只用了一阶判据一行，却是整个凸优化最重要的结论。非凸函数没有这个性质：驻点可能是局部最小、局部最大，也可能是鞍点，光看梯度为零什么都说明不了。

第 2 帧的「低点」是切线的延伸，它低于曲线，所以任何点的函数值都不小于这个线性近似。第 3 帧是判据的 payoff：在 x=2 处切线水平，整条线高度为零，于是 f(y) ≥ 0 对所有 y 成立，而 f(2)=0，全局最小点找到了。程序打出的 argmin_square:[2.000000] 与 min_square=0.000000 正是这件事的数值版。

6.5.1 一阶判据为什么等价于凸性

两个方向都能证，各用一次「导数单调」。先证「凸 ⇒ 切线在下」。固定 x 与 y，定义 φ(t) = f(x + t(y-x))，这是沿着两点连线看的一元函数；凸性保证 φ 在区间 [0,1] 上凸。对凸的一元函数，差商 φ(t)/t 随 t 减小而单调不增（几何上：割线斜率越往右越大），于是 φ(1) ≥ φ'(0)，也就是 f(y) - f(x) ≥ ∇f(x)ᵀ(y-x)。这就是一阶判据。

再证反向。若对每个 x 都有切线在下，取两点 a、b 与权重 t，令 x = t a + (1-t) b。把切线判据分别用在 y=a 与 y=b 上，得到两个不等式：f(a) ≥ f(x) + ∇f(x)ᵀ(a-x) 与 f(b) ≥ f(x) + ∇f(x)ᵀ(b-x)。第一个乘 t、第二个乘 (1-t) 再相加，右端含梯度的项恰好是 ∇f(x)ᵀ[t(a-x)+(1-t)(b-x)] = ∇f(x)ᵀ(x-x) = 0，消掉了，剩下 t f(a) + (1-t) f(b) ≥ f(x)。这正是凸函数定义。两条合起来说明：一阶判据与凸性完全等价，不是充分条件也不是必要条件中的一个，而是同一个性质的两种写法。

这个证明里最值得学的是「把多元问题压到一条直线上」的技巧。凸性的定义本身就只涉及两点连线，所以任何关于凸性的证明都可以先降维到一元；反过来，一元函数如果导数单调不减，它在任意直线上的限制都凸，于是整体凸。以后看到 Hessian 半正定的证明，用的也是同一招——把 y-x 当作任意方向 d，考察 g(t)=f(x+td) 的二阶导数 dᵀ∇²f d。

6.6 二阶判据：曲率决定凹凸

若 f 二阶可微，一阶判据还能再简化：f 凸当且仅当其 Hessian 矩阵处处半正定；若 Hessian 处处正定，f 严格凸。一元函数里 Hessian 就是二阶导数 f''，判据退化成 f''(x) ≥ 0。几何解释是曲率非负——曲线不会向下弯。

把这条判据用在三个函数上，手算只要几行：

  • 平方函数 f(x)=(x-2)²，f'=2(x-2)，f''=2 > 0，处处严格凸；更进一步 f'' ≥ 2，所以它是强凸的。
  • 平移指数 f(x)=eˣ-2x，f'=eˣ-2，f''=eˣ > 0，处处严格凸；不过 eˣ 在 x→-∞ 时趋于零，二阶导数没有正的下界，所以它不是强凸的。
  • 四次函数 f(x)=x⁴-2x²，f'=4x³-4x，f''=12x²-4；当 |x| < 1/√3 ≈ 0.577 时二阶导数为负，所以它在原点附近是凹的，整体不是凸函数。

四次函数的驻点由 4x³-4x=0 给出，即 x=0, ±1。x=0 是局部最大，x=±1 是两个局部最小，函数值都是 -1。程序从区间 [0.2,2] 做二分，只会找到 x=1 这一个极小点——另一个在负半轴。这正是「非凸问题里算法只能找到一个局部解，换起点可能换答案」的最小示例。

第 2 帧里指数函数的驻点是 ln 2 ≈ 0.693147，因为 eˣ=2；极小值是 e^{ln2} - 2 ln2 = 2 - 2×0.693147 ≈ 0.613706。程序打出的 argmin_exp:[0.693147] 与 min_exp=0.613706 与之吻合。这组数是本单元的第二条证据链：手算与真跑相互印证。

陷阱数值凸性检查只是抽样，不是证明

cv_midpoint_convex 在区间里取 64 段、逐段比较弦中点与曲线中点。它返回的 1 只说明「这 64 对点上没发现反例」，不说明「对所有点对都凸」。四次函数之所以被判成 0，是因为抽样恰好撞进了 |x|<0.577 的凹区；若把区间改成 [1,2]，同一函数在那里其实是凸的，程序会返回 1。你会被坑到的场景是：拿这个工具检查一个只在极窄区间非凸的函数，采样步长跨过去，误以为全局凸。数值检查适合做演示和回归测试，严谨结论还得靠二阶导数的代数判断。

6.6.1 从泰勒展开读出 Hessian 判据

二阶判据的推导只需要泰勒公式带余项：f(x+d) = f(x) + ∇f(x)ᵀd + ½ dᵀ∇²f(x+ξd) d，其中 ξ 在 0 与 1 之间。如果 Hessian 在定义域内处处半正定，那么最后一项对任意 d 都非负，于是 f(x+d) ≥ f(x) + ∇f(x)ᵀd 对任意 x、d 成立，按上一节的等价关系，f 是凸函数。反过来若 f 凸且二阶可微，取一条直线 d 考察一元函数 g(t)=f(x+td)，凸性给出 g''(t) ≥ 0，而 g''(t)=dᵀ∇²f(x+td)d，让 d 遍历所有方向就得到 Hessian 半正定。

半正定对这个词值得说清楚：对称矩阵 H 半正定是指对所有向量 d 都有 dᵀHd ≥ 0，等价于它所有特征值非负。正定则要求严格大于零，等价于所有特征值为正。一元情形里 Hessian 退化成一个数 f''，特征值就是它自己，所以判据读起来特别简单。多元情形里特征值的大小差异直接决定碗的形状：所有特征值都大且接近，碗圆；有的特征值很小，碗在某方向很扁；有特征值为负，那个方向上是凹的，函数整体不凸。

这也解释了强凸与光滑怎么用矩阵语言表达：μ I ⪯ ∇²f ⪯ L I。左边是所有特征值至少 μ，右边是至多 L。条件数 κ=L/μ 就是最大特征值与最小特征值之比。第 7 单元要用的二次碗正是把 Hessian 取成对角矩阵 diag(0.5, 2)，两个特征值直接写在矩阵上，收敛条件可以逐维验证，不需要抽象的函数分析。

工程惯例数值上怎么检查 Hessian 半正定

真实项目里的 Hessian 往往没有解析式。常用做法有两种：一是用有限差分近似二阶导，对每个方向 d 算 (f(x+εd)-2f(x)+f(x-εd))/ε²，ε 取 1e-5 量级；二是只检查最小特征值是否非负，用幂迭代反求。本单元的例子刻意选了能手算二阶导的三个函数，就是为了让「判据」不被数值误差搅浑。若你真的拿有限差分去查四次函数在原点附近的值，会看到 f''(0)≈-4，符号清清楚楚，不会被容差吞掉。

6.6.2 严格凸与强凸不是一回事

再补一个常被混用的区分。严格凸是指定义里那道不等号在 x≠y、0<t<1 时严格成立；强凸则要求多出一个二次下界 μ/2‖y-x‖²。强凸必然严格凸，但严格凸未必强凸。f(x)=x⁴ 是标准反例：它在整条实轴上严格凸（f''=12x² 只在原点为零，其余为正），但 f''(0)=0，找不到统一的正下界 μ，所以不强凸。它在原点附近的曲率越来越小，下降算法走到那里会明显变慢。

这个区分在理论里很重要。严格凸最多能保证最优点唯一（如果存在），但不能给出收敛速率；强凸才能给出 (1-μ/L)^k 这样的线性收敛保证。本例的平方函数既是严格凸又是强凸，是最省心的情形；平移指数函数严格凸但不强凸；四次函数在整条实轴上连凸都不是，自然谈不上强凸。三个例子刚好覆盖了三档，读输出时可以把它们当成一张「凸性谱系表」。

陷阱在有限区间上强凸，不等于全局强凸

指数平移函数在 [-5,5] 上二阶导数最小是 e^{-5}≈0.0067，于是在这个区间里它是强凸的，μ 可以取 0.0067。但换成整个实数轴，eˣ 可以任意接近零，μ 不存在。你会被坑到的场景是：在训练集观察到的曲率范围里证明了收敛，换到测试分布上输入变大，突然不收敛了。理论结论里的「在整个定义域上」这几个字不能省，实际建模时要检查输入范围是否真的有界。

6.7 二分求最小：为什么导数变号就够了

程序里求最小用的是二分法，而不是梯度下降。原因是这一单元的主角是凸性，二分法把「导数单调」这件事用得最直接：若 f 凸且可微，则 f' 单调不减；在区间 [lo,hi] 上若 f'(lo)<0 且 f'(hi)>0，唯一的驻点就在其中。每次取中点 m，看 f'(lo) 与 f'(m) 是否异号：是就把右端收到 m，不是就把左端收到 m。80 次之后区间长度缩到原来的 2^-80，远小于 double 的分辨率。

这段代码值得逐行看。df(lo) * df(m) <= 0.0 判断的是「左端与中点是否夹住了零点」；凸性保证导数只穿过零点一次，所以这个判断不会漏掉别的根。它没有学习率、没有动量、没有迭代次数调参——这正是凸性带来的奢侈。对非凸的四次函数，我们从 [0.2,2] 出发只能找到 x=1；若从 [-2,-0.2] 出发会找到 x=-1。换区间换答案，这是非凸问题的常态。

6.8 强凸：唯一性与收敛速度

普通凸函数只能保证「最优点构成一个凸集」，可能有一整片平坦的最优解：函数 f(x)=max(x-1,0) 在 x≤1 处全都取零，都是全局最小。强凸把这个口子收紧。若存在 μ>0 使得

f(y) ≥ f(x) + ∇f(x)ᵀ(y-x) + (μ/2) ‖y-x‖²

对所有 x,y 成立，就称 f 是 μ-强凸的。多出来的二次项像一只手，把函数从切平面往上顶开，于是最优点不可能成片——假设 x₁,x₂ 都是最小点，把其中一个代入另一个的不等式会得到 f(x₂) ≥ f(x₁) + (μ/2)‖x₂-x₁‖²，左边等于右边第一项，只能推出距离为零，即两点相同。

强凸还带来收敛速度。若 f 是 L-光滑（梯度 Lipschitz，等价于 ∇²f ⪯ L I）且 μ-强凸，梯度下降以固定步长 1/L 迭代时，函数值 gap 按 (1 - μ/L)^k 线性下降。比值 κ = L/μ 叫条件数：κ 越接近 1，碗越圆，下降越快；κ 越大，碗越扁，下降越慢。本例的平方函数 f''=2 处处成立，所以 L=μ=2、κ=1，是最理想的圆形碗；指数函数 f''=eˣ 没有正下界，μ=0，不是强凸，收敛保证就弱一档。

工程惯例条件数在深度学习里为什么重要

线性最小二乘、逻辑回归这类凸问题的条件数可能非常大：特征尺度差几个数量级时，Hessian 的最大特征值与最小特征值相差悬殊，梯度下降在陡的方向来回震荡、在平的方向几乎不动。解决手段不是换优化器那么简单——标准化输入特征往往比调学习率有效得多，因为它直接改善条件数。第 7 单元会在二次碗上把这件事做成可见的数字，第 8 单元的 Adam 则可以被理解为对每个方向的曲率做粗略归一化。

6.8.1 L-光滑：给曲率装上天花板

强凸给曲率装了地板 μ，还需要一个天花板才能谈稳定性。若存在 L>0 使得 ‖∇f(x)-∇f(y)‖ ≤ L‖x-y‖ 对所有 x、y 成立，就称 f 是 L-光滑的。对二阶可微函数，这等价于 ∇²f ⪯ L I，也就是所有特征值不超过 L。直观上：梯度变化得有多快有个上限，所以你敢迈步——步长太大时梯度会在两端剧变，算法震荡；知道 L 之后，取步长不超过 1/L 就能保证每步让函数值下降。

配套的下降引理是：f(x - (1/L)∇f(x)) ≤ f(x) - (1/(2L))‖∇f(x)‖²。它说只要步长合乎 L，梯度不为零就一定有正的函数值下降量，而且下降量与梯度平方成正比。把这条引理与强凸性结合，就能推出上一节那句 (1-μ/L)^k 的线性收敛率。注意这不是「凸函数自动有」的性质：|x| 在原点不可导，更谈不上 L-光滑；逻辑回归的 logistic loss 二阶导数上界是 ¼‖X‖²，数据矩阵的谱范数直接决定 L——又回到条件数。

实验记录拿本例的两个函数核对 L 与 μ

平方函数 f''=2 处处成立，所以 L=2、μ=2，κ=1，步长取 0.5 一步就能到最低点（从任意起点，w - 0.5·2(w-2)=2）。指数平移函数 f''=eˣ 在区间 [-5,5] 上的最大值是 e⁵≈148.4，所以在这个区间内可以取 L≈148.4，但它在整个实数轴上没有上界，全局 L 不存在；同时 eˣ→0，全局 μ=0。这解释了为什么程序对指数函数用二分而不是梯度下降：没有全局 L 与 μ，就没有任何固定的安全步长能保证一路收敛。

工程惯例把三行极小值连起来读

6.10 凸不等于好优化，非凸不等于没救

「凸问题保证全局最优」是真的，但常被误读成「凸问题一定容易」。有一类凸函数形状极其扁平：Hessian 的最小特征值接近零，条件数巨大。此时梯度很小却离最优点很远，算法要走很多步；或者梯度在窄谷两侧陡变，步长稍大就震荡。L1 正则化的目标函数还是非光滑的，|w| 在零点不可导，标准的梯度下降不能直接套用，需要次梯度或近端算子。所以凸性给的是定性保证，不是定量免费午餐。

反过来，非凸问题也不是一片荒原。深度神经网络的损失函数高度非凸，理论上充满局部极小与鞍点；但实践中一大类局部极小点的损失值彼此接近，而且过参数化让很多鞍点变成可逃离的平坦方向。真正让训练失败的往往不是「陷在坏局部最优」，而是梯度爆炸、梯度消失、学习率失配。这不是说可以不讲凸性——恰恰相反：凸问题是我们的理论实验室，在碗里能严格证明的东西（步长条件、线性收敛）给了非凸世界一套可迁移的直觉，第 7 单元就从这个碗开始。

  5. 成立：一阶判据代入驻点得 f(y) ≥ f(x*)。不强凸时最优点可以不唯一，例如 max(x-1,0) 在整个 x≤1 区间取零，最优点成一片，但每个都是全局最小。
