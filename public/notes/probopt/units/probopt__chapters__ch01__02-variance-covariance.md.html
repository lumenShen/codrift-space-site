2.1 先看工程长什么样

这一单元沿用上一单元的采样与对账流程，只把统计量从一阶矩换成二阶矩。共用库 common/ 依旧一个字不改：po_variance 与 po_covariance 已经在里面，我们用它们做真跑，再自己手算一遍做独立核对。新例子叫 cov_probe，它用固定种子造出两组人为相关的正态样本，外加一组「不相关但强依赖」的样本，一次性把三种情形摆在屏幕上。

大白话先建立一个画面

均值告诉你分布的重心，方差告诉你数据绕着重心散得多开。这两个数都只描述一个变量。一旦问「两个量一起怎么变」，就需要协方差：它为正时，一个变大另一个也倾向变大；为负时，一个变大另一个倾向变小；接近零时，两者没有线性上的同步倾向。注意最后一句里「线性」两个字——协方差只捕捉线性关系，这是它最大的局限，也是这一单元最值得记住的陷阱。

第 1 帧把上一节的 expect_mc/ 带进来作为起点——注意它标了 +，意思是「在那一节里它是新增的」，这一步只是交代故事起点。第 2 帧里新增的是 cov_probe/ 四个文件。两份例子并列在 examples/ch01/ 下，共用同一份 common/ 库；切换单元只需换清单的 sources，不需要搬动任何公共代码。这就是「一个例子一个目录、一个清单」的目录纪律。

2.2 方差：把「散」压成一个数

方差的定义是 Var(X) = E[(X − E[X])²]。先把每个样本与均值的差算出来，平方（抹掉正负号），再取期望。平方有两个作用：一是让正负偏差不互相抵消，二是让大偏差被更重地惩罚——离均值远的地方贡献按平方增长。开方之后得到标准差 σ = √Var(X)，它把量纲还原回原变量的单位。均值是米，方差是平方米，标准差又是米；这就是为什么报表里更常写标准差而不是方差。

手算两个熟悉的例子。均匀分布 [0,1)：E[X]=1/2、E[X²]=1/3，于是 Var(X)=1/3−1/4=1/12≈0.083333、σ≈0.288675。伯努利 p=0.3：因为 x²=x 对 0/1 成立，E[X²]=E[X]=0.3，于是 Var(X)=0.3−0.09=0.21、σ≈0.458258。你会在真跑里看到 var_x≈1，因为程序造的 x 是标准正态，方差理论值恰好是 1；std_x≈1 就是它的平方根。

第 1 帧先钉住均值 2；第 2 帧的三个偏差 -1,0,1 加起来是 0，说明「偏差之和」本身没有信息——正负会抵消；第 3 帧平方后得到 1,0,1，平均是 2/3。注意这里分母用了 3（总体方差的定义），样本方差常用 n−1，2.8 节专门讲这个区别。图里三帧各自自包含，第 3 帧仍然写出了均值和偏差节点，单独打印也能读懂。

陷阱把方差当成「平均偏差」

你会想：方差不就是「平均偏离均值多少」吗？于是把每个样本到均值的差直接平均。结果是 0——正负抵消了。你可能会改用绝对值的平均，那叫平均绝对偏差，也是一个合理的离散度指标，但它的数学性质远不如方差好：绝对值在 0 点不可导，做优化时没有干净的梯度；方差是二次函数，处处可导，还能和最小二乘、二次型、正态密度写成同一个框架。深度学习里几乎处处用方差和平方损失，不是因为绝对值不好，而是因为平方在代数上好用得多。

2.3 协方差：两个量一起变的方向

协方差的定义是 Cov(X,Y) = E[(X−E[X])(Y−E[Y])]。它把两个偏差相乘再取期望。如果 X 大于均值时 Y 也倾向于大于均值，两个偏差同号，乘积为正，协方差为正；如果 X 大时 Y 倾向小，偏差异号，乘积为负，协方差为负；如果两者没有同步倾向，正负乘积大致抵消，协方差接近零。符号就是方向，大小则受量纲影响——这是下一节要修正的地方。

程序里 y = 0.6x + 0.8ε₁、z = −0.6x + 0.8ε₂，其中 x、ε₁、ε₂ 都是独立标准正态。按期望的线性性，Cov(x,y) = 0.6Var(x) = 0.6，Cov(x,z) = −0.6Var(x) = −0.6。噪声项与 x 独立，贡献的协方差是零；系数 0.8 只影响 y、z 自身的方差，不影响与 x 的协方差。这个构造让你能在真跑之前就把答案算出来，然后拿程序验证——这才是可核对的实验，而不是看运气。

第 1 帧的两个样本都落在「同向」象限，乘积全正；第 2 帧都落在「反向」象限，乘积全负；第 3 帧特意画的是 x 与 x²——x 偏离均值时 x² 的偏差并不跟着线性地变大或变小，乘积正负抵消，协方差接近零。但 x² 显然完全由 x 决定！这张图把「不相关不等于独立」这件事提前摆在了眼前。

实验记录心算协方差的真值

用期望的线性性展开：Cov(x, 0.6x + 0.8ε) = 0.6Cov(x,x) + 0.8Cov(x,ε) = 0.6Var(x) + 0 = 0.6，因为 x 与 ε 独立且 Var(x)=1。同理 Cov(x, −0.6x + 0.8ε) = −0.6。真跑给出 cov_xy=0.589981、cov_xz=−0.608491，都在理论值附近，偏差约一个到两个标准误。注意符号完全符合直觉：正相关的 y 给出正协方差，负相关的 z 给出负协方差。

2.4 相关系数：把量纲约掉

协方差有量纲。把身高的单位从米改成厘米，涉及身高的协方差会放大 100 倍，但两个变量的关系强度当然没变。相关系数定义为 ρ = Cov(X,Y)/(σₓσᵧ)，把两个标准差除掉，得到一个无量纲的数。它满足 −1 ≤ ρ ≤ 1，这个界限来自柯西—施瓦茨不等式：|Cov(X,Y)| ≤ σₓσᵧ。等号成立当且仅当 Y 是 X 的线性函数（几乎处处），所以 ρ=1 意味着完全正线性相关，ρ=−1 意味着完全负线性相关。

程序里 y = 0.6x + 0.8ε，Var(y) = 0.36 + 0.64 = 1，所以 ρ = 0.6/(1×1) = 0.6。真跑给出 corr_xy=0.591904，与理论值吻合。 而 corr_xz=−0.603514，对应理论值 −0.6。两个相关系数大小接近、符号相反，正好展示「去掉量纲后，剩下的就是纯粹的线性同步程度」。

这一帧里 std_y 的真值没有在 stdout 里直接打印，但可以由 var_y=0.989167 开方得到约 0.994569。图元里的数字不是凭空写的，每一个都能从真实输出推出。这也提醒你：相关系数不是独立算出来的第三个统计量，它是协方差除以两个标准差的派生量——一旦前三者算错，ρ 会跟着错。

陷阱相关系数高不等于「有关系」

你会看到 corr_sq≈−0.04，于是断定 x 与 x² 几乎无关。大错特错：x² 完全由 x 决定，它们是函数关系，只是不是线性关系。相关系数只度量线性同步程度，对抛物线、正弦、周期性这类非线性关系几乎无能为力。真实数据里这种坑到处都是：某段时间里两个指标的相关系数接近零，不代表它们没有因果关系，可能只是关系是弯的。判断有没有关系，要画散点图、要看互信息，不能只看一个 ρ。

2.6 协方差矩阵为什么半正定

把多个随机变量的协方差排成矩阵：Σᵢⱼ = Cov(Xᵢ, Xⱼ)。对角线上是各变量的方差，非对角线上是两两协方差。这个矩阵有一个重要性质：对任意实向量 a，二次型 aᵀΣa ≥ 0。原因很直接——aᵀΣa = Var(a₁X₁ + ⋯ + aₖXₖ)，而方差永远非负。这叫半正定，与线性代数分册里讲的二次型、特征值判据完全呼应：半正定矩阵的所有特征值非负，可以写成 BᵀB 的形式。

半正定不是「正定」：允许等于零。什么时候取零？当 aᵀX 几乎是常数时——比如两个变量完全线性相关，X₂ = 2X₁，取 a=(2,−1) 就有 aᵀX=0 恒成立，方差为零。这解释了为什么协方差矩阵在变量共线时不可逆：行列式为零，逆矩阵不存在。工程上做白化、马氏距离、高斯判别分析时都会遇到这个坑，解决办法是加一个小扰动（收缩估计）或先做主成分分析去掉共线方向。

三帧从矩阵出发，到线性组合，再到非负结论。这个推理只用了一条事实：方差非负。它的价值在于把统计概念和线性代数接起来——你在线代里学的「半正定 iff 所有二次型非负」，在这里有了一个统计解释。以后看到别人说「协方差矩阵半正定」，你脑子里应该立刻出现「任意线性组合的方差非负」这句话，而不是一条需要背的矩阵判据。

工程惯例半正定在工程里意味着什么

训练神经网络时，梯度协方差矩阵常常接近奇异——不同参数的变化方向高度相关。优化器要估计这个矩阵的逆（自然梯度、二阶方法），就会遇到数值不稳定。实践里加一个阻尼项 Σ + λI，把它推离奇异点，这正是「半正定但不正定」的直接后果。理解协方差矩阵的结构，你才知道这个 λ 不是随手加的魔法数字，而是在处理共线方向。

2.7 独立与不相关：一道很容易踩空的缝

独立是强条件：对所有可能的取值组合，联合概率等于边缘概率的乘积。不相关是弱条件：只要求协方差为零。独立一定推出不相关（因为独立时 E[XY]=E[X]E[Y]，协方差为零），但不相关推不出独立——我们程序里的 x 与 x² 就是活生生的反例：后者完全由前者决定，独立无从谈起，协方差却近似为零。

还有一个经典反例更干脆。取 X 为 [−1,1] 上的均匀变量，Y = X²。两者显然不独立，但 Cov(X,Y) = E[X³] − E[X]E[X²] = 0 − 0 = 0，因为 X³ 是奇函数、对称区间积分为零。两个反例都说明同一件事：协方差只看到线性关系，独立要求所有函数关系都没有。把「不相关」当成「没关系」是这一节最容易犯的错。

陷阱把「协方差为零」当成「可以丢掉这个变量」

你会觉得 corr_sq≈0，于是特征选择时把 x² 丢掉，理由是「和 x 没关系」。这是灾难性的：x² 完全由 x 决定，丢不丢取决于你的模型能不能自己构造这个非线性特征。线性模型丢掉它就真的丢了信息，因为线性模型只能利用线性关系。相关性分析只能告诉你线性依赖；做特征选择时，对非线性关系要用互信息、距离相关这类能捕捉弯曲关系的指标。

2.8 样本方差的分母：n 还是 n−1

共用库的 po_variance 分母用的是 n，不是 n−1。这叫有偏样本方差：它的期望是 ((n−1)/n)σ²，系统性偏小一点。统计教材里常用 n−1（贝塞尔校正），让估计量无偏。为什么库里用 n？因为机器学习里我们关心的是「这批数据自身的离散程度」以及「最大似然估计」，两者都用 n；而且当 n=5000 时，(n−1)/n = 0.9998，差别小到远小于采样噪声。

这个选择不是随便的。如果用 n−1，样本协方差矩阵就不再等于最大似然估计；在高斯分布的参数估计里，MLE 的方差分母正是 n。深度学习里所有批归一化层算的批方差也用 n——它统计的是这一批数据的经验分布，不是对总体方差做无偏推断。分清这两种语境，你才不会在面对「为什么这里除以 n 而不是 n−1」时愣住。

工程惯例什么时候必须换成 n−1

做统计推断，比如用样本方差构造总体方差的置信区间、做 t 检验、估计线性回归的误差方差时，要用 n−1，否则推断会有系统偏差。做机器学习里的经验风险最小化、批归一化、协方差矩阵估计时，通常用 n。本书的例子都属于后者。两种分母带来的差异是 O(1/n)，样本量一大就忽略不计；真正的差别在「你在估计什么」这个语义上，而不在那一点数值。

2.9 数值陷阱：大数相消与量级失衡

样本方差的实现有个经典写法问题。直接用 E[X²] − (E[X])² 算，当均值很大而方差很小时，两项都很大且非常接近，相减会吃掉有效位——这就是灾难性相消。共用库采用的是两遍法：先算均值，再累加 (xᵢ−μ)²。它多遍历一次数据，但数值稳定得多。代价只是多一次循环，在这个量级完全无所谓。

协方差还有量级问题。如果 x 的量级是 1e6 而 y 的量级是 1e−6，它们的协方差可能是 1 这种不大不小的数，但直接乘 (xᵢ−μₓ)(yᵢ−μᵧ) 时两项相差 12 个数量级，浮点乘法的舍入误差占比会明显上升。工程上的办法是先各自标准化再算相关系数，等价于把量级问题从协方差挪到标准差里。这也是相关系数比原始协方差更常用的原因之一——它不仅去掉单位，还顺带改善了数值条件。

实验记录用这次真跑核对两种算法

两遍法给出的 var_x=1.004394；一遍法用 E[X²]−(E[X])² 算，结果应该在小数点后第六位一致或差一个 ulp，因为 x 的均值接近零、方差接近一，不存在相消。你可以改一份临时程序对比：把标准正态整体加上 1e8，两遍法仍给出约 1，一遍法会因为相消出现明显误差甚至负数。这个对照不需要进正文清单，自己跑一次就能对「数值稳定」有体感。

2.10 与深度学习的对应：协方差漂移与归一化

训练神经网络时，各层激活的分布会随参数更新而变化，这叫内部协变量偏移。批归一化做的事，本质上就是拿当前批的均值和方差把激活标准化，让后续层看到的分布稳定下来。你在本节手算的 μ 和 σ，正是批归一化每一步在算的东西。它用的是批内经验方差（分母 n），与本例一致。

更深层的问题是协方差漂移：不仅每个特征的均值方差在变，特征之间的相关结构也在变。这正是为什么有些归一化方法（比如白化、 decorrelated batch normalization）要处理整个协方差矩阵而不只是逐维方差。矩阵半正定的性质保证了白化变换在理论上是可行的，但共线方向会让逆矩阵数值爆炸——2.6 节讲的阻尼在这里就得派上用场。把这条线接起来，你就明白协方差不只是一个描述统计量，它直接决定了训练稳不稳。

陷阱别把批归一化当成「让数据独立」

标准化之后，各维的均值和方差被固定住，但特征之间的相关性仍然存在。批归一化没有改变相关结构，它只对每一维单独做平移缩放。要去掉相关性得做白化，那是乘一个矩阵，成本和风险都高得多。把「归一化」等同于「去相关」是常见的误解，根源是只看了方差没看协方差。

2.11 手算核对：把三组数算到底

第一组是 x 与 y。Var(x)=1，Var(y)=0.6²×1+0.8²×1=1，Cov(x,y)=0.6，ρ=0.6/√(1×1)=0.6。真跑 corr_xy=0.591904，偏差约 −0.008，在采样噪声范围内。

第二组是 x 与 z。Cov(x,z)=−0.6，Var(z)=1，ρ=−0.6。真跑 corr_xz=−0.603514，同样吻合。注意两组的方差一样、相关系数大小一样，唯一的区别是符号——这正说明符号携带的信息是「方向」，而不是「强度」。

第三组是 x 与 sq=x²。对标准正态，E[x]=0、E[x³]=0，所以 Cov(x,x²)=E[x³]−E[x]E[x²]=0。真跑得到 −0.061169，离零有几个标准误（样本三阶矩的标准误约 √15/√5000≈0.055），属于正常波动。这组数最值得记住：一个精确的零相关，配上一个完全确定的函数关系——统计量的局限在这里暴露得清清楚楚。

2.12 这一节新增了什么，下一节要什么

回到 2.1 的第 2 帧：这一节新增的是 cov_probe/ 四个文件，共用库没有改动，上一单元的例子原样留着。真正的新知识是二阶矩：方差度量单变量的离散度，协方差度量两变量的线性同步，相关系数把量纲约掉，协方差矩阵把多个变量的一次性关系打包成一个半正定矩阵。你还看到了两个边界：线性相关不等于任何关系，零协方差不等于独立。

下一单元问一个更实际的问题：采样均值为什么会收敛，它的误差长什么样？大数定律回答「收敛到哪」，中心极限定理回答「收敛多快、误差分布是什么」。你会看到本节的方差直接出现在 CLT 的 σ/√n 里——方差在这里从描述统计量升级为决定估计精度的核心参数。

2.13 协方差的代数性质：常数、缩放与和的展开

协方差有几条非常好用的代数性质，值得单独过一遍。第一条：与常数协方差为零，Cov(X,c)=0，因为常数没有波动。第二条：齐次性，Cov(aX,bY)=ab·Cov(X,Y)，把两个变量分别缩放，协方差按乘积缩放。第三条：对加法可分配，Cov(X+Y,Z)=Cov(X,Z)+Cov(Y,Z)。这三条合起来说明协方差是双线性的——和点积一样，对两个参数分别线性。线性代数分册里讲的双线性在这里又出现了一次，不是巧合：协方差本质上就是一种内积，只不过作用在「去掉均值后的随机变量」这个向量空间上。

把齐次性用到相关系数上，能看出它为什么对缩放不变。把 X 乘 a、Y 乘 b（假设 a,b>0），协方差变成 ab·Cov(X,Y)，两个标准差分别变成 aσₓ、bσᵧ，比值完全不变。这正是 2.4 节说的「去掉量纲」。如果 a 或 b 是负数，相关系数的符号会翻过来——这提醒你，对变量取负号不只是改单位，它颠倒了方向。数据预处理里把某个特征反向编码（比如把「失败次数」改成「成功次数」），相关系数的符号会跟着变，解释时要小心。

工程惯例双线性为什么让方差展开变得轻松

由双线性立刻得到 Var(X+Y)=Var(X)+Var(Y)+2Cov(X,Y)。这条公式是投资组合风险分析的基础：两支股票的收益方差不仅取决于各自波动，还取决于它们之间的协方差。若两者负相关，组合风险可能远小于各自风险之和——这就是分散投资的理论依据。深度学习里把两个独立噪声源的方差相加，用的也是这条公式在 Cov=0 时的特例。记住「方差展开多出一个两倍协方差」，你就不会在推导里漏掉那个 2。

2.14 从协方差到条件：相关性怎样影响预测

协方差还有一个实际用途：它决定了用一个变量预测另一个变量时能做得有多好。如果我们只能用 X 的线性函数 a+bX 去预测 Y，最小均方误差的系数是 b = Cov(X,Y)/Var(X)，剩余误差是 Var(Y)(1−ρ²)。相关系数越接近 1 或 −1，剩余误差越小；ρ=0 时线性预测毫无帮助，最佳预测就是常数 E[Y]。这个结论把 ρ 从一个描述统计量升级为「线性可预测程度」的指标。

用本例的数字验一下。Cov(x,y)=0.6、Var(x)=1，所以最佳线性预测是 ŷ=0.6x，剩余方差 Var(y)(1−0.6²)=1×0.64=0.64——正好是噪声项 0.8ε 的方差。这不是巧合：y 本来就是 0.6x+0.8ε，最小二乘把可解释的 0.6x 全部拿走，只剩噪声。对 z 同理，最佳系数是 −0.6。这条计算让你从生成公式直接读出回归系数，反过来也说明：看到回归系数 0.6，你可以推测生成过程里可能有类似的结构。

陷阱线性可预测不等于因果

ŷ=0.6x 说明知道 x 有助于预测 y，但不说明 x 导致了 y。程序里确实是 x 生成 y，可现实中两个变量的相关可能来自共同的第三个因素：夏天冰淇淋销量和溺水人数正相关，不是因为吃冰淇淋导致溺水，而是气温这个隐藏变量同时推高两者。相关系数不能区分直接因果、共同原因和纯巧合。要做因果推断，需要额外的结构假设或干预数据，不是靠协方差矩阵能解决的。

2.15 二维高斯的几何：协方差决定椭圆的形状

如果 (X,Y) 服从二维高斯分布，协方差矩阵完全决定了等密度线的形状。矩阵的特征值是两个主轴方向的方差，特征向量给出主轴的方向；等密度线是一个椭圆，长轴沿着方差大的方向。对角线上方差相等、非对角线上协方差为零时，椭圆退化成圆；协方差为正时椭圆沿右上—左下方向拉长，为负时沿左上—右下方向拉长。你在本节看到的 corr_xy≈0.59 对应的就是一枚向右上倾斜的椭圆。

这个几何图像解释了很多工程现象。高维高斯采样时，如果协方差矩阵有某个极小特征值，分布就沿着对应方向压得很扁，采样几乎只在一个低维子空间里活动——这正是生成模型里「模式坍缩」的一种表现。把协方差矩阵的特征值谱打印出来，往往比看相关系数矩阵更快发现共线问题。本节的 2×2 情形肉眼就能看出来，高维情形就得靠谱分析。

实验记录用特征值复核本例的椭圆

本例的矩阵约是 [[1.004, 0.590],[0.590, 0.989]]。它的迹约 1.993，行列式约 1.004×0.989−0.590²≈0.650，两个特征值之和等于迹、之积等于行列式，解出约 1.593 与 0.400。大特征值是小特征值的四倍，椭圆明显拉长；长轴方向对应向量约 (1,1) 的方向，与正相关的直觉一致。你可以用任意线性代数工具算一遍，核对这组数——它完全由 stdout 的四个数推出，不需要重新采样。

2.16 把三个量级分开：方差、标准误、置信范围

这一节出现了三个容易混淆的量级，值得最后理一遍。方差 Var(X) 描述单个观测值的离散程度，本例约 1。样本均值的方差 Var(X̄)=Var(X)/n 描述均值估计的波动，本例 n=5000，所以约 0.0002。标准误是后者的平方根，约 0.0141，用来给估计值画出「大约多准」的范围。三者相差一个 √n 的因子，含义完全不同：把单个样本的标准差当成均值的标准误，会让你以为估计 precision 很差；反过来把均值的标准误当成单样本的波动，会让你以为数据非常集中。

下一单元会把这条区分讲透：大数定律保证均值收敛，中心极限定理给出均值误差的分布形状。你现在只要记住，本例的 var_x≈1 是「单个人有多散」，而第 3 单元的 var_of_means≈0.002 是「批次均值有多散」——两者不是同一个统计量，分母和抽样单位都不同。

2.17 常见误解清单：把话说明白

最后把这一单元最容易说错的三句话纠正一遍，免得它们在后续推导里埋雷。第一句「方差越大风险越大」——只在均值相同、分布形状相近时才成立。两个投资组合均值不同，单纯比方差没有意义；实际金融里用的夏普比率把超额收益和波动放在一起比较。第二句「相关系数为零说明两个变量没关系」——只说明没有线性关系，抛物线、周期、分段关系都可能藏在那里，我们程序里的 x 与 x² 就是证明。第三句「协方差矩阵的对角线是标准差」——对角线是方差，标准差要对角线开方，两者的量纲差一个平方。

还有一句值得单独说：「协方差为负是坏事」。不对。负相关在组合里往往是好事，因为它让整体波动互相抵消。本例的 x 与 z 强负相关，如果你构造 x+z，噪声几乎抵消，结果非常稳定。真正危险的是多个变量同时高度正相关——它们会一起向同一个方向偏离，没有任何缓冲。理解这一点，你就能明白为什么分散投资要挑负相关的资产，而不是挑单个方差最小的资产。

工程惯例用一个小实验确认负相关的缓冲作用

取本例的 x 与 z，按 Cov(x,z)≈−0.6、Var(x)≈Var(z)≈1 算 Var(x+z)=1+1+2×(−0.6)≈0.8。相比 Var(2x)=4，把两个反向变量加起来，波动从 4 降到 0.8，下降五倍。这正是负相关提供的缓冲。如果你把 z 换成 y（正相关 0.6），Var(x+y)≈3.2，只比 4 略小。两个组合的均值相同，风险差四倍——这就是协方差的符号在实际决策里的价值。

2.19 把这一节的数字再核对一遍

最后用一条链把 stdout 里的九个数串起来，确认它们不是各算各的。std_x 应当是 var_x 的平方根：√1.004394≈1.002195，与打印一致。corr_xy 应当是 cov_xy 除以 std_x 与 var_y 的平方根：0.589981/(1.002195×√0.989167)≈0.589981/(1.002195×0.994569)≈0.591904，与打印一致。同理 corr_xz≈−0.603514、corr_sq≈−0.042765 都能从协方差与两个标准差重算出来。九个数字里真正独立算出来的只有四个——方差三个、协方差三个，其余都是派生量。

这条链给你一个通用的核对办法：拿到任何统计输出，先找出哪些量是原始估计、哪些是派生量，再用公式重算派生量。如果重算结果与打印不符，问题一定出在派生步骤；如果全部吻合而数值本身可疑，问题在原始估计或数据生成。本例的原始数据来自固定种子，派生公式来自统计定义，两条都独立可查——这就是「可核对实验」的含义。

小结这一节的要点
  • Var(X)=E[(X−E[X])²]，标准差是它的平方根，量纲回到原变量；
  • Cov(X,Y) 的符号表示线性同步方向，ρ=Cov/(σₓσᵧ) 去掉量纲并落在 [-1,1]；
  • 协方差矩阵半正定，因为任意线性组合的方差非负；共线时奇异，工程上要加阻尼；
  • 独立必不相关，不相关未必独立；x 与 x² 是零协方差但强依赖的反例；
  • 样本方差分母 n 与 n−1 的选择取决于「描述经验分布」还是「无偏推断总体」。

注自测题答案
  1. 方差的量纲是原变量单位的平方，标准差与原变量同单位。标准差能直接和均值、原始观测比较，读起来直观；方差则在代数上更好用。
  2. E[X]=0.3，E[X²]=0.3（因为 0²=0、1²=1），Var=0.3−0.09=0.21，σ=√0.21≈0.458258。0/1 变量满足 x²=x，所以两个期望相同。
  3. 协方差为正表示一个变量高于均值时另一个也倾向高于均值，例如身高与体重；为负表示一个高时另一个倾向低，例如海拔与气温。这里说的是线性同步倾向，不是因果。
  4. 除以标准差把量纲约掉，让不同单位的数据可以比较相关强度；取值范围 [-1,1] 由柯西—施瓦茨不等式 |Cov(X,Y)|≤σₓσᵧ 保证，等号对应几乎处处的线性关系。
  5. x² 完全由 x 决定，所以二者绝不独立；但标准正态是对称分布，E[x³]=0 且 E[x]=0，故 Cov(x,x²)=0−0=0。协方差只看线性关系，看不出平方这种弯曲依赖。
  6. 对任意向量 a，aᵀΣa=Var(aᵀX)≥0，因为方差非负，故半正定。当存在非零 a 使 aᵀX 几乎恒为常数时取等，例如两变量完全线性相关，此时矩阵奇异、不是正定。
  7. 做经验分布描述、最大似然估计、批归一化时用 n 是对的；做总体方差的无偏推断、构造置信区间、t 检验时必须用 n−1 做贝塞尔校正。
