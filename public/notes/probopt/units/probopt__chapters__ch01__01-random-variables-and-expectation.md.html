1.1 先看工程长什么样

概率、信息论与最优化这一册不装科学计算库。我们先用 C 把最小的一套概率原语写出来：固定种子的随机源、几种常见分布、均值方差协方差、熵与似然。理由和前面几册一样——这一册要证明的不是「会不会调现成的库」，而是每个数字从哪来、对不对。共用库 common/ 已经把这些原语放在 probopt.h / probopt.c 里，每个新例子只负责提供驱动和清单，共用库一个字都不改。

大白话先建立一个画面

你每天看到的「平均值」几乎都是采样出来的：一次点击是否转化、一天里某个广告的收益、一次考试的成绩。这些量在真正观察之前并没有一个确定的数，但它们的长期平均却相当稳定。期望就是把这种「长期稳定」写成一个数。这一单元要做的，是把「长期」两个字从口号变成两万次真实采样，让你亲眼看到样本均值怎样一点点贴住理论值。

第 1 帧是这一节开始时的形态：examples/ 下只有 common/ 共用库，chapters/ch01/ 还是空目录。第 2 帧长出 expect_mc/：一个声明文件、两个源文件、一个清单。头文件 expect.h 只放常量和函数声明，expect.c 只放实现，main.c 只管打印。这种分家从第二个工程起就是硬要求——接缝可见，读头文件就知道这个例子能干什么，实现换了算法不影响驱动。共用库始终不动，所有单元都从它取函数。

工程惯例为什么把常量写进头文件

EXPECT_N、EXPECT_SEED 放在 expect.h 里，驱动和算法看到的是同一份定义。要是把两万这个数在 main.c 写一遍、在 expect.c 再写一遍，改采样量时漏改一处，打印的样本数和实际采样数就对不上了。头文件是这份契约的唯一正本。代价只是多一次 #include，换来的是「改一处、全局一致」。

1.2 随机变量是函数，不是「未知的数」

初学最容易把随机变量理解成「一个数，只是我们还不知道它是多少」。这个理解在掷骰子的场合勉强能用，一到多个变量就立刻垮掉。正确的说法是：随机变量是一个函数，它把样本空间里的每个结果映射成一个实数。样本空间是所有可能结果的集合，比如掷一枚硬币是 {正面, 反面}，掷一个骰子是 {1,2,3,4,5,6}。函数规则告诉你每个结果对应哪个数：正面记 1，反面记 0；骰子掷出几点就记几点。

这个区别为什么重要？因为「未知的数」没法同时谈分布和期望，而函数可以。函数有定义域（所有可能结果）、有取值规则（每个结果的数值）、有取值概率（每个结果出现的可能性）。把这三样写清楚，期望才有落脚点。反过来，如果你把随机变量当成一个待揭晓的常数，就会问出「它到底等于几」这种没有答案的问题——它不是一个待揭晓的常数，它是一整张对应表。

第 1 帧先把样本空间摆出来；第 2 帧画的是函数规则本身——两个结果各自被映成一个数；第 3 帧把相同数值的结果归并，得到「取值 0 的概率 0.5、取值 1 的概率 0.5」。注意第 2 帧里 X 的两个值用的是不同的节点，第 3 帧才把它们按数值归类。这个两步过程正是「随机变量」与「它的分布」的区别：前者是映射，后者是映射之后各数值的概率权重。把这两件事分开，后面谈「两个不同的随机变量可以有同一个分布」时才不会绕晕。

陷阱把「随机」理解成「毫无规律」

你会觉得随机就是乱七八糟、无法预测，于是对「随机变量的期望」这句话本能地怀疑：既然随机，怎么会有确定的平均值？真相是：单次结果随机，长期频率稳定。掷一枚公平硬币，下一次是正是反完全无法预测；但掷一万次，正面的比例几乎必定贴近 0.5。这种「个体无序、群体有序」正是期望存在的经验基础。反过来，也不是所有随机量都有稳定平均——柯西分布就是反例，后面 1.6 节会讲。把「随机」等同于「没有规律」，会让你既看不懂期望，也看不懂为什么有些分布压根没有期望。

1.3 分布：离散与连续两种记账法

分布回答的是「随机变量取各个值的可能性有多大」。离散分布用概率质量函数：每个可能取值挂着一个概率，所有概率加起来恰好是 1。连续分布用概率密度函数：单个点的概率是 0，只有一段区间上的积分才是概率，整条曲线下的面积是 1。这个区别在代码里很关键——离散用 po_bernoulli 直接吐出 0 或 1，连续用 po_uniform 吐出 [0,1) 里的浮点数，两者都是从一个 [0,1) 的均匀随机数变出来的。

伯努利分布是最简单的离散分布：取值只有 0 和 1，取 1 的概率是参数 p，取 0 的概率是 1-p。它描述的是「一次试验成功还是失败」——用户点不点、邮件是不是垃圾、抛硬币正还是反。均匀分布是最简单的连续分布：在 [0,1) 上每个点的密度一样高，取值落进任意一段区间的概率等于那段区间的长度。它描述的是「完全不偏袒任何位置」的随机选择，也是其他所有分布的原料。

第 1 帧的两格概率表加起来是 1，这是离散分布的硬约束；第 2 帧把均匀分布画成一条水平密度线段，加上一次真实抽取 u。这两帧代表了两种完全不同的记账方式：离散是「逐格列概率」，连续是「给出密度、按区间积分」。共用库把两种都封装好了：po_bernoulli(p) 内部先抽一个均匀数再与 p 比较，po_uniform() 直接返回 LCG 产生的浮点数。看懂这层，你就知道伯努利并不是独立的随机源，它是均匀分布的一次加工。

实验记录手算伯努利的期望

取 p=0.3。按加权平均的定义，期望是「每个取值乘以它的概率再求和」：E[X] = 1×0.3 + 0×0.7 = 0.3。这个 0.3 不是「某次试验会得到 0.3」——单次只会得到 0 或 1——而是大量试验里 1 出现的长期比例。如果你做一万次试验，成功次数大约在 3000 附近，样本均值大约 0.3。这一节的 bern_true=0.300000 就是这个理论值，程序的任务是用真实采样去逼近它。

1.4 期望的两种读法：加权平均与长期频率

期望 E[X] 有两种读法，它们在数学上等价，但在直觉上各有各的用处。加权平均读法：把每个可能取值乘上它的概率再求和，离散情形写作 E[X] = Σ xᵢ p(xᵢ)，连续情形写作 E[X] = ∫ x f(x) dx。这是一个静态的、纸面上的计算，不需要真的做实验。长期频率读法：做很多次独立重复试验，把结果加起来除以次数，次数趋于无穷时这个比值趋于期望。这是一个动态的、可操作的过程，正是蒙特卡洛方法的依据。

两种读法的一致性不是巧合，而是大数定律的结论（第 3 单元会讲它的严格形式）。在这一节，我们先把它当成工作假设：只要你采样够多次，样本均值就能当作期望的近似。这一假设有个前提——期望必须存在。下一节会给出期望不存在的例子，那时长期频率读法会彻底失效：样本均值不收敛到任何数，而是越跑越跳。

大白话把「加权平均」读成「重心」

把数轴想成一根杠杆，每个取值是一个挂砝码的位置，概率是砝码的重量。E[X] 就是这根杠杆的重心位置。砝码重的那一侧把重心拉过去；如果所有砝码均匀分布，重心就在区间中点。均匀分布 [0,1) 的砝码处处一样重，重心显然在 0.5——这就是 E[X]=0.5 的直观来源。伯努利 p=0.3 是「0 处放 0.7 的重量、1 处放 0.3 的重量」，重心偏向 0，位置在 0.3。这两句话不用积分就能记住，而且能推广：想让期望变大，就把更多重量挪到右边。

1.6 为什么期望不一定存在：柯西引子

到这里你可能会以为每个随机变量都有期望。不是的。考虑柯西分布，它的密度是 f(x) = 1/(π(1+x²))，曲线形状像钟形但尾巴掉得很慢。按定义算期望要积分 ∫ x f(x) dx，也就是 ∫ x/(π(1+x²)) dx。这个积分的正部和负部各自都是发散的：右边尾巴的贡献是 +∞，左边尾巴的贡献是 -∞，∞ - ∞ 没有定义。所以柯西分布没有期望——不是期望等于 0，而是这个数压根不存在。

这件事对蒙特卡洛意味着什么？如果你从柯西分布采样两万次再求平均，样本均值不会稳定下来。原因是那少数落在极远处的样本值巨大，把它们加进来就把平均值猛地拉偏；样本越多，遇到极端值的机会越大，均值跳得越厉害。换句话说，长期频率读法在这里失效了：不管采样多少次，平均值都不收敛到任何固定数。这提醒我们「样本均值 ≈ 期望」这条经验规则有前提——期望必须存在，而且尾巴不能太重。

陷阱把「对称」当成「期望为零」

你会想：柯西分布的密度关于 0 对称，正负抵消，期望当然是 0。这个推理看起来天衣无缝，其实是错的。数学上要求的是绝对可积，即 ∫|x|f(x)dx 有限；柯西分布不满足这个条件，所以不能说正负抵消得到 0。更直观的说法：你把正负两边截断到 [-R,R] 再算平均，确实得到 0；但让 R 趋于无穷的过程中，先扩左边还是先扩右边会给出不同的极限路径，整体极限不存在。对称性只能在期望存在的前提下用来判断它是 0。这个坑在重尾数据里真实存在：某些金融资产收益率的分布尾巴很重，拿历史平均去预测未来就可能在某一天被一个极端事件彻底推翻。

1.7 把 LCG 看清楚：种子、状态与可复现

共用库的随机源是一个 32 位线性同余发生器（LCG）。它的全部状态就是一个无符号整数 po_rng：po_rng = po_rng × 1664525 + 1013904223 (mod 2³²)，然后取高 24 位除以 2²⁴ 得到 [0,1) 里的浮点数。这个公式只有乘法和加法，没有查表、没有系统调用，所以同样的种子在任何机器上给出逐位相同的序列。这就是我们敢把黄金值写进清单的底气。

第 1 帧是种子注入；第 2 帧是一次迭代的完整动作——状态更新和输出；第 3 帧说明序列的确定性。注意这里的 u1、u2 正是 first8:[...] 的前两项，你可以逐位核对。po_bernoulli 用的也是这条序列：它先取一个均匀数，与 p 比较，小于 p 就返回 1。所以一次伯努利采样消耗一个均匀数，均匀和伯努利两个序列是交织的，不是各自独立的——这一点在调试时要记牢，否则你会以为两个样本流互不影响。

工程惯例为什么用 LCG 不用标准库的 rand

标准库的 rand() 没有规定具体算法，不同实现给出不同序列，同样的种子在不同机器上结果不一样，黄金值就没法跨机器对账。LCG 的公式写在共用库里，每一位都可查，可复现性是硬保证。代价是它的统计质量一般——高维下会出现格子结构，不能当密码学随机源。本书只用它做数值实验的可复现采样，这个用途完全够格；真要做蒙特卡洛积分的严肃研究，该用更长的周期和更好的发生器。

陷阱把种子当成「随机性的来源」

你会以为种子让结果「更随机」，于是每次运行都换一个种子，还觉得这才叫科学。真相恰恰相反：种子的作用是消除随机性带来的不可复现，让同一份代码每次跑出逐位相同的数。换种子得到的不是「更真实」的结果，而是另一条样本路径——它可以用来检验结论是否依赖特定样本，但不能用来代替固定种子的对账。测试里如果需要「换个种子也该通过」，那是另一类检查；黄金值对账必须在固定种子上做，否则今天跑过的数字明天就对不上了。

1.8 误差从哪来：蒙特卡洛的 √n 速率

现在回答 1.5 节留下的问题：偏差 0.003677 和 -0.008350 算大吗？对独立同分布的样本，样本均值的标准差是 σ/√n，其中 σ 是单个样本的标准差。均匀分布 [0,1) 的 σ = 1/√12 ≈ 0.288675，所以 n=20000 时标准误约 0.288675/√20000 ≈ 0.00204。观测偏差 0.003677 大约是 1.8 个标准误——完全在正常波动范围内。伯努利 p=0.3 的 σ = √(0.3×0.7) ≈ 0.458258，标准误约 0.00324，观测偏差 -0.008350 约 2.6 个标准误，稍微偏大但仍在两三倍以内。

这里的 √n 是关键：想把误差缩小 10 倍，样本量要放大 100 倍；想缩小 100 倍，要放大一万倍。这就是蒙特卡洛方法「收益递减」的根源——它从不给你指数级的精度。好处是它与维度无关：不管被积函数有多少维，采样误差的速率都是 √n，这在高维问题上比网格方法划算得多。深度学习里的采样估计（比如从策略分布里采样回报）靠的正是这一条。

三帧里的数字是示意量级，不是这次真跑的结果，正文已用真实的标准误公式给出了精确尺度。图元要传达的是「横轴按平方放大、纵轴才按一次方缩小」这件事。你点开第 2 帧会看到真值节点仍在——这是帧自包含的要求，渲染器不会自动把上一帧的节点带过来。

实验记录心算验算标准误

对均匀分布 [0,1)：E[X]=0.5，E[X²]=1/3，所以 Var(X)=1/3−0.25=1/12≈0.083333，σ≈0.288675。除以 √20000≈141.421，得标准误 ≈0.002041。真跑偏差 0.003677/0.002041≈1.80。对伯努利 p=0.3：Var(X)=p(1−p)=0.21，σ≈0.458258，标准误 ≈0.003241，真跑偏差 -0.008350/0.003241≈−2.58。两个偏差都在几个标准误以内，说明采样过程没有系统性偏差——如果你看到偏差有几十个标准误，第一反应应该是检查随机源或累加代码，而不是怪运气。

1.9 失败模式：偏差、相关与「看起来收敛」

第一种失败是有偏的采样。如果你把 LCG 的输出取模后再缩放，或者用 rand() % 100 / 100.0 这种写法，得到的数不再均匀——低位比特的周期特别短，某些值出现得更频繁。这时样本均值会稳定地偏离真值，再多采样也救不回来。判据很简单：偏差随 n 增大不缩小，而是停在一个固定值附近。

第二种失败是样本不独立。标准误公式 σ/√n 假设样本之间独立。如果你的采样过程有惯性（比如马尔可夫链采样，或者重复用同一批样本做多次统计），有效的独立样本数远小于 n，实际误差会比公式预测的大得多。这时 n=20000 给不了你 √20000 的精度。第 10 单元讲 MCMC 时会把这件事说透。

第三种失败是只看轨迹不看尺度。采样均值曲线看起来「平了」，不代表收敛到真值——它可能只是恰好在那段区间里慢慢漂移。判断收敛要有两个东西：理论真值作参照，以及标准误作尺度。这一节的真值 0.5 和 0.3 就是参照，1.8 节的标准误就是尺度，两者缺一不可。

陷阱别把「样本均值接近真值」当成「采样正确」

你会看到 uniform_mean=0.503677 离 0.5 很近，于是觉得采样代码没问题。但一个把随机数全打成 0.5 的程序也会给出 uniform_mean=0.500000，看起来更漂亮。闸门为什么不只看均值？因为 first8:[...] 那行被逐字对账了——八个原始样本必须逐位匹配，这就堵住了「只抄一个常数」的假实现。数值对账的力量来自多个独立观测的联合约束，不是单个数字碰巧接近。

1.10 与深度学习的对应：损失就是样本均值

神经网络训练时用的损失函数，几乎都是对一批样本的平均值。均方误差 L = (1/n)Σ(yᵢ−ŷᵢ)² 是平方损失的样本均值；交叉熵 L = −(1/n)Σ log p(yᵢ) 是负对数似然的样本均值。所以你在本节练的「用采样平均逼近期望」，正是训练循环里每一步在做的事。区别只在于：这里的样本来自已知分布，训练里的样本来自数据分布；这里的真值已知，训练里的真值未知，我们要优化参数让这个平均值尽量小。

这个对应还解释了随机梯度下降的噪声。全量梯度是「对所有数据求平均」，随机梯度是「抽一小批样本求平均」。小批量的样本均值有波动，波动幅度按 1/√B 缩小，B 是批大小——这正是 1.8 节的 √n 速率。你增大批量能让梯度更稳，但收益按平方根衰减：批大小放大四倍，噪声才减半。这不是实现问题，是采样统计的铁律。

工程惯例为什么训练曲线会抖

看到 loss 曲线上下抖动，新手常以为代码写错了。实际上每个小批量只是数据分布的一次采样，批次之间的样本均值本来就有波动。批大小越小，抖动越明显；学习率越大，同样的梯度噪声被放得越大。理解「损失是样本均值」这件事，你就知道该先看批大小和学习率，而不是急着翻代码找 bug。想平滑曲线可以用指数移动平均，但那是显示技巧，不改变梯度本身噪声。

1.11 手算核对：不用程序也能验的三组数

第一组是均匀分布的期望与方差。E[X] = ∫₀¹ x dx = 1/2；E[X²] = ∫₀¹ x² dx = 1/3；Var(X) = 1/3 − (1/2)² = 1/12 ≈ 0.083333。三个数都用手算积分得出，与 1.8 节的标准误计算完全对上。

第二组是伯努利。E[X] = 1·p + 0·(1−p) = p = 0.3；E[X²] = 1²·p + 0²·(1−p) = 0.3；Var(X) = 0.3 − 0.09 = 0.21。注意 E[X²] = E[X] 是 0/1 变量特有的性质，因为 x² = x 对 0 和 1 都成立，这个简化在手写反向时能省不少事。

第三组是样本比例。bern_mean=0.291650 乘以 n=20000 得 5833——这就是两万次试验里 1 出现的次数。你可以用程序再数一遍成功次数，必须恰好是 5833，否则累加代码有 bug。这类「从打印值反推内部计数」的核对，比盯着平均值看有用得多。

1.12 把这一节接到后面：从期望到方差

期望告诉你分布的重心在哪，但它不告诉你分布有多散。两门课的平均分可能都是 75，一门全班都在 74–76，另一门从 30 到 100——均值一样，风险完全不同。度量这种「散」的就是方差，下一单元的主角。方差的定义 Var(X) = E[(X−E[X])²] 仍然是一个期望，所以你在本节练的两种读法照样适用：既可以按概率加权算，也可以采样估计。

从代码角度看，下一步几乎不用改结构：expect.c 里累加 u 和 b 的地方，再多累加一列 u*u，就能算出 E[X²]，再用 E[X²] − (E[X])² 得到方差。共用库已经把这件事封装成 po_variance，下一单元直接调它。这样你就看出这一册的推进方式：每一节只加一层统计概念，底层的采样与对账流程原样复用。

1.13 指示变量法：把计数变成期望

有一种手算技巧在这一册会反复出现，叫指示变量法。它的想法很简单：想知道「满足某个条件的样本有多少个」，就给每个样本定义一个只取 0 或 1 的指示变量——满足条件记 1，不满足记 0——然后对这个指示变量求期望。由于指示变量是伯努利变量，它的期望恰好等于条件成立的概率；把所有指示变量加起来，总个数的期望就是各个概率之和。这个方法把「数数」变成了「求期望」，从而能用期望的线性性绕开复杂的联合分布。

拿本节的两万次伯努利试验练手。第 i 次试验定义 Iᵢ，成功时是 1、失败时是 0，那么 E[Iᵢ] = p = 0.3。成功总次数 K = I₁ + I₂ + ⋯ + I₂₀₀₀₀，于是 E[K] = 2×10⁴ × 0.3 = 6000。真跑得到的成功次数是 5833，比理论值少 167——这个差值约等于 167/√6000 ≈ 2.16 个标准误，属于两三个标准误以内的正常波动。反过来从打印值核对：bern_mean=0.291650 乘两万正好是 5833，与这里的计数一致。这条链式核对把理论值、样本统计量、内部计数三件事串了起来。

指示变量法真正厉害的地方，是处理「相互依赖的事件」。比如想知道一批样本里有多少对数值相差小于 0.01，直接算这个计数的分布非常麻烦；但定义每对样本一个指示变量，总对数的期望就是各对概率之和，而每一对只是两个均匀分布的比较，容易手算。你不需要知道这些指示变量之间是否独立——期望的线性性对任意变量都成立，这是它比方差好用得多的地方。下一单元讲方差时会看到，方差的线性性要求独立性，用起来要小心翼翼。

工程惯例期望的线性性为什么这么好用

对任意两个随机变量都有 E[X+Y] = E[X] + E[Y]，不需要独立、不需要同分布、不需要任何额外条件。这是期望最值钱的性质。它让你可以把一个复杂量拆成若干个简单指示变量之和，逐个求期望再加起来。深度学习的损失函数设计里也常用这一招：整体 loss 写成每个样本 loss 之和，反向传播才能逐样本累加梯度。要是期望没有线性性，这套拆分立刻失效。

1.14 从期望到估计：偏差、方差与均方误差

现在把「估计」这件事说清楚。我们想用一个统计量去逼近某个未知的真值，这个统计量叫估计量。样本均值是最常用的估计量。评价一个估计量好坏有三个词：偏差是估计量的期望与真值之差，衡量「平均意义上偏不偏」；方差是估计量自身的波动，衡量「换一批样本会变多少」；均方误差是两者之和加交叉项，在偏差为零时恰好等于方差。样本均值对有期望的分布是无偏的：E[X̄] = E[X]，它的方差是 σ²/n。所以样本均值的均方误差就是 σ²/n，这正是 1.8 节标准误的平方。

这给出一个重要的工程判断：想降低均方误差，要么减小单样本方差 σ²，要么增大样本量 n。减小 σ² 的办法叫方差缩减，比如重要性采样、分层采样、公共随机数法；增大 n 简单粗暴但按平方根收益递减。深度学习里两者都在用：小批量训练对应增大 n，而各种归一化技术某种程度上是在压低梯度估计的方差。把均方误差拆成偏差和方差，你就有了分析任何估计量的统一框架。

陷阱无偏不等于每次都准

你会觉得「无偏估计」意味着每次估计都接近真值。不是的。无偏只保证大量重复试验的平均值对得上真值，单次估计可能差得很远。样本均值在 n=2 时也是无偏的，但两次采样得到的均值波动巨大。反过来，一个有偏但方差极小的估计量，在均方误差意义上可能比无偏估计量更好——机器学习里大量正则化方法就是故意引入偏差来换方差下降。评价估计量要看均方误差，不要只盯无偏性这一个词。

1.15 连续分布的期望为什么用积分

离散情形 E[X] = Σ xᵢpᵢ 很好理解，连续情形 E[X] = ∫ x f(x) dx 看着像另一套东西，其实是同一件事的极限。把实数轴切成长度 Δx 的小格，落在第 i 格的概率大约是 f(xᵢ)Δx，于是加权平均近似为 Σ xᵢ f(xᵢ) Δx。让 Δx → 0，这个和就变成积分。所以积分号不是新概念，它只是「格子无限细的求和」。记住这层，你就永远不会把概率密度和概率搞混：密度 f(x) 本身不是概率，乘以一小段长度 Δx 才是落进那一小段的概率。

对均匀分布 [0,1)，密度恒为 1，于是 E[X] = ∫₀¹ x·1 dx = 1/2，与 1.11 节的手算一致。对指数分布 f(x) = e^{−x}（x ≥ 0），E[X] = ∫₀∞ x e^{−x} dx = 1，这是第 3 单元 expected_mean=1.000000 的来源。你能手算这两个积分，就能对后面所有蒙特卡洛实验做独立核对——程序跑出来的数再漂亮，也要有一把不依赖程序的尺子量一量。

实验记录用采样验证积分的几何意义

在 [0,1) 上取均匀样本，估计 ∫₀¹ x² dx。把每个样本映成 x²，再求这些 x² 的平均值，按期望定义它逼近 E[X²] = ∫₀¹ x² f(x) dx = 1/3。这一节的程序里只累加了 u 本身，没有累加 u²；你可以自己加一列 su2 += u*u，打印 second_moment≈0.333，再算 0.333−0.5²≈0.083，正好是均匀分布的方差 1/12。这类改写是对「积分就是加权平均」最直接的验证，也让你在改代码的过程中把期望与方差的关系摸熟。

1.16 这一节新增了什么，下一节要什么

回到 1.1 的第 2 帧：expect_mc/ 多了头文件、算法实现、驱动和清单四样东西，共用库没有改动。这一节真正产出的不只是一个打印两万次平均值的程序，而是一套可复用的流程：固定种子 → 真采样 → 打印数值行 → 清单声明黄金值与容差 → 闸门从 stdout 重算判定。后面九个单元都在这套流程上加内容，只是被估计的量从期望换成方差、批次均值、似然、熵、对偶间隙。流程不变，概念逐层叠加，这是这一册的组织方式。

下一单元问一个紧接着的问题：重心知道了，分布有多散？方差与协方差把「散」和「一起变」量化成数，并且会把你带到一个看起来纯代数、其实有深刻统计含义的结论——协方差矩阵半正定。你会看到本节的期望概念在那里原样复用，也会看到独立与不相关这两个词之间那道很容易踩空的缝。

小结这一节的要点
  • 随机变量是样本空间到实数的函数，分布是映射之后各取值的概率权重；
  • 期望既是加权平均 Σxᵢpᵢ，也是长期频率的极限；柯西分布说明这个极限不一定存在；
  • 固定种子的 LCG 让采样逐位可复现，这是黄金值对账的前提；

注自测题答案

  2. 意味着大量独立重复试验里 1 的长期比例趋近 0.3。单次试验只会得到 0 或 1，永远不会得到 0.3；期望是群体的统计量，不是单次结果的候选值。
  3. E[X]=∫₀¹x dx=1/2；E[X²]=1/3；Var(X)=1/3−1/4=1/12≈0.083333，σ≈0.288675；n=20000 时标准误 σ/√n≈0.002041。真跑偏差 0.003677 约 1.8 倍标准误，属正常波动。
  4. 期望要求 ∫|x|f(x)dx 有限；柯西的正部积分是 +∞、负部是 -∞，相减无定义，所以期望不存在。对称只能在期望存在时用：截断到对称区间确实得 0，但让区间无穷扩张时正负两边各自发散，极限不存在。
  5. 每次运行得到不同样本路径，stdout 里的 uniform_mean 等值会逐次变化，清单里的固定黄金值会频繁报 numeric_value_mismatch。可复现采样是数值对账的前提，种子必须钉死。
