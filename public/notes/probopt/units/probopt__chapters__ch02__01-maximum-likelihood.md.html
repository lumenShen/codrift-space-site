4.1 先看工程长什么样

从这一单元起进入第 2 章，例子目录变成 examples/ch02/，单元文件落在 chapters/ch02/。按写作契约，第二个项目起必须是多文件工程：src/ 放两个源文件，include/ 放头文件，清单的 sources 列出至少两个 .c，并且头文件被 #include 进来。这不是形式主义——它让「声明」与「实现」的接缝可见，读头文件就知道这个例子能干什么，换了实现不影响驱动。共用库 common/ 仍然一个字不改，po_bernoulli_loglik 与 po_normal_loglik 直接复用。

大白话先建立一个画面

前面三节我们一直在「从已知分布采样」：分布参数是给定的，我们算均值、算方差、算误差。这一章把问题反过来：参数是未知的，数据已经有了，我们要找最可能生成这些数据的参数。这叫最大似然估计。它是深度学习训练的数学原型——你手里的网络权重就是那个未知参数，训练数据就是已观察到的数据，优化器在做的事本质上是把「数据的似然」推到最大。看懂这一节，你就看懂了训练目标函数的来历。

第 1 帧是动笔前的形态：examples/ch02/ 还不存在，chapters/ch02/ 是空目录。第 2 帧长出 mle_bernoulli/：mle.h 声明常量和两个函数，mle.c 实现采样与正态参数估计，main.c 做网格搜索并打印，po04-mle.json 声明数值对账。注意这一节同时演示了两种分布的 MLE——伯努利是主角，正态是配角，两者共用同一套「写出似然、取对数、求最大」的流程。

工程惯例为什么第二个项目必须拆成多文件

拆开之后，main.c 只负责「选参数、打印结果」，mle.c 只负责「造样本、算统计量」。如果你要把伯努利换成别的分布，只改 mle.c，驱动一行不动。代价是要写 #include "mle.h"，还要保证声明与实现签名一致——编译器不会替你检查跨文件的语义，只有链接器保证符号存在。这个成本换来的是可接手性：别人读头文件就知道这个例子提供什么能力，不必先读完整个实现。

4.2 似然不是概率：把函数和变量的身份换过来

设数据 x₁,…,xₙ 已经观察到，分布的概率质量或密度是 f(x|θ)，其中 θ 是参数。在概率视角里，θ 固定、x 变化，f(x|θ) 描述「不同数据的可能性」；在似然视角里，x 固定、θ 变化，L(θ) = f(x₁,…,xₙ|θ) 描述「不同参数的合理性」。同一个数学式子，换个变量身份就从概率变成了似然。这个身份切换是理解最大似然的第一道门槛。

为什么似然不是「参数的概率」？因为 L(θ) 对 θ 积分通常不等于 1——它压根不是 θ 的概率密度。它只是「如果参数真是 θ，看到这批数据的可能性有多大」。一个参数值让数据出现的可能性大，我们就说它「更合理」，但不会说「θ 取这个值的概率大」。要把似然变成参数的概率分布，需要贝叶斯框架和先验分布，那是另一条路。最大似然刻意不引入先验，只问哪个参数最能解释眼前的数据。

陷阱把最大似然当成「参数最可能的值」

你会脱口而出：「MLE 就是让参数最可能的值」。这句话在日常交流里能听懂，但严格说是错的——它暗示参数有概率分布，而频率学派不承认参数是随机的。正确的说法是「让观察到的数据最不意外的参数值」。这个区别不只是措辞：当你开始给参数加先验、算后验，你就进入了贝叶斯统计；MLE 是后验在均匀先验下的众数，但这个概念只有在贝叶斯框架里才成立。把两者混着用，会在讨论正则化时彻底说不清。

4.3 取对数：乘积变和，下溢变可控

样本独立时，联合概率是各样本概率的乘积：L(θ) = ∏ᵢ f(xᵢ|θ)。一万个样本意味着一万次相乘。直接算有两个麻烦。第一，每个因子都小于 1，一万个因子乘起来会极小，双精度很快下溢成 0——0 与「非常小」在对数上差得很远，化成 0 后所有参数看起来一样差。第二，乘积的导数涉及复杂的乘积法则，求最优解很麻烦。

取对数一举解决两件事：ℓ(θ) = ln L(θ) = Σᵢ ln f(xᵢ|θ)。乘法变成加法，不再下溢；对数函数是单调递增的，所以最大化 L 与最大化 ℓ 给出完全相同的参数。导数也好求了——和的导数就是导数的和。深度学习里所有训练损失几乎都写成负对数似然，正是因为它把一长串相乘变成了可累加、可求导、数值稳定的和。

三帧从乘积形式走到可用形式，第 3 帧已经把最优解写了出来。注意第 2 帧里「单调」节点仍在——这是取对数合法的唯一理由；如果换个不单调的变换，最大值位置就变了。图里的 k 是成功次数、n 是总次数，与程序打印的 successes 和 n 对应。

大白话用大白话说取对数

一堆小于 1 的数相乘，越乘越小，小到计算机都装不下；取对数相当于把「相乘」改成「把各自的缺点相加」——每个样本对参数的不满程度累加起来，总不满最小的地方就是最合理的参数。 对数是单调的，所以「总不满最小」和「原始乘积最大」是同一件事。这个翻译不丢信息，却让计算从容易溢出变成稳稳当当。

4.4 伯努利的 MLE 就是样本均值

伯努利似然：观察到 k 次成功、n−k 次失败（顺序不影响似然，因为独立同分布），所以 L(p) = pᵏ(1−p)ⁿ⁻ᵏ。对数似然 ℓ(p) = k ln p + (n−k) ln(1−p)。求导得 ℓ'(p) = k/p − (n−k)/(1−p)，令它为零：k(1−p) = (n−k)p，化简得 p = k/n。这就是样本均值。二阶导 ℓ''(p) = −k/p² − (n−k)/(1−p)² < 0，所以这是极大值而不是极小值。

这个结论很漂亮：最大似然估计给出的正是我们凭直觉会用的「成功次数除以总次数」。它给直觉提供了严格依据。程序里的 sample_mean=0.357900 就是 successes/n = 3579/10000，网格搜索找到的 phat=0.36 是最接近它的网格点（网格步长 0.01）。两者稍有差异，纯粹因为网格是离散的；如果把步长缩小到 0.0001，phat 会更接近 0.3579。

第 1 帧把真实计数写进节点；第 2 帧是对数和导数；第 3 帧给出解析解与网格解的对照。三帧自包含，第 3 帧仍保留了导数节点。这张图与 4.3 节的通用流程图分工不同：那张讲「为什么取对数」，这张讲「伯努利具体怎么解」。

在 p=0.36 处，ℓ' = 3579/0.36 − 6421/0.64 ≈ 9941.67 − 10032.81 ≈ −91.1，导数为负，说明已经越过峰值（网格点 0.36 略大于真最优 0.3579）。在 p=0.35 处，ℓ' = 3579/0.35 − 6421/0.65 ≈ 10225.7 − 9878.5 ≈ +347.2，导数为正，说明还没到峰值。两边一正一负，峰值夹在 0.35 与 0.36 之间，与解析解 0.3579 一致。这种「在候选点算导数符号」的办法，能在没有解析解时快速确认网格搜索找对了没有。

4.6 正态 MLE：均值与方差

正态分布的密度是 f(x|μ,σ) = (1/(√(2π)σ)) exp(−(x−μ)²/(2σ²))。对 n 个独立样本取对数似然：ℓ(μ,σ) = −n ln(√(2π)σ) − (1/(2σ²))Σ(xᵢ−μ)²。对 μ 求导并令零，得到 μ̂ = (1/n)Σxᵢ，就是样本均值。对 σ² 求导并令零，得到 σ̂² = (1/n)Σ(xᵢ−μ̂)²，分母是 n。

为什么是 n 而不是 n−1？因为这里是最大似然估计，优化的目标是似然本身，不是「无偏估计总体方差」。MLE 的方差系统性偏小，偏差因子是 (n−1)/n；本例 n=3000，因子 0.99967，小到远低于采样噪声。上一单元讲过，做无偏推断才用 n−1，做经验分布描述和 MLE 用 n——这里的 normal_var_hat=2.226284 与真值 2.25 的差距主要来自采样，不是分母选择。

三帧按「数据 → 均值 → 方差」的顺序推进，第 3 帧仍保留 mu_hat 节点，说明方差计算依赖均值估计。这里用到的 po_mean 与 po_variance 正是上一单元的共用函数——同一套工具，换个场景继续用。normal_var_hat 的真值 1.5²=2.25，偏差 −0.0237，与 n=3000 下方差估计的标准误量级一致。

陷阱把样本方差直接当成 MLE 方差

你会习惯性地写 1/(n−1)Σ(xᵢ−x̄)²，然后说这是「方差的最大似然估计」。严格说不对：那是无偏估计，不是 MLE。两者在 n 大时几乎一样，所以实践里没人计较；但在推导似然方程时，分母必须写 n，否则你在优化的不是似然函数。做模型选择、比较不同分布的 AIC/BIC 时，似然值要算得精确，这时候分母的约定就不能含糊。

4.7 过拟合与正则化：MLE 的边界

最大似然只优化对训练数据的拟合程度，不管参数有多复杂。如果模型容量很大，它能把训练数据「背下来」，得到极高的似然，却在新数据上表现很差——这就是过拟合。举一个极端的例子：对一维数据，你可以用一个次数比样本数还高的多项式穿过每个点，残差为零、似然趋于无穷，但这个多项式在两点之间剧烈震荡，毫无预测价值。

正则化是对 MLE 的修正：在目标函数里加一项惩罚复杂度的项。ℓ(θ) − λ·R(θ) 里 λ 控制惩罚强度，R 衡量参数有多大或有多复杂。加上 L2 惩罚等价于给参数加了一个高斯先验，从贝叶斯角度看这是在求最大后验估计而不是最大似然。这个联系很重要：它告诉你 L2 正则不是拍脑袋加的，它有明确的统计解释。本例只做纯粹的 MLE，正则化留到后面的优化分册展开。

大白话用大白话说过拟合

MLE 像一个死记硬背的学生：把见过的每一道题的答案都背下来，考原题满分，换个数字就不会了。正则化像老师要求「不许死记，要理解规律」——它限制学生把参数调得太极端，逼模型学到更一般的模式。限制太松会过拟合，太紧会欠拟合，中间的 λ 要靠验证集来选。这套权衡贯穿整个机器学习。

4.8 数值稳定：log 0 与下溢

共用库的 po_bernoulli_loglik 在 p=0 且样本成功时会对 0 取对数，结果在 IEEE 浮点里是 −∞。这不是 bug，是数学事实：ln 0 没有有限值。程序里网格从 0.01 开始、到 0.99 结束，正好绕开了这两个端点。如果你把网格改成从 0 开始，峰值附近的比较还可能正常，但端点处会出现负无穷，打印出 −inf，闸门会报 numeric_value_invalid。

工程上处理这类边界有三种办法。一是避开端点，像本例这样留一个小间隔。二是加一个极小量 ε，用 ln(p+ε) 代替 ln p，缺点是引入了微小偏差。三是在代码里显式判断，遇到零概率就返回一个很大的负数。深度学习框架里的交叉熵实现通常做第三种，还会用 log-sum-exp 技巧避免分子分母同时下溢。你现在知道这些技巧服务的目标是什么：让「对数似然」这个量在浮点里保持可靠。

陷阱把 −inf 当成「很小的值」继续算

你会觉得 −inf 只是一个特别小的数，加加减减无所谓。真相是它会污染整个计算：−inf + 1 = −inf，−inf − (−inf) = nan。一旦 nan 进了梯度，所有参数都变 nan，训练彻底崩掉。更隐蔽的是 −inf 参与的比较：如果所有候选的对数似然都是 −inf，网格搜索会停在第一个候选上，看起来「找到了最优」，其实全是废值。防御办法是在计算前检查参数范围，在计算后检查有限性，不要等 nan 冒出来才查。

4.9 网格搜索与解析解：两条路互相验证

本例用网格搜索，因为它不需要推导导数，代码直白到一眼能看懂。解析解 p̂ = k/n 则给出精确答案。两条路给出的数略有差异：phat=0.36 是网格点，sample_mean=0.357900 是解析值。这个差异不是错误，而是离散化的代价。你可以把网格改成步长 0.001，此时 phat 会变成 0.358，更接近解析解；代价是循环次数放大十倍，但对一万次样本来说仍然瞬间完成。

什么时候必须用数值优化？当似然方程没有解析解时，比如混合模型、逻辑回归、神经网络。这时梯度下降、牛顿法、EM 算法轮番上场，但它们优化的目标仍然是同一个对数似然。本节的网格搜索就是这些算法的玩具版：枚举候选、算目标、选最大。理解了它，你再看 Adam 更新公式时就知道那一堆运算服务的目标是同一个 ℓ(θ)。

实验记录把网格步长改细，看 phat 怎么变

把循环改成 grid = 1; grid <= 9999; ++grid、p = grid / 10000.0，理论最优网格点是 3579/10000=0.3579。你可以先写下预测，再真跑核对。注意 ll_at_phat 也会变大（更接近真正的峰值），而 ll_at_half 不变——因为它与网格无关。这个实验让你亲手看到「离散化误差」和「模型本身的不确定性」是两回事：前者可以靠细化网格消除，后者只能靠更多数据缓解。

4.10 与深度学习的对应：交叉熵就是负对数似然

分类任务的交叉熵损失，本质就是伯努利或类别分布的负对数似然除以样本数。二分类时，标签 y∈{0,1}、模型预测概率 p，单样本损失 −[y ln p + (1−y)ln(1−p)]，正好是伯努利对数似然取负。整个训练集上的平均交叉熵，就是 −ℓ(p)/n。所以最小化交叉熵与最大化伯努利似然是同一件事，只差一个负号和一个常数因子。

这个对应关系解释了三件事。第一，为什么分类用交叉熵而不是均方误差——交叉熵直接来自数据的概率模型，梯度在概率接近错误标签时不会饱和得太厉害。第二，为什么训练曲线要报 loss 而不是似然——loss 是负对数似然，越小越好，读起来符合直觉。第三，为什么标签要做独热编码——独热标签让目标分布变成确定性的，交叉熵里目标分布的熵项为零，剩下纯粹的对数似然项。下一单元讲熵与 KL 散度时会把这层关系完全展开。

工程惯例为什么框架里用 log_softmax 而不是先 softmax 再 log

先算 softmax 得到概率，再对概率取对数，中间会把很小的概率下溢成 0，接着 log(0)=−∞。log_softmax 把两步合并，用 log-sum-exp 技巧直接在 log 域计算，数值稳定得多。它的数学结果与「先 softmax 再 log」完全相同，但避开了下溢。你现在知道它服务的目标：让 4.8 节说的负对数似然在浮点里算得准。

4.11 手算核对：把两个似然值算到底

ll_at_half 可以用解析公式核对。k=3579、n−k=6421，p=0.5 时每一项的对数都是 ln 0.5≈−0.693147，所以 ℓ(0.5)=10000×(−0.69314718056)=−6931.471806，与程序打印逐位一致。这是一个很好的独立尺子：不需要程序，只用自然对数的基本值就能验证。

ll_at_phat 在网格点 0.36 处按公式 3579×ln(0.36)+6421×ln(0.64) 算。ln(0.36)≈−1.021651，ln(0.64)≈−0.446287，两项分别是 −3656.468 与 −2865.631，合计约 −6522.099，与打印值 −6522.099301 一致。两个似然值的差是 409.372505，意味着 p=0.36 的似然是 p=0.5 的 e⁴⁰⁹ 倍——这个数字大到没有物理意义，但足以说明数据对 p=0.5 的否定有多坚决。

陷阱别直接比较似然而要比较对数似然

似然值是 e^(−6522) 这种极小的数，不同参数之间的似然比是 e⁴⁰⁹，任何浮点数都装不下。比较对数似然则完全可行——它的数值范围只有几千，差值 409 一目了然。这也是为什么所有统计量（似然比检验、AIC、BIC）都用对数似然定义。看到别人报「对数似然 −6522」，你要知道这不是「负数所以很差」，而是「取了对数之后的尺度，越大越好」。

4.12 这一节新增了什么，下一节要什么

回到 4.1 的第 2 帧：这一节新增的是 mle_bernoulli/，头文件、两个源文件、清单一起到位，共用库没动。真正的新东西是把「从数据反推参数」变成一个可计算的目标函数：写出似然、取对数、求最大。伯努利的解是样本均值，正态的解是样本均值与样本方差，两条都与前面三节的统计量直接接上。你还看到了数值稳定的必要性——log 0 和负无穷会实实在在地毁掉计算。

下一单元问一个更根本的问题：我们说「交叉熵是损失」，可它为什么叫交叉熵？熵是什么，KL 散度为什么非负又不对称？你会发现交叉熵等于目标分布的熵加上目标与模型之间的 KL 散度，而独热标签让熵项变成零——于是最小化交叉熵就等价于最小化 KL。这一册的主线到此完成从采样到损失函数的闭环。

4.13 充分统计量：为什么只需记住两个计数

伯努利的似然 L(p)=pᵏ(1−p)ⁿ⁻ᵏ 只依赖两个数：总次数 n 和成功次数 k，不依赖每个样本的出现顺序。这两个数叫充分统计量——它们已经包含了样本中关于 p 的全部信息。一旦你知道 n 和 k，再看原始的一万次结果不会让 p 的估计更准。这个结论在数据压缩和系统设计中很实用：你不必存下一万个 0/1，存两个整数就够了。

充分统计量也解释了为什么 MLE 那么容易求。它把高维数据压缩成低维摘要，优化问题从「一万维样本上的函数」变成「一维参数上的函数」。正态分布的充分统计量是样本均值与样本平方和，对应本例打印的 normal_mu_hat 与 normal_var_hat。并非所有分布都有这么紧凑的充分统计量——神经网络的参数估计就没有，这也是深度学习必须依赖数值优化的原因之一。

工程惯例充分统计量在在线学习里的用处

如果你的数据流是逐条到达的，不能一次性把所有历史数据留在内存里，充分统计量让你只保存少量摘要就够了：伯努利只要累加成功次数和总次数，正态只要累加和、平方和、计数。新的样本到来时更新摘要，随时能算出当前 MLE。代价是丢掉了原始样本，事后想验证分布假设或找异常值就做不到了——这是压缩的普遍代价。

4.14 似然比检验：用差值判断参数是否可疑

4.11 节算出两个对数似然相差 409，这个差值本身就是一种统计检验。似然比检验的思想是：比较「参数自由取最优值」与「参数被限制在某个假设值」两种情况下的最大对数似然，差值越大，说明限制越不合理。对大样本，统计量 2(ℓ(θ̂)−ℓ(θ₀)) 近似服从卡方分布，自由度是被限制的参数个数。本例的差值是 2×409≈818，远大于任何常用临界值，所以 p=0.5 的假设被坚决拒绝。

这个框架把「估计」和「检验」统一在同一个似然函数下：估计找峰值，检验看峰值与假设点之间的距离。深度学习里做模型比较时用的 AIC 与 BIC 也都建立在对数似然上，只是在峰值附近加了一个参数个数的惩罚项。你现在看到的 ll_at_phat 与 ll_at_half 不只是两个打印数字，它们是一整套统计推断的原料。

陷阱大样本下几乎所有假设都会被拒绝

你会以为似然比差值越大越有说服力，于是拿一百万条数据去检验「转化率是否等于某个值」。问题在于检验统计量的增长与样本量成正比：再小的真实差异，样本量足够大时也会给出巨大的差值，把原假设拒绝掉。这时统计显著与实际重要是两回事——p=0.3579 与 p=0.36 的差别在商业上可能毫无意义，但一百万条数据能把它判为「高度显著」。报结论时要同时给效应量，不能只给显著性。

4.15 从 MLE 到 MAP：先验怎样进入目标函数

最大似然不假设参数有任何偏好。如果你事前就知道 p 大概率在 0.5 附近，可以把这份知识写进先验分布，转而最大化后验——这叫最大后验估计。对伯努利参数，共轭先验是 Beta 分布，加上先验后的最优解不再是单纯的 k/n，而是成功与失败计数各加上一个「伪计数」。样本少时伪计数影响大，样本多时被真实数据淹没。这套机制给了正则化一个清晰的统计解释。

L2 正则对应高斯先验：惩罚项 λ‖θ‖² 就是负的对数高斯先验。L1 正则对应拉普拉斯先验，它会产生稀疏解。理解这层对应关系，你在调正则化强度 λ 时就知道自己其实在表达「我事前相信参数有多大」——λ 越大，先验越窄，模型越不敢把参数调大。本例没有加正则，属于纯 MLE；这也解释了为什么它只优化训练数据的拟合，不过问参数复杂度。

大白话用一句话把三种估计串起来

MLE 只问数据怎么说；MAP 再问先验怎么说；贝叶斯推断不止取一个点，而是把整个后验分布都算出来。三者共用同一个似然函数，区别只在是否引入先验、以及最终要一个点还是一个分布。本单元站在第一级，后面两级在信息论与优化分册里会陆续出现。

4.16 常见误解清单

第一句「MLE 一定存在且唯一」。不一定。若数据里全是成功或全是失败，伯努利的似然在 p=1 或 p=0 处取最大，端点处对数发散；若模型不可辨识（两个参数组合给出相同分布），最优点是一条线而不是一个点。第二句「样本越多 MLE 越接近真值」。这要有前提：模型设定正确、样本独立同分布。模型错配时，MLE 收敛到「最接近真分布的那个模型参数」，而不是你心里想的真值。

第三句「对数似然越大模型越好」。在同一份数据、同一族模型里可以这样比；跨数据集比较就没有意义，因为样本量不同会让对数似然按 n 缩放。这也是 AIC、BIC 要补偿样本量的原因。第四句「网格搜索找到的就是全局最大」。网格只覆盖你列的候选点，若真实峰值在两点之间，网格值只是近似；若似然函数是多峰的，粗网格甚至会漏掉更高的峰。本例的似然是单峰凹函数，网格搜索才万无一失。

4.17 为什么种子对似然实验同样重要

本例的采样、正态样本、网格搜索全部由固定种子驱动。伯努利序列的确定性保证了 successes=3579 在任何一次重跑里都一模一样；正态序列用 MLE_SEED+1 作为另一个固定种子，避免与伯努利使用完全相同的均匀数序列——虽然两条序列独立不是统计上的硬性要求，但复用同一条序列会让两个估计的误差产生人为相关，解释起来更麻烦。

网格搜索本身没有随机性，它是确定性的枚举。但它的输入来自采样，所以整个实验的可复现性仍然系于种子这一处。清单里 successes、sample_mean、phat 给 atol=1e-6 而不是宽松容差，正是因为这些量在固定种子下是精确整数；宽松容差会让「种子写错但碰巧接近」的假实现蒙混过关。数值实验的严格程度要和量的确定性匹配——这是贯穿这一册的容差设计原则。

实验记录复现性检查：两次运行逐字节一致

在 examples/ch02/mle_bernoulli/ 目录下按给定编译命令生成可执行文件，连续运行两次并把输出重定向到两个文件，用 diff 比较。按 LCG 的确定性，两次 stdout 必须完全相同；只要不同，就说明采样路径被某个未固定的因素改变了。再把 MLE_SEED 换成一个别的值，输出应该整体变化而网格搜索逻辑不变——这验证了「种子控制数据、不控制算法」这条分工。

4.18 用两个数字把整节收束

把本例的计数记牢：n=10000、k=3579、n−k=6421。三个数字撑起了所有输出：sample_mean=3579/10000=0.357900 是解析 MLE；网格点 0.36 是它在离散候选里的最近邻；ll_at_half=10000×ln(0.5)=−6931.471806 是原假设处的对数似然；ll_at_phat≈3579×ln(0.36)+6421×ln(0.64)=−6522.099301 是峰值处的对数似然。正态那一半也同理：3000 个来自 N(2,1.5²) 的样本，给出 mu_hat≈2.02、var_hat≈2.23。

记住这两个场景的共同结构：先确定参数空间（本例是 p∈(0,1)、μ∈ℝ、σ²>0），写出似然，取对数，求最大。无论模型多复杂，这三步不变。神经网络的巨大参数空间让第三步必须靠数值优化，但第一步和第二步的形状完全相同——这就是这一节被称为「训练本质」的原因。你在本节手算的每一个对数，都在训练循环里以某种形式重复出现。

4.19 似然函数的形状：为什么峰值好找

伯努利的对数似然是凹函数：二阶导恒为负，曲线只有一个峰，没有局部极大值的干扰。这个性质让网格搜索和牛顿法都能可靠工作，也让我们敢用「在候选点算导数符号」来确认峰值位置。凹性不是所有模型都有的——神经网络的损失函数充满局部极小值和平坦区域，优化器能不能找到好解依赖初始化和调参技巧。本例的简洁正是因为它是一个「教科书级」的单峰问题。

理解这一点，你就能分清两类难度。一类是「目标函数容易优化但模型太简单」，另一类是「模型表达力强但目标函数难优化」。MLE 的理论框架同时覆盖两者，差别只在求解难度。本单元演示第一类，让你先把「构造目标函数」这件事学扎实；等到优化分册，再专门处理第二类。这样的分工避免了你一上来就被数值细节淹没，看不见统计主线。

4.20 一个容易被忽略的细节：顺序无关

伯努利样本的出现顺序不影响似然：先成功后失败与先失败后成功，给出同一个 k 和同一个 n，因此同一个似然值。这是独立同分布假设的直接后果——联合概率等于边缘概率的乘积，而乘法可交换。程序里把一万次结果存进数组再逐项调用对数似然，换成流式累加计数再用解析公式，结果完全一样。理解这点，你就能在工程中放心地把批量计算改成增量计算，不必担心顺序改变结论。

小结这一节的要点
  • 似然是「固定数据、变化参数」的函数，它不是参数的概率；
  • 取对数把乘积变和、避免下溢，且因单调性不改变最大值位置；
  • 伯努利 MLE 是 k/n，正态 MLE 的均值是样本均值、方差分母是 n；
  • 网格搜索与解析解互相验证，端点处 log 0 必须用避开或显式处理；
  • 交叉熵就是负对数似然，L2 正则等价于高斯先验下的最大后验估计。

注自测题答案
  1. 概率固定参数、变化数据；似然固定数据、变化参数。似然对参数不积分为 1，不是参数的概率分布，因此不能说参数「最可能」；准确说法是「让已观察到的数据最不意外的参数值」。
  2. 对数似然 ℓ(p)=k ln p+(n−k)ln(1−p)，导数 k/p−(n−k)/(1−p)，令零得 k(1−p)=(n−k)p，即 p=k/n；二阶导恒负，故为极大值。
  3. MLE 优化的是似然函数本身，其方差解的分母是 n；n−1 是总体方差的无偏估计，用于统计推断。做 MLE、描述经验分布、批归一化用 n；做置信区间和假设检验用 n−1。
  4. 网格步长 0.01，phat 只能取两位小数，最接近 0.3579 的点是 0.36。把步长细化到 0.0001 后网格点会更接近 0.3579，离散化误差随之缩小。
  5. p=0.5 时每项的 ln p 与 ln(1−p) 都是 ln 0.5≈−0.69314718056，共 10000 项，故 ℓ=10000×(−0.69314718056)=−6931.471806，与打印一致。
  6. p=0 且样本成功时 ln(0)=−∞，打印会出 −inf，若所有候选都如此还会让比较失效。处理办法：避开端点（留小间隔）、加一个极小量 ε 用 ln(p+ε)、或显式判断零概率并返回很大的负数。
  7. 分类交叉熵就是负对数似然除以样本数；对独热标签，目标分布只有一个取值为 1 的格，其余为 0，−Σq ln q 中只有 q=1 那项有贡献而 ln 1=0，故目标分布的熵为零，交叉熵退化为 −ln p(真实类别)。
