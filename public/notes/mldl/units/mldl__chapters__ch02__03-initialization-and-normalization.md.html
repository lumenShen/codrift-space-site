2.1 先看工程长什么样

前面两个单元的小网络只有一两层，随便给个随机初值也能训起来。从这一单元起，我们开始把层数加到五层，问题立刻变了：同样尺度的权重，在浅层只是「数值不太好看」，在深层会把前向方差放大三千万倍，或者压到小数点后六位只剩一个 3。这一节要回答的就是这件看似琐碎的事——权重初值到底该取多大，以及为什么不归一化就训练不动。

「深层难训」这句话常被当成经验之谈，其实可以拆成两个可测量的现象。第一是前向信号失控：输入经过若干层后要么数值爆到几千万，要么缩到机器精度附近，后面的层看到的输入已经失去区分度。第二是反向信号失控：上一单元推过的 δ 链要连续乘很多次权重转置与激活导数，任何一次乘性偏差都会被指数放大。两者互为镜像，但观测量不同——前者看激活方差，后者看梯度范数。本例只跑前向并量方差，因为对同形网络来说两边增益同阶，看一边就足以定位问题；真训练里两边都该盯。

例子放在 books/mldl/examples/ch02/init_normalize/。它仍然是纯 NumPy 手算加 PyTorch 对照：initnorm.py 负责权重生成、标准化与五层前向链，main.py 负责固定三种随机源、跑七种配置、打印方差与 ReLU 死亡率。清单 ml06-init.json 用 mode=numerical，把十一个真跑读数钉成黄金值；程序自己不打判定字样，判定权在闸门。

第 2 帧里旧目录只保留了入口与模块两个文件，清单被省略——图元是示意图，不必把上一节的全部文件重画一遍，但与本帧论点有关的结构必须都在。initnorm.py 里没有 torch，main.py 只在最后用 torch 双精度重算一次 He 链的方差做独立参照；这层独立性让「方差数字是手算出来的」这句话有第二条证据。

工程惯例为什么用方差而不是用 loss 来诊断初始化

初始化坏掉时，loss 的表现经常伪装成别的问题：太小会「loss 几乎不降」，太大会「loss 突然变成 nan」。两者都可以靠调学习率缓解一点点，于是你很容易在错误方向上耗掉半天。方差是更直接的观测量：它不看优化器怎么更新，只看信号经过五层之后还剩多少。本例把每层激活方差打成一个列表，第一次失控出现在哪一层一眼可见。工程惯例里这叫「前向健全性检查」，不是标准，但它的代价只是几行 .var()，比追 nan 便宜得多。

2.2 方差为什么会一路变：连乘的账

先看线性层。设某层输入 a 的每个分量均值 0、方差 v，权重 W 独立同分布、均值 0、方差 σ²，fan_in 是输入维度，忽略偏置。输出 z = aW 的方差近似是

var(z) = fan_in · σ² · v

因为输出的一个分量是 fan_in 个「输入乘权重」之和，独立项相加方差相加。想让方差在层间保持不变，就要令 fan_in · σ² = 1，也就是 σ = 1/√fan_in。这就是所有 1/√n 的来源：它不是玄学常数，是「让每层乘性增益接近 1」的直接结果。

这条推导依赖三个假设，值得逐个认清。第一，输入与权重均值近似为零，否则交叉项会贡献额外方差；所以 BatchNorm 和 LayerNorm 都要先减均值。第二，权重相互独立；参数共享的卷积层不满足这点，但方差的量级估计仍然可用，只是 fan_in 要按「每个输出位置连接的输入个数」重新数。第三，激活近似线性；tanh 在小信号区近似恒等，ReLU 在正半轴导数为 1，所以补偿系数不同。假设不成立时，1/√n 只是起点，仍需用实测方差校准。把公式连同假设一起记住，才不会在换激活或换结构时照抄常数。

反向时类似。上一单元的 δ 回传规则里要乘一次 (W⁽ˡ⁺¹⁾)ᵀ，均值零时方差同样按 fan_out · σ² 缩放（fan_out 是下一层宽度）。层与层都取同形时 fan_in = fan_out，前向和反向的增益一致；宽窄变化很大时，只按 fan_in 或只按 fan_out 取尺度会让其中一个方向失衡，这也是后面用 2/(fan_in+fan_out) 折中的理由。

举一个失衡的例子：某层把 64 维压到 16 维，若按 fan_in=64 取 σ²=1/64，前向增益是 1，反向增益却是 fan_out·σ² = 16/64 = 0.25，梯度每过这样的层就掉到四分之一；反过来按 fan_out=16 取尺度，前向增益变成 4，激活逐层膨胀。取调和平均 2/(64+16)=0.025 时，前向增益 1.6、反向增益 0.4，两边偏离都不算离谱。这就是为什么框架默认用 fan_in 与 fan_out 一起算尺度：它不追求某一方向完美，而是让两个方向都别跑太远。本例各层同形，这个差别被隐藏了，换到编码器—解码器结构就会立刻显形。

第 3 帧的星号落在第四层输出上，是为了强调「失控不是最后一步突然发生的」：每层的增益只要偏离 1 一点点，连乘五次就会放大成显著偏差。本例的朴素初始化 σ=1、fan_in=64，单层增益是 64×1 = 64，ReLU 再折半约 32，五层下来约 32⁵ ≈ 3.3×10⁷；真跑打印的 var_naive=36246816.664773 正是这个量级。反过来取 σ=0.05，单层增益约 32×0.0025 = 0.08，五层后只剩 0.08⁵ ≈ 3×10⁻⁶，对应 var_vanish=0.000003。

大白话把每层想成一级放大器

信号从输入出发，每过一层就像经过一级放大器。放大器增益略大于 1，五级之后声音震耳；略小于 1，五级之后几乎听不见。 Xavier 与 He 做的事情，就是把每一级放大器的旋钮拧到增益约等于 1 的位置。 BatchNorm 更像每级后面加了一个自动音量控制器，不管前一级送来多大声音，先归一到标准响度再往下传。严谨说法是：初始化控制方差的连乘增益，归一化在每层重新标定分布。

这里要区分前向方差与梯度方差。上面推的是激活值在层间的变化；梯度的回传要乘转置权重与激活导数，增益是 fan_out·σ² 再乘一个激活导数平方的期望。对称网络里两者同阶，所以控制住前向通常也控制住反向；不对称结构里必须两边都算。线性代数分册把反向解释成转置 Jacobian 的连乘，本单元给那个连乘补上了尺度估计：奇异值普遍小于 1 就指数衰减，大于 1 就指数爆炸，而 σ≈1/√n 正是让随机矩阵的奇异值落在 1 附近的统计手段。

2.3 四种权重尺度：Xavier、He 与两种朴素值

initnorm.py 的 weights 提供四种尺度。Xavier 均匀分布在 ±√(6/(fan_in+fan_out)) 之间，均匀分布的方差是 limit²/3 = 2/(fan_in+fan_out)，同形时约 1/fan_in；它是为零中心、导数在 1 附近的激活（如 tanh）设计的。He 正态取标准差 √(2/fan_in)，多出来的 2 是为了补偿 ReLU 把约一半激活置零造成的方差折半。两种朴素值分别是标准差 1.0（爆炸）和 0.05（塌缩），它们是反例的角色，不是可选配方。

为什么 ReLU 要多一个因子 2？设 z 对称零均值、方差 v，ReLU 把负值变零，正值保留，于是 E[ReLU(z)²] = ½E[z²] = v/2。要让下一层的激活方差仍为 v，线性部分必须把方差放大 2 倍，即 fan_in·σ² = 2，所以 σ² = 2/fan_in。Xavier 面对 tanh 时不用这个补偿，因为 tanh 是奇函数、正负都保留，在小信号区近似恒等，方差主要由权重尺度决定。把 He 用在 tanh 上会偏大，把 Xavier 用在 ReLU 上会偏小——偏多少要看激活的二阶矩，这就是「配方要配激活」的含义。

均匀与正态的选择也值得说一句。Xavier 常用均匀分布，因为它的尾部更短，极端大权重更少；He 常用截断或直接的正态分布，因为推导里用到的是二阶矩而非分布形状，正态更方便采样。本例按常见配方实现：Xavier 用 ±√(6/(fan_in+fan_out)) 的均匀分布，其方差恰为 2/(fan_in+fan_out)；He 用标准差 √(2/fan_in) 的正态分布。框架里的实现会多一个 gain 参数，用来把激活的二阶矩显式写进公式——它的默认值正是上面这些推导的结果。自己写初始化时，先确认框架默认配置与你用的激活是否一致，比记住某个函数名更重要。

第 2 帧的数字直接来自 stdout 的 gain:[21.940366,899.699445,28283.802826,1055630.735184,36246816.664773]：这是朴素大方差配置下五层激活方差的列表，每一格都比上一格大一个数量级以上。注意第 2 帧和第 3 帧都是自包含的——它们各自重画了本帧要展示的节点与边，没有依赖第 1 帧的上下文。读这种多帧图时，比较相邻帧的差异才是重点：同样的五层结构，只换权重尺度，结局一个冲上天一个沉到底。

陷阱把 Xavier 和 He 当成可以互换的默认选项

你会看到很多代码里写 nn.init.xavier_uniform_ 就照抄，换到 ReLU 网络也不改；你会误以为「反正都是 1/√n 量级，差一个 2 不大」。真相是 ReLU 的方差折半使 He 的 2/fan_in 成为必要补偿，用 Xavier 会让信号逐层偏小，深层里尤其明显。症状不是立刻报错，而是浅层梯度比深层大很多、训练后期几乎只有最后几层在动。查法：把每层的激活方差打出来，若逐层递减，先怀疑初始化与激活不匹配，再怀疑学习率。

2.4 ReLU 死亡：负半轴上的永久沉默

ReLU 是 max(z,0)，负输入的激活是零，导数是 0。问题在于：一旦某个神经元对所有训练样本都落在负半轴，它的激活恒为零，反向时 dz = dh · 0 = 0，权重梯度 dW = aᵀ·dz 也恒为零。这个神经元从此再也不会被更新——它「死了」。死亡本身不是灾难，死太多才是：如果一层里大半神经元都死了，这一层的有效宽度骤减，表达力随之塌掉。

死亡和坏初始化直接相关。若权重尺度过大且偏置被推到明显负值，线性分数整体偏负，落入负半轴的比例就高。本例专门量了一次：main.py 用朴素大方差权重算出线性分数，再统一减去 2.0 当偏置，真跑得到 dead_relu=0.596920——约六成激活是零。这不是模型学到「这些特征不重要」，而是尺度与偏置共同把神经元推过了零点。学习率过大会加速这个过程：一次激进更新把偏置推得很负，后面就再也回不来了。

从微分层面看，死亡是「局部导数为零」被永久锁死。反向公式里 dz1 = dh * (1 - h²) 这一项用的是 tanh，换成 ReLU 就是 dz = dh * (z > 0)；当 z <= 0 时整个指示函数为 0，不论上游敏感度 dh 多大，传回去的梯度都是 0。权重梯度 dW = aᵀ @ dz 跟着变成零矩阵，偏置梯度也为零。优化器看到零梯度就什么都不做，下一次前向这个单元仍然输出零——正反馈闭环就此形成。Leaky ReLU 把负半轴斜率改成 0.01 之类的小正数，正是为了给这个闭环留一道缝：梯度虽小但不再严格为零，单元还有机会被拉回正半轴。

陷阱用「ReLU 输出稀疏是好事」掩盖死亡

你会看到激活里大量零值，觉得「稀疏表示，效率高」；你会误以为这是网络自己学会了只保留重要特征。真相要分两种情况：正常的稀疏是不同样本激活不同神经元，整体统计上每个神经元都还有梯度；死亡是同一个神经元对所有样本都输出零，它的梯度永久为零。查法是在若干 batch 上统计每个神经元的激活率，若某个单元在所有 batch 里都是 0，它已经死了。缓解手段包括减小学习率、换用 Leaky ReLU 或 PReLU（负半轴保留一个很小的斜率）、以及给偏置加正则，让它们不要往很负的方向漂。

ReLU 也不是没有优点。正半轴导数恒为 1，不会像 sigmoid 那样在两端饱和，所以梯度不会因为激活导数变小而指数衰减；计算上只是一次比较，比指数函数便宜得多。今天的深层网络几乎都用它或它的变体，代价就是上面这条死亡风险。ml07 的卷积网络里也会遇到同样的事，只是那里的「神经元」换成了某个卷积核的某个输出通道。

2.5 BatchNorm：把每层重新拉回标准尺度

BatchNorm 的训练期公式很短。对一个 mini-batch 的每个特征维度 k，先算批均值 μ_k 与批方差 σ_k²，再做标准化 x̂ = (x - μ_k)/√(σ_k² + ε)，最后用可学习的 γ、β 做缩放平移 y = γ·x̂ + β。ε 是防止除零的小常数，γ、β 让网络能自己决定「要不要保留原来的尺度与偏移」——如果恒等映射最优，学成 γ=σ_k、β=μ_k 即可。

轴的选择决定语义。本例的张量形状是 (batch, features)：axis=0 表示沿 batch 维求统计量，也就是对每个特征在「这一批样本」上标准化，这是 BatchNorm；axis=1 表示每条样本在自己的特征维上标准化，与其他样本无关，这是 LayerNorm。把轴写反不会报错——两个维度都能求均值——但意义完全不同：写反之后，BatchNorm 会让样本之间互相泄露信息，训练与推理的行为也对不上。

BatchNorm 最容易被忽略的是训练与推理走两条路。训练时用当前 batch 的统计量，同时用滑动平均累积一个运行均值与运行方差；推理时不再有 batch 统计可用（可能一次只来一条样本），改用累积的运行统计量。如果这两个路径不一致，会出现这样的怪事：训练时标准化后方差恰好是 1，推理时喂进同一种分布的数据，输出尺度却不对。本例把这件事做成一个最小实验：同一批标准差为 2 的数据，训练期标准化后 bn_train_var=1.000000，推理期按运行方差 1 缩放后 bn_eval_var=4.006719——后者正好保留了原始散布（末位偏差来自有限样本的抽样噪声）。

实验记录训练期与推理期：同一批数据，两种方差
  • 工具链：3.14.3；命令 python src/main.py，工作目录为例子目录；三种随机源固定为 12345；
  • 数据：4096 行 64 列，每个元素来自标准差为 2 的正态分布；
  • 训练期：沿 batch 维减均值除批标准差，bn_train_var=1.000000；
  • 推理期：假设运行方差为 1，只做除法，bn_eval_var=4.006719，即原始方差被完整保留；
  • 结论：训练/推理必须用不同分支；把分支写反或漏掉运行统计量，模型上线后的行为会与验证时不一致。

γ 与 β 的初值也值得交代。常见做法是 γ=1、β=0，让归一化层在训练开始时近似恒等；之后它们是可训练参数，由梯度决定要不要改变尺度与偏移。eps 通常取 1e-5 量级，本例用 1e-12 是因为输入尺度小、追求与解析值完全一致；它只在方差几乎为零时起作用，正常批上方差远大于 eps，加不加几乎没有区别。把 eps 当成「防止除零的数值保险」而不是超参数去调，就不会在它上面浪费时间。另一个常见误区是把标准化放在激活之后：BatchNorm 的标准写法是线性分数之后、激活之前，这样标准化的是即将进入非线性的信号，效果最可控。

还有一条纪律：BatchNorm 的统计量来自 batch，意味着 batch 越大估计越稳。 batch 很小时（比如 2 或 4），批方差噪声很大，训练会抖；分布式训练里还要跨卡同步统计量。相比之下，LayerNorm 对每条样本独立标准化，不依赖 batch 大小，这就是为什么它在序列模型和 Transformer 里成了默认选择。代价是它失去了 BatchNorm 那点「用 batch 统计带来正则化噪声」的效果——没有免费午餐。

2.6 LayerNorm 在 Transformer 里的位置

Transformer 块的标准画法是：输入先经过 LayerNorm，再进注意力或前馈网络，然后把结果与原输入相加（残差）。也有把 LayerNorm 放在残差相加之后的「post-norm」写法，两种都能收敛，差别在训练稳定性与梯度尺度上。pre-norm 把归一化放在子层之前，恒等通路因此不被归一化改写，浅层梯度更稳，深层模型常用；post-norm 把归一化放在相加之后，输出尺度被严格约束，但深层训练需要更仔细的学习率预热。本例只演示「归一化 + 残差」这两个零件，不评价两种排布的优劣——那是真实大模型训练里的经验问题，需要看具体深度、宽度与优化器。

把 LayerNorm 与上一节的 BatchNorm 并排看，差别集中在「统计量来自哪里」。BatchNorm 的均值方差来自同一特征在 batch 上的取值，因此带进了其他样本的信息；LayerNorm 的统计量只来自当前样本自己的特征向量，与其他样本无关。这个差别带来三个后果：LayerNorm 不依赖 batch 大小，小 batch 也能用；推理时不需要保存运行统计量，行为天然一致；但它也失去了 batch 统计带来的轻微正则化噪声。序列模型还有第三个理由：一条序列里每个位置都是一条独立样本，逐位置标准化对变长输入天然友好。本单元不展开注意力机制——那是 ch03 的事——这里只关心一件事：为什么序列模型偏爱 LayerNorm。因为一条序列里每条样本（每个位置）都有自己的特征向量，LayerNorm 逐位置标准化，既不看 batch 里别的序列，也不看同一序列里别的位置，所以变长序列、单条推理都不受影响。

第 3 帧的星号落在 short 上，这是整节的收束：残差连接把雅可比变成 I + J_F，其中 I 是恒等映射，它的导数恒为 1。即使子层的雅可比很小，梯度也能沿恒等通路原样回传，浅层参数因此收得到更新。本例量了「只加残差、不配归一化」的情形：res_var=21.242281，比 He 单独用的 1.115581 大了约十九倍。原因不难算：残差分支 z = Wx + x，若 Wx 的方差与 x 相当，相加后方差约翻倍，ReLU 再折半，单层增益约 1.5，五层就是 1.5⁵ ≈ 7.6；再叠上随机波动，真跑读到 21。这说明残差不是随便加的加号——它改变了增益预算，因而常常要与归一化、缩放因子一起设计。

工程惯例残差连接的正确读法

这是工程惯例而非标准。把残差想成「给梯度修一条高速路」：主路要经过子层的矩阵乘与激活，辅路是恒等映射，两者相加。前向时信息可以原样传到更深的层；反向时梯度可以绕过子层直接到达浅层。代价是通道数必须匹配（形状不一致要用 1×1 卷积或线性投影对齐），以及加法那一处的尺度会变大——所以有些实现给残差分支乘一个 1/√L 之类的缩放。把它当成「多加一条路」，而不只是「加一个数」，读 Transformer 代码时会顺很多。

var_xavier 比 1 小一些并非错误。Xavier 保证的是线性分数 z 的方差不被放大，但 tanh 本身会把方差往小压，且这种压缩会逐层累积到一个不动点；本例五层后停在约 0.1。因此「Xavier 配 tanh 不一定恰好得到方差 1」这句话要记牢：初始化稳的是进入激活之前的尺度，激活函数还会再改一次。He 配 ReLU 之所以更接近 1，是因为前面算过的 2 倍补偿正好对上 ReLU 的方差折半，两个效应抵消。

2.8 把这条链接回反向传播

现在把本单元和上一单元接起来。δ⁽ˡ⁾ = (δ⁽ˡ⁺¹⁾ (W⁽ˡ⁺¹⁾)ᵀ) ⊙ φ′(z⁽ˡ⁾) 里有两个缩放来源：权重的转置，以及激活导数。若每层的 Wᵀ 谱半径都小于 1，连乘 L 层后梯度按指数衰减，浅层收不到更新；若大于 1，梯度指数放大，一次更新把权重推到溢出。本例的 gain:[...] 是前向方差的轨迹，但同样的连乘结构也作用在反向敏感度上——这正是线性代数分册说的「反向是转置 Jacobian 的连乘」，本单元给它补上了尺度估计。

把这条链和线性代数分册的奇异值接上，尺度估计会更严谨。一个随机矩阵把向量拉长还是压短，由它的最大与最小奇异值决定；σ≈1/√n 让同形随机矩阵的奇异值集中在 1 附近，于是单层的增益也集中在 1 附近。反向时要看的是整条乘积链的奇异值分布，而不是某一层：即使每层平均增益接近 1，少数几层的极端奇异值也可能在几十层里累计出可观偏差。这也是为什么「初始化正确」只是必要条件，还要配归一化与残差——它们分别从分布和拓扑上限制这条链的偏离。

梯度消失的症状是：浅层参数几乎不动，损失曲线早早变平，看起来像「学习率太小」。梯度爆炸的症状是：损失变成 nan，或者权重在几个 step 内涨到极大值。两者的根都在增益失控，因此根本对策是初始化、归一化与残差通路，而不是单纯调学习率。学习率能缓解，但它改变不了「每层增益偏离 1」这个乘法结构；把学习率调小十倍，爆炸只是晚几步发生。

陷阱用梯度裁剪以为治好了爆炸

你会看到裁剪之后 loss 不再变 nan，于是宣布问题解决了；你会误以为梯度爆炸就是「梯度太大，砍小就好」。真相是裁剪只处理已经出现的大梯度，不处理产生它的增益结构。每层仍把信号放大几十倍，裁剪只是在最后把总数压回去，方向信息已经被扭曲，浅层与深层的更新比例依然失衡。它是有效的工程保险，尤其配合残差与归一化一起用，但不能替代正确的初始化。判断办法：把裁剪阈值临时去掉，若立刻回到 nan，说明根因还在。

要让这条判断更具体，可以做一次最小对照：把网络冻在初始点，只跑前向与反向、不做任何参数更新，打印每层激活方差与每层梯度范数。若两者都逐层放大一个数量级，问题在权重尺度；若激活正常而梯度异常，问题多在损失缩放或反向实现；若梯度正常但训练仍崩，问题转向学习率与更新规则。这个「冻结初值体检」不花训练时间，却能把初始化、损失、优化器三类原因分开。本例的七条链就是在做前半段——它不更新任何参数，只看前向方差，因此读数不受优化器选择干扰，可以当作纯粹的结构诊断。

工程惯例按顺序执行的深层网络体检

第一步，打印每层输入与输出的方差，看是否逐层放大或衰减一个数量级以上；本例的 gain:[...] 就是模板。第二步，确认初始化与激活匹配：tanh 用 Xavier，ReLU 用 He，别混。第三步，统计 ReLU 激活率，若某些单元在所有 batch 里都是零，先降学习率或换 Leaky ReLU。第四步，确认 BatchNorm 的训练与推理分支各自独立，并检查运行统计量是否真的被更新。第五步，确认残差分支的形状匹配与尺度预算；单加残差就可能把增益推到 1.5 以上。第六步，最后才动学习率与梯度裁剪。六步都不需要读框架源码，打印几个方差与激活率就能做完。

三个单元连起来读，方法上的一致性比结论更值得记：ml04 用独立手算模块给 XOR 训练做基线，ml05 用手写梯度、autograd 与中心差分三方对拍，本例用 NumPy 与 torch 在同一组权重上重算方差。每一次都是「先建立独立路径，再让数字说话」。工具换了、网络深了，这条纪律没变。下一章进入卷积网络，参数共享会改变 fan_in 的算法，但本节这套方差账本照样适用——你只需要重新数「一个输出连到多少个输入」：对 3×3 卷积核就是 9 乘通道数，而不是整张输入图的像素数。把这一点数对，Xavier 与 He 的公式可以原样搬过去。

小结这一节的要点
  • 线性层前向方差约 fan_in·σ²·v；取 σ=1/√fan_in 让增益接近 1，连乘多层才不爆炸或塌缩；
  • Xavier 用 2/(fan_in+fan_out) 配 tanh，He 用 2/fan_in 配 ReLU，多出的因子 2 补偿 ReLU 的方差折半；
  • ReLU 死亡源于负半轴导数恒零：神经元一旦对所有样本输出零，梯度永久为零；真跑 dead_relu=0.596920；
  • BatchNorm 沿 batch 维标准化并在推理期改用运行统计量；LayerNorm 沿特征维、逐样本独立，适合 Transformer；
  • 真跑 var_he=1.115581 最稳，朴素大方差五层冲到 36246816.664773，残差单用 res_var=21.242281，说明残差也要算进增益预算。

  2. 对对称零均值的 z，E[ReLU(z)²] = ½E[z²]，方差折半；He 取 σ²=2/fan_in 让 fan_in·σ²=2，乘上折半后恰好回到 1。换成 sigmoid 不成立：sigmoid 是零中心不成立、且有饱和区，它的导数在原点约 0.25，方差补偿要按该激活的二阶矩重新算，通常不能照搬 He。
