1.1 先看工程长什么样

这一册承接桥接册的 PyTorch 写法，但把问题从「会算梯度」推进到「会训练模型并判断它学没学会」。第一步仍然是把工程骨架摆出来：一个入口脚本负责造数据、调用算法、打印证据；一个本地模块放全部可复用的计算；一个清单声明黄金值，让闸门从真实标准输出里逐行对账。本单元的例子叫 linreg_fit，它用固定种子造六十个带噪的直线样本，然后同时跑闭式解和两百步梯度下降，最后把两条路的参数与损失摆在一起。

第 2 帧的 fit.py 是本单元的核心：造数据、拼设计矩阵、求闭式解、跑梯度下降、算决定系数、做梯度对账，六件事都放在这一个模块里。入口只负责调度与打印。第 3 帧的清单不是装饰：它把标准输出里的十个数值声明为黄金值，容差写成 atol 一乘十的负六次方。从此以后，任何人改动算法或数据，只要这十个数变了，闸门就会报出来——想让闸门变绿，要么证明改动是有意的并更新黄金值，要么把代码改回去。

这个骨架与桥接册第二单元完全同构，差别只在模块名和算法内容。入口用 from fit import ... 导入同目录模块，之所以能直接导入，是因为解释器会自动把入口脚本所在的 src 目录放进模块搜索路径。清单里 sources 两个条目顺序不能反：第一个是入口，闸门会真的执行它；第二个是被导入的本地模块，闸门会先做语法检查再让它随着入口一起运行。

1.2 监督学习到底在学什么

监督学习的输入是一批「题目连同答案」的样本。第 i 个样本写成一对 (x_i, y_i)：x_i 叫特征或输入，y_i 叫标签或目标。本单元的特征只有一个数——横坐标；标签也只有一个数——纵坐标。六十对样本摆在一起，就是训练集。要注意「监督」二字的意思不是有人盯着程序跑，而是每个输入都配了正确答案，算法可以用答案来纠正自己。如果只有输入没有答案，那就是另一类问题，本册暂不涉及。

第二个要素是假设，也就是你允许模型长成什么样。本单元把假设限定成一条直线：y = w x + b。这里的 w 与 b 不是数据，而是待求的参数；选定「用直线」这一步，就已经排除了曲线、折线、分段函数等所有别的可能。假设空间越小，越不容易被噪声带偏，但也越可能连真实规律都装不下——这个张力会在第三单元以偏差与方差的名字重新出现。现在先记住：学习不是在所有函数里挑最好的，而是在你事先划定的那一小类函数里挑最好的。

第三个要素是损失，它把「挑最好的」变成一个有唯一答案的优化题。损失是一个函数，吃进参数和全部样本，吐出一个数：数越小，说明模型在这批样本上犯的错越少。本单元用平方误差的平均值，也就是每个样本的预测值与真实值之差的平方，再取平均。平方有两个好处：正负误差不会互相抵消，而且函数光滑可导，后面能用梯度。代价是对离群点敏感——一个错得很远的样本会因为平方而被放大，这一点在后面讲鲁棒性时还会提到。

把三要素串起来就是经验风险最小化：在假设空间里找一组参数，使训练集上的平均损失最小。「经验」二字提醒我们，这个最小值只是对训练集而言的；它并不保证模型在没见过的数据上同样好。本单元先把优化这件事讲透，第三单元再补上泛化那一半。

大白话用大白话说清三要素

把学习想成学生刷题。数据就是练习题和答案；假设就是学生事先被限定只能用一种套路答题，比如「一律套直线公式」；损失就是每答一题扣多少分，错题扣分的平方。所谓的「学」，就是在这个套路里反复调整两个旋钮，让总分扣得最少。学生把练习题背得再熟，也可能换一套题就不会——这就是训练集损失与测试集损失的差别，第三单元会专门对付它。

1.3 把直线写成矩阵：设计矩阵登场

如果只有一个样本，写 y = w x + b 很自然；一旦有六十个样本，就该换一种写法。把每个样本的第一列填成常数一、第二列填成它的横坐标，得到一个六十行两列的矩阵 X，叫设计矩阵。把两个参数竖着堆成向量 [b, w]，那么六十个预测值可以一次性写成 X @ beta。第一列的一乘以 b 给出截距，第二列的 x 乘以 w 给出斜率，两列相加正好是那条直线在六十个横坐标上的取值。

这样改写不只是为了代码好看。它把「找一条直线」变成「找一个向量」，于是线性代数里关于矩阵的全部工具都可以搬过来：列空间、投影、 Gram 矩阵、条件数、奇异值分解。更实际的一点是，代码里只需一次矩阵乘法就能算出全部预测，不必写六十次循环。桥接册讲过的数组广播和 @ 运算在这里派上用场——beta 是长度为二的向量，X 的形状是六十行两列，矩阵乘法自动把每个参数roadcast到对应的列上。

第 1 帧是数据的原貌，第 2 帧给出了设计矩阵的两列，第 3 帧把预测与残差接上。请特别看第 2 帧那一列全一：它不是多余的数字，而是把截距 b 伪装成一个「特征」的技巧。有了这一列，截距和斜率就统一成了同一个向量的两个分量，后面求梯度时完全可以一视同仁。如果忘了这一列，模型就被强迫穿过原点，拟合出来的斜率会被截距的缺失拧到一个错误的位置上。

生成器把横坐标取成从零到十的六十个等距点，真值设成 2.5 x + 1.0，再叠加标准差零点五的高斯噪声。噪声不是 bug，而是现实：真实观测几乎不会精确落在一条直线上。正因为有噪声，闭式解才不会恰好等于真值 w=2.5 与 b=1.0，而是靠近它们的一个估计。固定种子让这份噪声每次都一样，于是这个估计可以当成可复现的黄金值写进清单。

这段代码里有两层随机源：入口在启动时固定了 random、numpy 与 torch 三种种子，模块内部又用一个以固定数字播种的局部生成器来抽噪声。两层都写死是故意的：局部生成器保证数据生成不受别处调用随机函数的影响，入口固定三种种子则保证任何将来加入的随机操作也可复现。真正的训练模式里，种子要由闸门通过环境变量注入，以便跑对照种子；本单元只做解析量与框架量的对照，写死数字就够了。

1.4 平方误差：把直觉写成公式

有了 X 和 y，损失可以写得很短。记残差向量为 r = y - X @ beta，那么损失就是 r 每个分量平方后取平均，也就是 mean(r ** 2)。用矩阵记号写是 (1/n) (y - X beta)^T (y - X beta)。这里的二分之一或一除以 n 只是常数因子：它不改变最优参数的位置，却让梯度的表达式干净，也让不同样本数的损失值可以横向比较。

为什么不用绝对误差？绝对值在零点不可导，优化时会遇到「尖角」，需要另一套工具；平方处处光滑，梯度就是一个线性表达式，能直接解方程。为什么不用误差的四次方？四次方对离群点更敏感，而且没有平方误差这样干净的几何解释。选择损失从来不是「哪个更正确」，而是「哪个假设与当前问题匹配、哪个优化起来可控」。这一册始终用平方误差做线性回归，用交叉熵做分类，正是因为这两个选择与各自的模型假设相配。

把损失对 beta 求导是关键一步。逐分量展开可以得到梯度 ∇ = (2/n) X^T (X beta - y) = (2/n) X^T r。它的形状是两行一列，与 beta 一致。直观读法：梯度是「每一列特征与残差的内积」组成的向量。如果某一列与残差正相关，说明增大对应的参数能减小损失，梯度就指向那边；如果已经正交，说明这一列再也解释不了残差里的任何结构，参数就到了最优附近。

这个「内积为零」的读法直接通向下面的几何图像。它也是梯度检查的公式来源：本单元最后会把手写的 (2/n) X^T r 与框架 autograd 的结果相减，最大绝对差写进 grad_diff。真跑得到零，说明我们对梯度的推导和框架的计算在这组数据上逐位一致。

陷阱以为损失越小模型越好，会被坑在哪

你会看到：把设计矩阵加几列随机噪声特征，训练损失立刻下降，于是你认定模型变好了。你的第一反应是「损失可是优化目标啊」。真相是：损失只是在训练集上量的，多出来的列给了模型更多自由度去贴合噪声，下降的那部分很可能是对噪声的记忆。判断办法是把数据拆成训练与测试两份，看测试损失是否同步下降；第三单元会用一个九次多项式把这件事做得非常直观。本单元先建立优化直觉，别急着把训练损失当成最终成绩。

1.5 最小二乘的几何：投影与法方程

现在换一副眼镜看同一个问题。设计矩阵 X 有两列：一列全一，一列横坐标。这两列张成一个二维平面，躺在六十维的观测空间里。任意一组参数 beta 都把 X 的两列按系数加起来，得到一个落在这个平面上的向量 X beta，也就是拟合值。观测向量 y 是六十维空间里的另一个点，通常不在这个平面上，因为我们故意加了噪声。

最小二乘要找的是平面上离 y 最近的那个点。几何上，最近点就是从 y 向平面作垂线的落点，也就是正交投影。垂线向量正是残差 r = y - X beta。「垂直」意味着残差与平面里任何一个方向的内积都为零；只要检查平面的一组基，也就是 X 的两列，就够了。于是得到正交条件 X^T r = 0，把 r 展开就是 X^T (y - X beta) = 0，整理之后恰好是 X^T X beta = X^T y。这条方程叫法方程，它与「梯度等于零」是同一件事的两种说法。

第 1 帧把观测点、平面和距离都画出来了；第 2 帧强调投影点仍然在平面内，残差是垂直的那一段；第 3 帧把几何语言翻译成代数语言：X^T pred 与 X^T y 相等，因为两者之差是 X^T resid，而它为零。这一段翻译很重要——它解释了为什么法方程里会出现 X^T X 这个看起来有点突兀的矩阵：它其实就是两列特征两两做内积得到的 Gram 矩阵。

投影视角还顺手解释了另一件事： fitted value 的平方和不会超过观测值的平方和。因为 pred 是 y 在子空间上的投影，而投影不会把向量变长。这个事实在推导决定系数的分解时会被用到。更重要的是，它告诉我们残差里剩下的部分与模型已经解释的部分是正交的，不能再从同一组特征里榨出信息；想继续降低残差，只能引入新的特征或者放宽假设空间。

1.6 正规方程：一步解出参数

当 X^T X 可逆时，法方程可以直接解出 beta = (X^T X)^{-1} X^T y。这就是正规方程给出的闭式解。它之所以可逆，是因为两列特征既不共线也非零：全一列与横坐标列没有任何线性关系，除非所有横坐标都相同。一旦出现共线，比如你同时放入「身高厘米」和「身高毫米」两个特征，X^T X 就会奇异，闭式解不存在——这时需要删特征或者改用能处理秩亏的方法。

代码里用 np.linalg.solve(X.T @ X, X.T @ y)，而不是先算逆再相乘。两者在数学上等价，数值上却不是一回事：显式求逆会把舍入误差放大，而且在矩阵接近奇异时可能给出一个看起来合理、实际上完全不可靠的答案。求解器用分解法直接解线性方程组，通常更稳、也更快。这个习惯从线性代数分册延续到这里：看到逆矩阵就想「能不能改写成求解」。

实验记录为什么闭式解的数值稳定性值得单独说
  • 条件数会平方：若设计矩阵的条件数是 k，那么 X^T X 的条件数大约是 k 的平方，原本温和的病态会被放大成严重的病态；
  • 这里的设计矩阵只有两列且横坐标跨度适中，条件数很小，所以闭式解与求解器结果完全可信；
  • 特征一旦很多、量纲又差得很远，比如一列取值在零到一、另一列在零到一百万，正规方程就会把小特征的信息淹没；
  • 稳妥做法是先把特征标准化，或者直接走基于奇异值分解的最小二乘函数；那份函数不构造 X^T X，因此不会承受条件数平方的代价。

1.7 梯度下降：不解方程，一步一步走

闭式解很干脆，但有两个前提：矩阵要能装进内存，而且 X^T X 要可逆。特征一多、样本一大，这两条都可能不成立。梯度下降换了一种思路：不从起点一步跳到答案，而是反复问「往哪个方向走损失下降最快」，然后走一小步。方向由负梯度给出，步长由学习率控制。公式写作 beta_{t+1} = beta_t - lr * (2/n) X^T (X beta_t - y)。

学习率是这里最要紧的超参数。它太大，一步跨过谷底，损失会在两边来回反弹甚至发散；它太小，每一步都像蚂蚁搬家，两百步走不到地方。对平方损失来说，损失曲面是一个碗，曲率由 X^T X 的特征值决定，学习率必须小于某个与最大特征值有关的阈值。本单元取零点零一、从零出发跑两百步，是专门为这组数据挑的：既稳定，又能看出迭代解与闭式解之间的差距。

第 2 帧与第 3 帧是两条独立路径，第 4 帧把它们拉到一起比较。注意第 3 帧那条 data -> grad：梯度下降每一步都要重新计算残差，也就是重新把全部样本过一遍；闭式解则把数据压成 X^T X 与 X^T y 之后就不再回头看样本。这正是两条路的根本差别——一次大计算对上许多次小计算。数据规模变大时，前者受限于矩阵规模，后者受限于迭代次数与每步的吞吐。

真跑给出的 w_gd=2.570612 与 w_closed=2.542644 不相等，这不是 bug，而是两百步还没走完的证据。相应的损失 loss_gd=0.229608 也略高于 loss_closed=0.220680。迭代次数再加，这组差会继续缩小；但永远不要指望浮点运算给出逐位相同的两条路，闭式解求出的是数值意义上的驻点，迭代解则停在离驻点很近的地方。把这两个数都写进黄金值，等于给「哪条路被改坏了」留了一个双保险。

1.8 真跑：代码与标准输出摆在一起

入口的前半段固定种子、造数据、调用两条求解路径，并计算拟合值与梯度残差。注意打印顺序：先闭式解后梯度下降，先损失后指标，这样读输出的人可以一眼看出两条路的对应关系。

后半段是证据。数值一律走等号，并保留六位小数，例如 w_closed=2.542644；数组与张量走冒号，例如 beta:[0.715911,2.570612]。这条纪律不是审美偏好：闸门把等号左边当数值键，方括号不是合法数字，写成 beta=[...] 会报数值格式错误；冒号让整行退化为普通文字，闸门按逐字对账，读者也不会把结构说明误读成待比较的黄金值。

1.9 手算核对：哪些数能不用程序验

先核对闭式解的量级。真值是斜率二点五、截距一，噪声标准差零点五；六十个横坐标均匀铺满零到十，因此参数的标准误差大约与噪声标准差除以横坐标的离散程度同量级，斜率会落在二点五附近几个百分点的范围里。真跑的 w_closed=2.542644 与 b_closed=0.902543 完全在这个范围，说明生成器和求解器都没有把数量级搞错。手算核对不必精确到小数点后六位，但要能判断「是不是同一个世界的东西」。

再核对损失与残差范数的关系。loss_closed 是残差平方和除以样本数六十，乘以六十就是残差平方和；开平方应当等于 resid_norm。用真跑的数算：零点二二零六八零乘以六十约等于十三点二四，开平方约等于三点六四，与 resid_norm=3.638787 一致。这个关系能抓出两类错误：损失忘了除以样本数，或者残差范数算成了别的范数。

梯度下降那一组也能自查。两百步之后斜率从零走到二点五七，已经越过闭式解一点点；截距从零走到零点七二，还在往零点九爬。两个方向速度不同，是因为截距对应的那一列全一与斜率对应的横坐标列，长度和方差不同，梯度的两个分量尺度不一样。要公平比较收敛速度，通常先把特征标准化；不过那会改变参数的含义，本单元保留原始尺度，让读的人直接看到「同一学习率对不同特征效果不同」这件事。

1.10 决定系数：把损失变成可比的分数

均方损失的单位是标签单位的平方，换一组标签尺度，数字就跟着变，不方便跨问题比较。决定系数 R² 解决了这个问题：它的分母是「什么都不学，一律预测样本均值」时的总平方和，分子是模型的残差平方和，最终算 1 - 残差平方和 / 总平方和。基线模型给出零分，完美拟合给出一分；如果模型比基线还差，它会是负数。因为是无量纲比值，不同任务之间也能粗粗比较。

第 1 帧的基线不是随便挑的：在只允许输出一个常数、又不知道新样本标签的情况下，预测均值是使平方损失最小的常数。所以用总平方和当分母，相当于问「我们这套方法比最笨的办法强多少」。第 2 帧换成真正的预测；第 3 帧给出比值。真跑的 r2=0.996054 说明模型解释了绝大部分波动——这并不意外，因为数据本来就是按直线生成的。要是换成第三单元那些噪声特征，训练 R² 一样可以很高，而测试 R² 会原形毕露。

还有一处细节值得点明：R² 的分母只跟标签的波动有关，与样本数无关；分母为零时，也就是所有标签完全相同，R² 没有定义。报告指标时要连同数据规模和指标定义一起给出，否则一个孤零零的零点九九六说明不了太多。本单元把 n=60 一起打印，就是为了让这个分数有上下文。

1.11 梯度对账：手写公式遇到 autograd

桥接册已经讲过 autograd 会沿着计算图自动求导。这里做一件更具体的事：把刚才手推的梯度 (2/n) X^T r 写一遍，再让框架在闭式解处反向传播一次，把两者的最大绝对差打出来。之所以选闭式解处的参数，是因为那里的梯度理论上应该为零；如果手写公式写错，比如忘了除以样本数或者把转置写反，两个向量就不会吻合，grad_diff 会跳到一个明显非零的值。

真跑的 grad_diff=0.000000 说明两条路在这组双精度数据上逐位一致。这里有两个容易忽略的工程点。第一，张量必须用双精度构造，默认单精度会让最后几位对不上，差值虽小却不再是零；黄金值写零的前提就是类型统一。第二，打印损失之前要 detach，否则把一个还挂在计算图上的张量转成标量会触发警告；那不会影响数值，却会让输出变脏。本单元把这两处都写进代码，读者可以直接照抄这个习惯。

实验记录把手算梯度故意改错一次

把 manual 那行里的二除以 n 改成一除以 n，重跑 python src/main.py。你会看到 grad_diff 从零跳到一个大约为零点一一的量级，而 w_closed、r2 这些数完全不变——这说明梯度检查只守梯度这一件事，不会替别的环节背书。再把改动撤回来，grad_diff 回到零。做完这次实验，你对「黄金值各自守一摊」的理解会比读十遍说明更牢。

1.12 常见坑与读图指引

第一个坑是把截距那一列漏掉。设计矩阵如果只有横坐标一列，模型就被迫穿过原点，拟合参数会为了补偿截距而扭曲斜率，损失和决定系数都会变差。判断办法是打印设计矩阵前两行，确认第一列全是一。第二个坑是显式求逆。数学上等价不代表数值上等价，矩阵越接近奇异，显式求逆的误差越大；养成用求解器的习惯，比事后解释异常值便宜得多。

第三个坑是把学习率当越大越好。平方损失的碗有明确的曲率，步长超过阈值就会发散。判断办法很简单：盯住训练损失，如果它不降反升或者在几个值之间跳动，先把学习率除以十。第四个坑是把训练指标当最终成绩。本单元的数据是按直线生成的，假设与真值完全对齐，所以训练 R² 很高；真实任务没有这么好的运气，第三单元会给出一个训练误差一路下降、测试误差掉头上升的例子。

这一单元有五张图元，读法各不相同。第一节的目录树只看带加号的行，确认本单元新增的两个源文件与清单；设计矩阵那张内存图看第 2 帧那一列全一，它把截距变成了参数向量的一部分；两条路径那张图看第 2 帧与第 3 帧的分叉，再在第 4 帧汇合；投影图看第 2 帧那条垂线，它是法方程的几何来源；决定系数图看第 1 帧的基线，它解释了分母为什么那样选。每一帧都是自包含的，打印出来时各帧独立成图，所以关键节点在相邻帧里重复出现是刻意的。

1.12.1 特征尺度：同一个问题，两种难度的优化地形

还有一个值得单独拆开的话题：特征的尺度会同时改变闭式解的数值稳定性和梯度下降的快慢。本单元的数据很好说话，横坐标只从零铺到十，两列特征的量纲也差不多。换成真实数据，一列可能是房间面积，取值几百到几千；另一列可能是房间数，取值一到五。两列放在同一个设计矩阵里，X^T X 的对角元素会相差好几个数量级，矩阵的条件数随之变大。闭式解要求解一个病态方程组，梯度下降则要面对一个又长又窄的碗：沿着陡的方向必须小心翼翼，沿着平的方向又走得极慢。

把特征中心化并标准化能显著改善这件事。中心化是每一列减去自己的均值，标准化是再除以自己的标准差。做完之后，各列都在零附近、方差都接近一，损失曲面从狭长的山谷变成接近圆形的小碗，同一个学习率在各个方向上都能走得动。对闭式解来说，条件数下降意味着求解更可靠；对梯度下降来说，收敛需要的步数大幅减少。代价是参数不再直接对应原始单位：斜率变成了「特征变动一个标准差，预测变动多少个标签标准差」，解释时要记得换回来。

工程惯例工程惯例：标准化要只学训练集上的统计量

标准化用到的均值和标准差，必须从训练集算出来，然后原封不动地用到验证集和测试集上。有人图省事把全部数据放在一起算统计量，看似更精确，实则把测试集的分布信息泄漏进了训练流程——测试集不再「没见过」。本单元没有做标准化，因为数据本来就很规矩；一旦你在自己的任务里引入这一步，请把统计量也当成模型参数一样保存下来，和拟合出的权重放在一起交给下游。这个纪律在第三单元讲数据拆分时会再次出现。

还有一种常见的误解，认为截距那一列也要标准化。全一列的均值是一、标准差是零，除以标准差没有意义，所以它通常保持原样；更稳妥的做法是先把其他列中心化，此时截距项正好等于标签均值，含义清楚。代码里如果把全一列也送进标准化函数，十有八九会得到一堆除以零的警告。判断办法仍然是打印设计矩阵的前两行：任何一列变成 NaN，问题一定出在这一步。

最后把这件事接回几何图像。中心化相当于把坐标原点搬到数据云的中心，标准化相当于把各个方向的尺子统一长度。第 1.5 节那张投影图里的二维平面没有变化，变的是我们看它的坐标架：坐标架越接近正交且等长，求投影的数值过程越安稳。几何事实和数值实现在这里完全一致——这不是巧合，而是线性代数之所以能指导机器学习的原因。

1.13 从线性回归走向逻辑回归

线性回归的输出可以是任意实数，适合预测房价、温度、销量这类连续量。如果标签只有两个值，比如「是否患病」「是否点击」，直接拿直线去拟合会遇到两个麻烦：预测值可能跑到零到一之外，没法当作概率；平方误差在预测严重错误时给出的梯度会饱和得不合适，分类边界也变得不自然。下一单元会换一个输出函数，把直线的结果压进零到一，并换一个与伯努利分布相配的损失函数。

别小看这一步切换。它让我们第一次看到「模型输出什么」与「用什么损失」必须成套设计：连续量配平方误差，来自高斯噪声的假设；二分类配交叉熵，来自伯努利分布的假设。到那时你会再次用到本单元的三要素框架——数据没变多少，假设和损失变了，整个优化问题的性格就变了。而梯度下降、数值稳定性、固定种子、黄金值对账这些工程习惯，会一直沿用到最后一单元。

小结这一节的要点
  • 监督学习由数据、假设、损失三要素构成，学习就是在假设空间里最小化训练集上的平均损失；
  • 设计矩阵第一列全一对应截距，参数向量只有两项，预测写成 X @ beta，残差写成 y - X@beta；
  • 最小二乘的几何是向列空间作投影，正交条件 X^T r = 0 展开即得法方程 X^T X beta = X^T y；
  • 闭式解用求解器而非显式求逆，梯度下降用负梯度逐步走；学习率必须小于由曲率决定的阈值；
  • 决定系数用「一律预测均值」作基线，残差范数与均方损失相互可核；手写梯度与 autograd 的差值是可复现的证据。

注自测题答案
  1. 三要素是数据、假设、损失。数据是六十对带噪直线的输入输出；假设是限定为直线 y = w x + b；损失是预测与观测之差的平方均值。学习就是在假设给出的两条参数里，找到使损失最小的那一组。
  2. 第一列全一让截距 b 成为参数向量的一个分量，这样截距和斜率在矩阵乘法里地位相同。忘掉它，模型就只剩 y = w x，被强迫通过原点；本例真截距约为一，缺列会让斜率被拧偏，损失明显变大。
  3. 损失对参数的梯度是 (2/n) X^T (X beta - y) = (2/n) X^T r，它是「各列特征与残差的内积」组成的向量。令梯度为零等价于 X^T r = 0，也就是残差与每一列特征都垂直，正是正交条件。
  4. 均方损失是残差平方和除以样本数，所以残差平方和约等于 0.220680 × 60 = 13.2408；开平方得到约 3.6388，与 resid_norm=3.638787 一致。这个核对能发现「忘记除以样本数」或「范数算错」这类故障。
  5. 显式求逆会额外放大舍入误差，尤其在矩阵接近奇异时；求解器直接解线性方程组，通常更稳也更快。两列特征完全共线时 X^T X 奇异，逆不存在，闭式解不唯一；需要删特征、正则化，或者改用能处理秩亏的分解方法。
  6. 分母是总平方和，即每个标签偏离样本均值的平方之和；「一律预测均值」正是使平方损失最小的最优常数，所以这个分母代表基线的误差。所有标签相同时总平方和为零，比值没有定义，报告时应当明确说明这种情况。
