8.1 先看工程长什么样

前面两个单元里，特征值只对我们自己主动摆出来的对称矩阵有意义。可真实数据很少这么乖：用户-物品评分表、词-文档矩阵、一张图片的像素阵列，全都不是对称的，甚至根本不是方阵。SVD 就是把「谱分解」这件事推广到任意矩阵的办法——不管它多长多扁、对不对称，都能拆成「旋转、拉伸、再旋转」三段。

这一节仍然不装库。我们先把 2×2 的最小例子用 C 写出来，把每一步数值都摆到屏幕上，再去谈推荐系统里那个「低秩近似」的直觉。理由和前面几节一样：这一册要证明的不是你会不会调 numpy.linalg.svd，而是这些数字到底从哪来、对不对。

第 1 帧是讲故事用的起点：ch03 的目录还空着。第 2 帧里冒出来一个 svd_small/，里面有本地头文件 svd.h、算法实现 svd.c、驱动 main.c 和清单 la08-svd.json。共用库 common/ 没有变化——这一节继续从它取 mat_transpose、mat_mul、mat_vec、vec_scale 这些函数，不再另写一套矩阵乘法。

大白话把 SVD 想成三步流水线

拿一张纸画一个单位圆。任意线性变换作用在圆上，结果都是一个椭圆。椭圆可以分成三个动作：先把圆旋转到某个角度（这就是右边的 Vᵀ），再沿两个主轴拉伸成椭圆（这就是中间的 Σ），最后把整个椭圆旋转到输出坐标（这就是左边的 U）。三个动作串起来，就是 A = UΣVᵀ。所以 SVD 不是在变魔法，它只是在说：任何矩阵都等价于「选两组正交坐标 + 两个拉伸倍数」。

工程惯例为什么头文件里只放声明

include/svd.h 里只有结构体 svd2_t 和三个函数声明，src/svd.c 里才是真正的分解代码，src/main.c 只负责打印。这样分家的代价是你要多学一个 include guard 和一条 -Iinclude，换来的是接缝清楚：想换算法只改 svd.c，想换展示只改 main.c。后面 la09、la10 都照这个形状摆。

上面那三帧还藏着一个前提：Vᵀ 和 U 都是正交矩阵，所以它们不拉伸也不压缩，只是换个角度。如果换成随便一个可逆矩阵，圆会被拉成斜的椭圆、主轴之间也不再垂直，我们就没法用「两个拉伸倍数」把变换说清楚。换句话说，SVD 的价值恰恰在于它把一份任意线性变换拆成了「两个不损失长度的操作 + 一个只做拉伸的操作」。这也是为什么后面讲 PCA 时可以干脆把数据投到 V 的前几列上——投影矩阵是正交的，投完不会把距离关系搅乱。

另外提醒一句：这里的「旋转」是口语说法。严格地讲，正交矩阵还包括镜像，行列式可能是 −1，并不是所有正交变换都能靠转动一个角度实现。但无论旋转还是镜像，它都保持向量长度和夹角不变，这对我们接下来的推导才是真正要紧的性质。

8.2 A=UΣVᵀ：旋转、拉伸、再旋转

先把三个符号钉死。U 和 V 都是正交矩阵——它们的列向量两两垂直且长度为 1，几何上就是旋转或镜像，转置等于逆。Σ 只有主对角线非零，对角元叫奇异值，按从大到小排成 s1 ≥ s2 ≥ 0。写法 A = UΣVᵀ 从右往左读：先拿 Vᵀ 把输入转到一组特殊的坐标（主轴），再拿 Σ 在各轴上乘上拉伸倍数，最后拿 U 把结果转到输出坐标。

下面三帧把这件事拆开。注意第 2 帧里只有拉伸动作，这正是「谱」这个字的含义：换一组坐标之后，复杂变换退化成几个纯粹的缩放。

第 1 帧到第 2 帧，坐标从 x 变成 x'；第 2 帧到第 3 帧，长度变了又转回去。这三帧合起来读，你就能明白为什么 U 和 V 一般不相等：它们服务的是输入和输出两侧各自的主轴，只有对称矩阵才会出现两边共用一组轴的特殊情况。

工程惯例奇异值的符号与排序都是约定

从 AᵀA 解出来的特征向量可以整体取正或取负：v 和 −v 都是同一个方向。程序里 atan2 给出的角度固定了一套取法，所以同一矩阵在不同库里可能得到符号相反的 U、V 列，但重建出来的 A 完全一样。同理，Σ 的对角元习惯上从大到小排，这是约定而不是数学要求；不排序也能分解，只是「保留前 k 个」就失去了「保留最重要的 k 个」的含义。看到别处的 SVD 输出符号和你不一样时，先别急着判定谁错了。

为什么 AᵀA 能把奇异值交出来

现在回答标题里的问题。对 A = UΣVᵀ 两边取转置再乘回去：

AᵀA = (UΣVᵀ)ᵀ(UΣVᵀ) = VΣᵀUᵀUΣVᵀ = VΣ²Vᵀ

因为 U 正交，UᵀU = I，中间两项消掉；ΣᵀΣ = Σ² 就是对角元各自平方。这个式子长得和 la07 的谱分解一模一样——AᵀA 是对称矩阵，它的特征向量就是 V 的列，特征值就是 s²。所以流程变成：先算 B = AᵀA，再对 B 做一次对称阵的特征分解，最后把特征值开平方，就得到奇异值。svd.c 正是这么做的，用 atan2 直接给出 2×2 对称阵的旋转角，避开了求特征多项式再解二次方程的数值尴尬。

同理 AAᵀ = UΣ²Uᵀ，所以 U 的列是 AAᵀ 的特征向量。不过在这个小例子里我们走了一条更省事的路：拿到 V 和 s 之后直接算 u_i = A v_i / s_i。这两条路给出的 U 只差一个符号约定，不影响后面的截断误差。

陷阱平方会啃掉小 singular value

你会看到：程序明明报 s2 = 0.968371，可如果你在纸上把 AᵀA 的特征值算到六位小数再开方，末位常常对不上。你会误以为是开方写错了。真相是先平方再开方会放大相对误差：一个很小的奇异值平方之后更小，浮点舍入在它身上占的比例更大。这就是为什么本例用 atan2 直接算角度、而不是先解二次方程。生产环境的大矩阵通常连 AᵀA 都不显式构造，直接用 Golub-Rebisch 那一类稳定的算法——我们这里图的是每一步都能手算，代价就是不能用它去做病态矩阵。

8.3 秩：非零奇异值有多少个

la04 讲过用高斯消元数主元来判断秩，那要看行变换的过程。SVD 给了一个静态的判据：rank(A) = 非零奇异值的个数。原因很直观——Σ 的对角元就是各个独立方向的「权重」，权重为零的方向根本没贡献，剩下的方向数就是这张矩阵真正能铺出的维数。

这个判据在推荐系统里特别好用。把用户-物品评分矩阵做一个 SVD，如果前 20 个奇异值之后突然掉到接近零，说明这张表虽然有几万行几万列，真正起作用的偏好方向只有二十来个。于是你可以只用前 20 个奇异三元组重建一张近似表，存储量从「用户数 × 物品数」降到「(用户数 + 物品数) × 20」。这就是所谓隐因子模型的直觉：不是每个用户都单独记一遍，而是把每个人写成少数几个「口味」的组合。

第 1 帧里两格对角元都是非零，所以 rank = 2；第 2 帧把第二格抹零，就得到秩 1 的近似。注意 Σ 的非对角元永远是零——SVD 的「换坐标」工作全被 U 和 V 吸收了，中间的 Σ 只负责拉伸。这一点和 la07 的谱分解完全一样，区别只在于 U 和 V 不再是同一个矩阵。

还有一件容易被含糊过去的事：「零」在浮点数里不是一个干净的开关。上面的代码用 1e-9 作为阈值，而不是写 if (s == 0.0)。原因是真实的数值分解几乎不会给出精确的 0，一个本该为零的奇异值常常落在 1e-15 这种量级。阈值定得太大，会把真实但很小的方向误杀；定得太小，又会把数值噪声当成有效维度。这个阈值是工程约定，不是数学定理，写在清单和正文里才能被人审查。

工程惯例为什么大矩阵不先算 AᵀA

小例子里先算 AᵀA 很方便，因为它把问题化归成上一节已经会做的对称阵分解。但条件数会被平方：如果 s1/s2 = 10⁸，那么 AᵀA 的条件数就是 10¹⁶，已经逼近双精度的极限。代价很清楚——这条路径只适合教学和小维度，真要做推荐系统那种几万维的分解，得用直接作用在 A 上的稳定算法。我们把这个代价写出来，是为了让你以后看到「论文里不用 AᵀA」时知道为什么。

选 k 的时候有个实用办法：把奇异值平方求和当作总能量，然后看前 k 个平方和占了多少比例。本例总能量是 s1² + s2² = 17.062258 + 0.937742 = 18，只留 s1 就拿到 17.062258，占 94.79%。换成一张真实的评分表，你可能发现前 50 个方向就吃掉九成能量，于是把 k 定在 50。这个比例不是定理，是工程上衡量「近似够不够好」的尺子；它必须和业务需求一起定，比如推荐系统能容忍的误差往往由点击率而不是由数学决定。

还有一点值得说清：低秩近似压缩的是「矩阵里重复的结构」，不是随机噪声。如果一张表几乎全是噪声，奇异值会摊得很平，前几个方向占的能量比例很低，此时截断会丢掉大量信息。所以看到「SVD 可以压缩」这句话时，要追问一句：这张表的奇异值是不是真的集中？只有谱很尖的矩阵，低秩近似才划算。

8.4 低秩截断：把能量少的方向扔掉

低秩近似问的是：如果只准保留 k 个奇异值，怎么重建才损失最小？答案由 Eckart–Young 定理给出——保留最大的 k 个，扔掉其余的，在 Frobenius 范数意义下这就是最优解。Frobenius 范数就是把矩阵所有元素平方求和再开方，和向量的欧氏范数是同一套算法，只是把矩阵摊平成一长串。

我们的程序选 k = 1，只留 s1。svd2_lowrank 把保留下来的三元组一项项累加回 s_i · u_i · v_iᵀ，得到近似矩阵 A1。然后驱动算 A - A1 的 Frobenius 范数，打印成 trunc_err。这里有一个很漂亮的恒等式值得记住：

被丢掉的 Frobenius 能量，正好等于被丢掉的奇异值的平方和再开方。

本例只丢了一个 s2，所以 trunc_err = s2 = 0.968371。真跑结果确实如此，这不是巧合。原因是不同奇异值对应的方向彼此正交，误差矩阵 A - A1 的奇异值恰好就是那些被丢掉的 s_i，Frobenius 范数作为「所有奇异值平方和的平方根」，自然只剩这一项。

陷阱截断不是把原矩阵某几格清零

你会想当然地以为「秩 1 截断」就是把 A 的两个元素抹成 0。你也可能会拿截断后的矩阵去和 A 比，发现每一格都变了，于是怀疑程序写错。真相是：截断作用在 Σ 上，不是在 A 上；把 Σ 的一个对角元清零之后，还要乘回 U 和 Vᵀ 重建，这个过程会把误差铺到所有格子里。所以 trunc_err 必须按 Frobenius 范数整体算，不能只看某一格。

Frobenius 范数不是唯一的选择。如果只关心「最差的那一个方向被扭曲了多少」，你会用谱范数，也就是最大的那个奇异值；它等于截断误差矩阵的最大奇异值。两者给出的最优秩 k 近似恰好是同一个（因为同时保留最大的 k 个奇异值），但误差数值不同。本例的谱范数截断误差是 0.968371，Frobenius 截断误差也是 0.968371，这是两个方向恰好凑巧相等的特例；换成三个以上奇异值，两个数就分开了。

把这个恒等式写进程序的意义还不止于验证。它让你可以不重建矩阵就估计误差：只要把没保留的奇异值平方求和开方，答案就出来了。工业级推荐系统正是靠这一点来做实时近似的——先离线算好奇异值和向量，线上只保留前 k 个，误差预算由剩下的奇异值直接给出，不必每次都去减一遍大矩阵。

下一单元转到正定矩阵：如果说 SVD 回答「一张表有多少个有效方向」，那么正定回答的是「一个二次函数是否只有一个最低点」。Cholesky 分解就是这条路上的工具，它和 SVD 一样，本质也是换一组坐标看同一件事。

8.6 存在性：任意矩阵为什么都能拆成三段

上一节用 2×2 的例子演示了分解，但你可能会怀疑：那是小矩阵的运气，还是所有矩阵都成立？答案是后者，而且证明不需要解什么大方程组，只要一个「挑最胖方向」的递归。把单位圆上的每个点 x 送进 A，得到一条闭合的椭圆曲线；因为圆是闭集、A 是连续的，像上一定有一个离原点最远的点。取这个点对应的输入方向作 v1，把它的拉伸倍数记作 s1 = ‖Av1‖。接着在与 v1 垂直的子空间里重复同样的寻找，得到 v2 与 s2，以此类推。每一步都在一个更低维的正交补里做，最多 n 步就停。这就是 SVD 存在性的直觉：在输入空间里挑一组互相垂直的方向，使每个方向被 A 拉伸的倍数依次递减。U 的列则取 Av_i 的归一化结果；不同 v_i 正交，它们的像也自动正交，因为 (Av_i)·(Av_j) = v_iᵀ AᵀA v_j，而后者为零。

严格证明还要处理两种边界情形。若某个 s_i = 0，则 Av_i = 0，归一化做不下去，这时从 AAᵀ 的零空间补一组正交基，Σ 的对应位置写零即可。若几个奇异值相等，比如 s1 = s2，那么这一小段子空间里任何一组正交基都合法：V 不唯一，但 Σ 与重建出来的 A 唯一。这就是「分解不唯一、谱唯一」的典型例子——别的库给出的 U、V 可能和课本不同，先看 Σ 是否一致，再谈谁错。

这条构造也是理解「为什么 AᵀA 的特征值给出奇异值」的最短路径。对任意单位向量 v，有 ‖Av‖² = vᵀAᵀAv = vᵀBv，其中 B = AᵀA 是对称阵。上一句里的「找拉伸最大的方向」就是在最大化二次型 vᵀBv，而 Rayleigh 商的最大值恰是 B 的最大特征值 λ1：把 v 展开成 B 的特征基，vᵀBv = Σ λ_i y_i² ≤ λ1 Σ y_i² = λ1，等号在 v 取 λ1 的特征向量时成立，于是 s1² = λ1。递归到正交补上，得到的正是 min–max 定理给出的第 i 个特征值。所以「开方」不是碰巧，而是两次最大化问题的答案必须相等：一次在 A 的拉伸里问，一次在 AᵀA 的二次型里问。代价也在这里——B 把 s 变成 s²，小奇异值被压得更小，相对误差被放大。

大白话读图指引：三步流水线图在讲什么

8.2 那张三帧图里，别把「旋转」理解成真的把物体转了一下。它说的是换坐标：第 1 帧把同一个向量从标准坐标改写成主轴坐标，节点写作 x' = Vᵀx，点没动、坐标变了；第 2 帧才真正发生长度变化，Σx' 的每个分量乘上各自的 s；第 3 帧又换回输出坐标。读这类图时盯住带星号的节点：星号表示「这一步新出现的东西」。第 1 帧星号在 x'，第 2 帧在 Σx'，第 3 帧在 y。三帧合起来，A 就等价于「选基底—拉伸—换回基底」。哪一帧星号没读懂，先回到那一帧的输入节点，别急着跳下一帧。

8.7 截断误差为什么正好等于被丢掉的奇异值

把 8.4 那句「误差等于 s2」升级成能推广到任意维度的证明。记 A_k = U Σ_k Vᵀ，其中 Σ_k 只保留前 k 个对角元。误差 E = A − A_k = U (Σ − Σ_k) Vᵀ，括号里是一张只在第 k+1 项往后非零的对角阵。Frobenius 范数有一条关键性质：乘上正交矩阵不变，即 ‖QMQᵀ‖_F = ‖M‖_F，因为 ‖M‖_F² = tr(MᵀM)，代入 Q 后 QᵀQ = I 直接消掉。于是 ‖E‖_F² = ‖Σ − Σ_k‖F² = Σ{i>k} s_i²。本例只丢一个 s2，开方后误差就是 0.968371。

证明还没用到「最优」。为什么保留最大的 k 个最好？还是用酉不变性：对任意秩不超过 k 的候选 B，令 C = Uᵀ B V，则 ‖A − B‖_F² = ‖Σ − C‖_F²。要让这个量最小，C 必须尽量贴近 Σ；但 C 的秩最多 k，最多占住 Σ 的 k 个对角位置，把最大的 k 个 s_i² 留下，剩下的平方和最小——这就是 Eckart–Young 定理的证明骨架。反过来说，若你贪心保留了较小的 s2 而丢掉 s1，误差就变成 4.130649，是最优解的四倍多。最优性不是直觉，是从 Frobenius 范数的旋转不变性推出来的。

陷阱三种看似等价其实不等价的说法

第一种：把 Frobenius 误差换成「原矩阵逐格误差的最大值」，然后期待它还等于 s2。逐格最大值没有旋转不变性，U、V 把误差铺到所有格子，最大那一格通常既可能远小于也可能远大于 s2。第二种：以为谱范数误差也等于「所有被丢奇异值的平方和开方」。谱范数只取最大方向，是 max_{i>k} s_i；本例只丢一项所以两数相等，三四个奇异值时就分开了。第三种：以为秩 k 截断后能把丢掉的信息补回来。截断是有损压缩，你能算出的只是误差大小，不存在把它还原的逆操作。

手算核对：从逐格数字走到 s1²+s2²=18

不依赖程序做一次完整核对。A = [[3,1],[2,2]]，按 Frobenius 定义逐格算：‖A‖_F² = 9+1+4+4 = 18。再从 AᵀA = [[13,7],[7,5]] 算迹与行列式：迹 18、行列式 65−49 = 16，故 λ1+λ2 = 18、λ1λ2 = 16。由于 s_i² = λ_i，立刻有 s1²+s2² = 18，与逐格结果完全对上。这不是巧合：Frobenius 范数的平方既能按格子求和，也能按奇异值求和，两条路必须给出同一个数，否则某一边的实现一定错了。

再核截断：s1² = (9+√65)² ≈ 17.062258，s2² ≈ 0.937742，相加恰为 18；丢掉 s2 后误差平方 ≈ 0.937742，开方即 0.968371。若还想看误差矩阵长什么样，取 v1 ≈ (0.864910, 0.501927)、u1 ≈ (0.749678, 0.661803)，重建 A1 = s1 u1 v1ᵀ ≈ [[2.678330, 1.554295],[2.364382, 1.372104]]；逐格相减得 E ≈ [[0.321670, −0.554295],[−0.364382, 0.627896]]，四格平方和 ≈ 0.103472+0.307243+0.132774+0.394253 ≈ 0.937742，开方仍是 0.968371。注意 E 也可以用第二个奇异三元组直接写成 s2 u2 v2ᵀ，两种写法得到同一张矩阵。手算要挑不容易被舍入污染的量：迹、行列式、平方和都稳，拿六位小数的元素来回倒推最容易出错。

8.8 数值稳定性与失败模式

把 AᵀA 显式构造出来再分解，好处是化归成上一节已会的对称阵问题，坏处是条件数被平方：若 s1/s2 = 10⁸，B 的条件数就是 10¹⁶，已经贴着双精度的极限。小奇异值在 B 里变成 s²，相对误差被放大，甚至完全被大特征值吃掉；atan2 直接给角度能绕开解二次方程时两根相减，但绕不开 B 本身的信息损失。生产环境因此不显式形成 AᵀA，而用 Golub–Rebisch 那类直接对 A 做正交变换的算法，或在对角占优时用 Jacobi 旋转；它们只动 A，误差控制在机器精度乘以矩阵规模的水平。本程序选 AᵀA 路线纯粹是为了每一步都能手算，代价就是不能拿它去判病态矩阵。

秩阈值同样要当工程参数看。写 s > 1e-9 是假设输入的元素量级在 1 附近；如果 A 先被乘了 10⁻⁶，所有奇异值一起缩小，同一个阈值就把本该有效的方向全杀掉了。稳妥的做法是用相对阈值，例如 s_i > tol·s1，tol 按机器精度与维度定，再把实际取值写进清单和正文让人审查。

陷阱失败模式：一张几乎秩 1 的评分表

把输入换成 A' = [[3,1],[2, 2+1e-10]]，第二个奇异值掉到约 1e-10 量级。程序里 if (s[1] > 1e-9) 会把它判成零，rank 从 2 掉到 1；可 trunc_err 是按 A'−A1 独立重算的，仍报一个小但非零的数。此时 stdout 与清单黄金值不再相符：若数值行数变了，闸门先报 numeric_line_mismatch；行数没变但某个值超差，报 numeric_value_mismatch；反过来若你只改正文 output 想掩盖，正文与真实 stdout 逐行不一致，报 stale_output。更隐蔽的失败是元素量级相差十几个数量级：算 AᵀA 时大数吃小数，小奇异值安静地变成 0，程序不崩，只是给出错误的秩亏结论。阴性对照的思路在这里照样适用——故意喂一张近秩亏矩阵，看阈值与清单是否真能抓住错误，而不是只在 examples 里那张乖矩阵上打转。

在推荐、LoRA 与压缩里的角色

推荐系统里的用户-物品评分表有几万行几万列，但人的口味往往集中在几十个方向上。SVD 把这张表写成少数几个「用户偏好强度 × 物品主题」的外积之和：保留前 k 个三元组，存储从「用户数 × 物品数」降到 k ×（用户数 + 物品数），线上打分只需点积。这里 k 的选择不是数学问题而是误差预算问题：前 k 个平方和占总能量的比例决定近似精度，业务能容忍多少误差决定 k 取多少。

LoRA 用的是同一个低秩假设，只是对象换成了权重增量。微调时不改预训练权重 W，而是学一个 ΔW = BA，其中 B 是 d×r、A 是 r×k，r 远小于 d、k。训练参数从 d×k 个降到 r×(d+k) 个；如果 W 是 4096×4096、r = 8，参数量从一千六百万降到六万五千，差了二百多倍。为什么低秩够用？因为下游任务真正需要改的方向远少于权重的总自由度——这和评分表里「有效口味只有几十种」是同一个观察。SVD 在这里既是理论解释（ΔW 的谱集中在前 r 个方向），也是实用工具（训练后可以把它吸收回 W，或用它来选 r）。

图像压缩则是另一种出场：一张灰度图就是矩阵，前几十个奇异值常常就能重建出可辨认的轮廓；边缘和纹理落在后面的小奇异值里，丢掉它们就是有损压缩。要注意谱是否真的尖：如果一张表几乎全是噪声，奇异值摊得很平，前几个方向占的能量很低，低秩近似反而损失巨大。所以「SVD 能压缩」这句话要补上前提——谱集中，才划算。

大白话读图指引：Σ 的对角盒图别只读数字

8.3 的 memory 图第 1 帧把四个格子都画出来，是为了强调非对角格永远是零；换坐标的活全在 U、V 里，Σ 只做拉伸。第 2 帧给 Σ[1][1] 和 trunc_err 都加了星号：前者表示「这一维被抹掉」，后者表示「这是抹掉之后新出现的量」。读图时把两帧叠起来看：第 1 帧是原矩阵的谱，第 2 帧是近似矩阵的谱；两帧只差一格，而这一格正好就是误差的大小。这也是为什么误差可以不算矩阵差就得到——你已经在 Σ 上看到了它。

8.9 从 SVD 走到 PCA：同一件事的两种写法

主成分分析常被誉为「数据科学的第一个工具」，它的推导在不少教材里要写满两页：先中心化、再求协方差、再做特征分解、最后按特征值排序。有了 SVD，这条路可以缩短成一句话：对中心化数据矩阵做 SVD，右奇异向量就是主成分方向。设 X 是 m×n，每行是一个样本，先减去列均值得到 Xc。协方差矩阵是 C = XcᵀXc/(m−1)，而 SVD 给出 Xc = UΣVᵀ，于是 C = VΣ²Vᵀ/(m−1)。对比谱分解 C = QΛQᵀ，立刻看到 Q = V、Λ = Σ²/(m−1)。也就是说，C 的特征向量与 Xc 的右奇异向量相同，特征值则等于奇异值平方除以 m−1；各主成分的方差贡献率就是 s_i² / Σ_j s_j²。样本投影到前 k 个主成分上的坐标是 Xc V_k = U_k Σ_k，几何上就是把数据换到方差最大的那几个正交方向上。

这条等价带来两个实用结论。第一，样本数远小于维度时不要显式算 C：C 是 n×n，n 可能是几万，而 SVD 可以直接对 m×n 的 Xc 做，复杂度低得多，也不会因平方放大误差。第二，PCA 的「方差最大」和「重构误差最小」是同一件事的两种说法：投影到前 k 个主成分，丢掉的正是后面那些小奇异值方向，残差平方和按 8.7 的公式就是 Σ_{i>k} s_i²。本单元的例子虽然只有 2×2，但整套逻辑一模一样——A1 保留了 s1 方向，丢掉的 s2 就是「第二主成分贡献的方差开方」。

工程惯例常见误解速查

误解一：「SVD 需要矩阵对称或满秩」。不需要，任意 m×n 矩阵都有 SVD；秩亏时只是某些 s_i 为零。误解二：「SVD 和特征分解是一回事」。特征分解要求方阵与可对角化，且不保证特征向量正交；SVD 对任意矩阵成立，U、V 都正交，两者只在对称正定等特殊矩阵上重合。误解三：「不同库给出的 U、V 不一样，必有一个错了」。重复奇异值或符号约定不同都会造成差异，先看 Σ 是否一致。误解四：「奇异值必须降序，否则分解无效」。降序只是约定，不排序也成立，只是「保留前 k 个 = 保留最重要 k 个」的说法不再成立。误解五：「复数矩阵不能用 SVD」。可以，把转置换成共轭转置即可，本书只讨论实数情形。

陷阱开方前的「负特征值」不是负值奇异值

用 AᵀA 路线时，算出的第二个特征值可能是一个极小的负数，比如 −1e-16。这不是说某个方向有「负的拉伸」，而是舍入误差把本该为零的量推过了零点。程序里写 sqrt(lam > 0 ? lam : 0) 把这类值夹回零，是正确的防御；但如果你看到的是 −0.5 这种明显的负数，那说明输入矩阵或转置乘法写错了，夹回零只会掩盖 bug。同样地，代码里 u_i = Av_i/s_i 遇到 s_i = 0 会除零，这时正确的做法是跳到零空间补基，而不是把极小值硬当除数。数值防御和数学错误要分开看：前者处理噪声，后者需要修代码。

把这一单元和下一单元接起来：SVD 告诉你数据里有哪些方向、每个方向有多重要；但「这个方向上的变化是不是稳定」「一个二次型在这些方向上是不是向上翘」是另一个问题，正定矩阵与 Cholesky 专门回答它。到了 la10，你还会问「这些量对参数怎么变」，于是需要矩阵微分。三段串起来就是：方向（SVD）— 曲率（正定）— 敏感度（微分），深度学习里绝大多数线性代数运算都能塞进这个框架。

小结这一节的要点
  • A = UΣVᵀ 把任意矩阵拆成两次正交旋转和一次对角拉伸；U、V 的列各自正交，Σ 的对角元是奇异值；
  • AᵀA = VΣ²Vᵀ 说明 AᵀA 的特征值开方就是奇异值，但平方会放大相对误差，只适合小维度；
  • rank(A) 等于非零奇异值个数，阈值要显式写，不能靠精确的零；
  • 最优秩 k 近似是保留最大的 k 个奇异值；Frobenius 截断误差等于被丢弃奇异值的平方和再开方，本例恰好等于 s2；
  • 黄金值和容差只写在清单 expect.numbers，正文贴真实 stdout，程序自报的 PASS 不算证据。

  7. 逐格算 ‖A‖_F² = 9+1+4+4 = 18；AᵀA 的迹 18、行列式 16，故 s1²+s2² = 18。取 u1 ≈ (0.749678, 0.661803)，A1 = s1 u1 v1ᵀ ≈ [[2.678330, 1.554295],[2.364382, 1.372104]]，E ≈ [[0.321670, −0.554295],[−0.364382, 0.627896]]，四格平方和约 0.937742，开方 0.968371。LoRA 与低秩评分表都在说：真正需要保留的有效方向远少于矩阵自由度，于是用 r 个外积去逼近一张大矩阵。
