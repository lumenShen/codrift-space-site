:::note 一句话结论
硬件底子不错，50W 的低音底盘弹性十足；但默认调音偏焖，人声基本被吞。花十分钟调一版 EQ，能救回来大半。
:::

## 起因

一直缺一个低音拿得出手、又能带出门的蓝牙音箱：桌面的只够听个响，耳机的低频终究隔一层。刷到这台的时候它还只有港版——海外名叫 Xiaomi Sound Party，2025 年先在海外开卖，想上车只能海淘。后来国行以「小米蓝牙音箱 Pro」的名字上架，定价 599，我也就顺势入了。到今天正好用满一个月。

## 机器本身

:::stat-grid
- **50W** | 15W 高音 + 35W 低音单元
- IP67 | 防尘防水
- 26h | 标称续航
- 599 | 国行定价
:::

参数之外，这一个月里比较直观的几点：

- 带提手，IP67 防尘防水，户外属性拉满，随手拎着走不用操心
- 蓝牙 5.4，支持两台组立体声（TWS）和多台串联，party 玩法是留足了的
- 侧面一圈幻彩灯光，氛围感这个东西见仁见智
- 调音出自哈曼（Harman AudioEFX）——对，这也是下一段要吐槽的重点

## 默认调音：焖

一个字总结这台音箱的原声：**焖**。

不是闷在「量」上的那种轰头，而是整个能量重心压在中低频，中高频偏暗。拆开说：

- **低频的弹性是够的**。鼓点打下去有 Q 弹的回弹，不是只有量没有质的死低音——这是这台机器最值钱的底子
- **人声被完全吞掉**。歌手像躲在鼓和贝斯后面唱歌，以人声为主的流行基本没法听
- **高频偶尔出来露个面**。镲片、气声时不时冒一下，又马上缩回去

所以默认状态下，电子、嘻哈这类节奏型的歌很爽，低音一响整个人就想动；但只要歌的主角是人声，它就开始糊弄。忍了一阵，决定动手。

## 我的 EQ

十段均衡器，从低频到高频：

| 频点 | 增益 |
| --- | --- |
| 31 Hz | -3 dB |
| 62 Hz | -3 dB |
| 125 Hz | -3 dB |
| 250 Hz | -2 dB |
| 500 Hz | -1 dB |
| 1 kHz | +5 dB |
| 2 kHz | +4 dB |
| 4 kHz | +6 dB |
| 8 kHz | +4 dB |
| 16 kHz | +5 dB |

思路就两刀：

1. **31–125 Hz 统一收 3 dB**：焖的源头在中低频，先把量收掉。弹性不受影响，鼓点照样弹
2. **1 kHz 起整体抬 4–6 dB**：人声的基频到齿音都在这一段，4 kHz 给得最多，因为这台的 2k–4k 凹得最狠——人声被吞，主要就吞在这里

效果立竿见影：人声一下子站到了前面，亮了很多，整台音箱从「节奏机」变成了「能安心听歌的箱子」。说不上 hi-fi，但已经是一个比较均衡的听感，流行、人声、电子都能交代过去。

:::note 使用提示
各家播放器 EQ 的增益范围不一样（有的 ±6 dB，有的 ±12 dB）。如果你的播放器上限拉不到 +6，把整组数值按比例缩放就行，曲线形状不变，效果基本不变。调的时候拿两三首最熟的歌当参照，比对频点瞎拉效率高得多。
:::

## 适合谁

- 想要低音好、能带出门的：可以入，这个价位这个低频弹性没得挑
- 想开箱就听人声的：要么接受它的焖，要么照抄上面的 EQ，没有第三条路

一个月下来我的结论是：这 599 买的其实是一个 50W 的低音底盘加一块调音空间。硬件是真的好，调音是真的焖——好在 EQ 这东西，焖是能救的。
